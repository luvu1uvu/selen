# Architecture Decision Records

Короткие записи о значимых решениях: контекст → решение → последствия.
Новое решение — новый файл со следующим номером. Принятые ADR не переписываем: если решение
меняется, пишем новый ADR и отмечаем в старом «Заменён ADR-XXXX». Частичное изменение по решению PM
допускается в том же ADR: правка по месту + раздел «Изменения» с датой и причиной (пример — ADR-0003).
