# Правила вида Selen

Как выглядит интерфейс Selen: цвета, отступы, размеры, скругления, шрифт, состояния, тексты. Файл собран 20.10.2026
из текущего кода (LATER-71, ADR-0023): токены `frontend/src/index.css`, компоненты `frontend/src/shared/ui`, частоты
классов Tailwind по `*.tsx`, раскладка досок (ADR-0019), тексты `locales/ru`. Он описывает, как уже сделано и как
делать дальше; что сейчас расходится с правилами — раздел 12.

- **Раскладку и поведение** экранов задаёт README Kaiten (`docs/ui-reference/kaiten/README.md`): где что стоит и как
  себя ведёт — как в Kaiten. **Облик** (цвета, шрифт, значки, отступы) — свой, по этому файлу.
- **Значения** берутся из кода: токены — `index.css`, размеры компонентов — `shared/ui`. Здесь — какие из них где
  применять. Значение меняется в коде — меняется и строка здесь, в том же PR.
- **Кто сверяет:** сессия, которая делает экран; ревьюер подэтапа; агент `ux-reviewer` (`.claude/agents/`). Агент
  находит то, чего здесь нет, и предлагает дополнение — оно попадает сюда в PR с изменением интерфейса и принимается
  PM вместе с PR.

## 1. Основа

- **shadcn/ui** (стиль new-york, базовый цвет neutral), Tailwind 4, значки **lucide**. Новый элемент интерфейса — сначала
  готовый компонент `shared/ui` (или `npx shadcn add`, ловушка — CLAUDE.md), потом свой.
- **Тема — только светлая.** В `index.css` токены заданы только для `:root`; классы `dark:` в коде — задел, не тема.
- **Шрифт — системный** (стандартный `sans` Tailwind), моноширинный — для номеров карточек и ключей.
- Единица шкалы — 4 px (`1` в Tailwind = 0,25rem). Произвольные значения (`p-[3px]`, `-left-[4.5px]`) — только с
  комментарием, почему не шкала.

## 2. Цвета

Только токены: `bg-*`, `text-*`, `border-*` с именами из таблицы. Нужен новый смысловой цвет — новый токен в `index.css`
(в `:root` и `@theme inline`), а не цвет палитры в компоненте.

| Токен | Значение | Для чего |
|---|---|---|
| `background` | белый | фон страницы, окон, блока доски, шапок доски и колонок |
| `foreground` | почти чёрный | основной текст |
| `card`, `popover` | белый | карточка на доске и `Card`; меню, всплывающие панели |
| `primary` | почти чёрный | основная кнопка; активный раздел полосы — `bg-primary/10 text-primary`; упоминания и ссылки в тексте |
| `secondary` | светло-серый | вторичная кнопка и бейдж |
| `muted` | светло-серый | подложки: список вкладок, код, ячейка под указателем при переносе |
| `accent` | светло-серый | наведение и выбранное: строки дерева, пункты меню, кнопки `ghost` и `outline` |
| `muted-foreground` | серый `#737373` | вторичный текст: подписи, счётчики, подсказки, пустые состояния (контраст — раздел 11) |
| `destructive` | красный | ошибки, удаление, неверное поле; плашка активной блокировки в окне карточки — белая (`bg-background`), граница `destructive/40` и полоса слева `border-l-4 border-l-destructive` (на розовой заливке текст был ниже 4,5:1, U-1 UX-ревью UI-1a) |
| `success` | зелёный `emerald-600` (3,8:1 к белому) | полосы прогресса: чек-листы и дочерние карточки в окне карточки (UI-1a) |
| `border`, `input` | серый `#e5e5e5` | границы блоков, полей, разделители колонок и строк |
| `ring` | серый `#a1a1a1` | рамка фокуса с клавиатуры |
| `sidebar` | `#fafafa` | полоса разделов и панель дерева |
| `canvas` | `#ecedef` | холст страницы досок: свободное место вокруг блоков досок заметно темнее досок (ADR-0019) |
| — | `color-mix(muted 40 %, background)` | фон полосы дорожки (`LaneRow`): произвольное значение, кандидат в токен `--lane` |

`secondary`, `muted` и `accent` сейчас одного цвета (`#f5f5f5`) — различаются смыслом; выбирать по смыслу.

**Цвета палитры Tailwind — только здесь:**

| Смысл | Цвета | Где |
|---|---|---|
| Успех | `emerald`: фон 50/100, граница 200, текст 700/800 | `Badge` `success`, `Alert` `success` |
| Предупреждение | `amber`: фон 50/100, граница 200, текст 800/900 | `Badge` `warning`, `Alert` `warning` |
| Ошибка, опасность | `red`: фон 50/100, граница 200–400, текст 700/800 | `Badge` `destructive`, `Alert` `destructive`, блокировка и срочность на фасаде карточки |
| Категории колонок | очередь — `slate-500`, в работе — `blue-600`, готово — `emerald-600`: не меньше 3:1 к белому (раздел 11) | точка категории в заголовке колонки (LATER-77) |
| Затемнение под окном | `bg-black/50` (окно), `bg-black/40` (выезжающая панель на узком экране) | `Dialog`, `Sheet`, `AppLayout` |
| Аватары | 8 цветов `UserAvatar`, инициалы белые — каждый цвет не меньше 4,5:1 с белым | фасад карточки, участники, люди в карточке |

Цвета меток и типов карточек задаёт пользователь (`LabelBadge`, `CardTypeLabel`); текст на них белый.

## 3. Отступы

Шкала, которая используется: **0.5 (2 px), 1 (4), 1.5 (6), 2 (8), 3 (12), 4 (16), 6 (24), 8 (32), 12 (48)**. Частота по
коду: `gap-2` — больше сотни мест, затем `gap-1`, `gap-4`, `px-2`, `px-3`, `gap-3`, `gap-6`, `gap-1.5`. Другие шаги
(`2.5`, `5`, `7`) — только внутри компонентов shadcn и для позиций значков в поле.

| Где | Отступ |
|---|---|
| Значок и текст в одной строке (кнопка, пункт меню, бейдж) | `gap-2` в кнопке и меню; `gap-1.5` в строке дерева и маленькой кнопке; `gap-1` в бейдже и на фасаде карточки |
| Кнопки в ряду, элементы в строке | `gap-2`; мелкие значки рядом — `gap-1` |
| Блоки внутри окна, формы, вкладок | `gap-4` (`DialogContent`, `Tabs`); заголовок и описание окна — `gap-2` |
| Разделы страницы | `gap-6`; заголовок страницы и пояснение под ним — `gap-1`/`gap-2` |
| Поля обычной страницы (`main`) | `p-4`, с 768 px — `p-8` |
| Окно (`Dialog`) | `p-6`; выезжающая панель (`Sheet`) — `p-4`; окно карточки — без своего поля, содержимое — `px-4 pt-5 pb-6`, с 640 px — `px-6`, секции — `gap-4` |
| Строка «название поля — значение» (окно карточки) | название — колонка 10rem (160 px), зазор `gap-4`; уже 640 px — название над значением; строки — `gap-2`; кнопка без фона в столбце значений и внизу секции — текст вровень с левым краем (`-ml-2` при `px-2`) |
| Меню | `p-1`; пункт — `px-2 py-1.5`; разделитель — `my-1` |
| Подсказка (`Tooltip`) | `px-3 py-1.5` |
| Бейдж | `px-2 py-0.5`; плотная метка на фасаде — `px-1.5` |
| Сообщение (`Alert`) | `px-4 py-3` |
| Ячейка таблицы | `p-2` |
| Холст досок | `p-3`, с 768 px — `p-4`; между досками ряда и между строками одного ряда — `gap-3`, между рядами — `gap-6`: ряд виден на экране (ответ PM 21.10) |
| Вкладки страницы пространства («Участники», «Метки») | как у холста: `p-3`, с 768 px — `p-4` — левый край вровень с названием на панели |
| Панель страницы пространства | `px-3 py-2`, с 768 px — `px-4`; группы (название, вкладки, кнопки) — `gap-x-4`, кнопки — `gap-2`; узкая панель (уже 56rem, container query) — группы `gap-x-1.5`, название · ключ · ⓘ — `gap-1`, вкладки — `px-1.5`, ключ — `px-1.5` |
| Блок доски | шапка, строка заголовков колонок, тело, полоса дорожки — по `px-3`; с ручкой ⠿ (страница пространства) название стоит в 43 px от края блока (`-ml-1` + `size-7` + `gap-1.5`), ручка — примерно вровень с названиями дорожек |
| Колонки | зазор `gap-2`, тонкая линия-разделитель — посередине зазора |
| Ячейка доски | `p-2`; карточки друг под другом — `gap-2` |
| Карточка на доске | `px-3 py-2`; строки внутри — `mt-1`/`mt-1.5` |
| Дерево | панель — `px-2`; строки — `gap-0.5`; шапка — `px-4`; поиск — `px-3 pb-2` |

Похожие элементы — с одинаковыми отступами: строки одного списка, ячейки одной доски, кнопки одного ряда. Левые
края текста в столбик совпадают. В блоке доски (замер 20.10): название доски и полосы дорожек — 12 px от края блока
(`px-3`); названия колонок — 20 px (`px-3` блока + `px-2` заголовка), вровень с левым краем карточек (`px-3` + `p-2`
ячейки).

## 4. Размеры

| Что | Размер |
|---|---|
| Верхняя панель и шапка дерева | `h-14` (56 px) — одна линия во всю ширину окна |
| Кнопка | `h-9` (обычная), `h-8` (`sm`), `h-10` (`lg`); кнопка-значок — `size-9`; на доске (шапка блока, заголовок колонки, полоса дорожки) — `size-7` (`ghost`), кнопки-значки одного блока — одного размера; панели дерева — `size-8` |
| Поле ввода, выпадающий список | `h-9`; поиск в дереве — `h-8` |
| Строка дерева, пункт меню | `h-8` (32 px) |
| Значок lucide | `size-4` по умолчанию (в кнопке ставится сам); `size-3.5` — шевроны и крестик поиска; `size-3` — на фасаде карточки и в бейджах; `size-5` — полоса разделов |
| Аватар | `size-7`; мелкий — `size-5` |
| Полоса разделов / панель дерева | `w-14` (56 px) / `w-64` (256 px) |
| Блок доски | шапка — `h-12` (48 px); заголовок колонки — не ниже `h-9`, с `py-2`; полоса дорожки — `h-10` (40 px); колонка — `w-68` (272 px); ячейка — не ниже `h-24`; блок — не уже 20rem (320 px) и не ниже 15rem (240 px), ширина — по колонкам, высота — по содержимому (ADR-0019) |
| Доски в ряду (страница пространства) | доски не сжимаются: каждая своей ширины по колонкам, не поместилась — на следующую строку того же ряда, ряд вбок не прокручивается; прокрутка вбок внутри блока — только у доски шире холста (решение PM 21.10, вариант Б); свёрнутая — шапка `h-12` по ширине содержимого «⠿ Название · N карточек ⋯ ˅» (`w-fit`); ручка ⠿ — `size-7`, только когда доски рядами (с 769 px) |
| ✕ окна | `size-8` (32 px) в углу (`top-3 right-3`), рамка фокуса, подпись «Закрыть» для диктора; **без подсказки Tooltip** — исключение из раздела 8: окно без полей отдаёт фокус ✕ при открытии, и Esc закрыл бы подсказку, а не окно (E2E `space-panel.spec`) |
| Окно | до `max-w-lg` (512 px) по умолчанию; шире — по содержанию (просмотр вложения — `max-w-5xl`); окно карточки — `max-w-3xl` (768 px, README Kaiten: «около 800 px»), у верха экрана (`top-8`), не выше экрана — прокручивается содержимое; уже 640 px — на весь экран |
| Ряд действий окна карточки | «+» слева — круглая `size-9` основного цвета с `shadow-md`; «⋯» справа — круглая белая с границей и `shadow-xs`; кнопки стоят на линии `border` во всю ширину |
| Текст-пояснение на странице | не шире `max-w-2xl`; содержимое «Структуры» — `max-w-3xl` |
| Цель щелчка | не меньше 24×24 px (WCAG 2.5.8) — у кнопок и стрелок раскрытия; номер карточки кнопкой или ссылкой — `inline-flex min-h-6 items-center` |

## 5. Скругления, границы, тени

`--radius` = 0.5rem: `rounded-sm` 4 px, `rounded-md` 6 px, `rounded-lg` 8 px, `rounded-xl` 12 px.

| Скругление | Где |
|---|---|
| `rounded-sm` | пункты меню |
| `rounded-md` | кнопки, поля, бейджи, подсказки, меню, карточка на доске, строки дерева |
| `rounded-lg` | окна, сообщения (`Alert`), список вкладок, значки полосы разделов |
| `rounded-xl` | блок доски, `Card`, пустое место на пустой доске |
| `rounded-full` | аватары |

- **Граница** — 1 px, цвет `border`. Пунктир — заглушка пустого места (пустая доска) и место броска при переносе.
  Цветная полоса слева у карточки (`border-l-4`) — тип карточки.
- **Тени:** `shadow-xs` — кнопки, поля, карточки на доске; `shadow-md` — меню и всплывающие панели; `shadow-lg` —
  окна и перетаскиваемая карточка. Блок доски — без тени, только граница на фоне холста.

## 6. Шрифт

| Размер | Где |
|---|---|
| `text-2xl font-semibold` | заголовок страницы (`h1`) |
| `text-xl font-semibold` | заголовок экрана ошибки |
| `text-lg font-semibold` | заголовок окна; название пространства на панели страницы пространства (панель над холстом — компактная, как шапка доски) |
| `text-base font-semibold` | название доски в шапке блока, заголовок панели дерева |
| `text-sm` (14 px) | основной текст интерфейса: кнопки, поля, меню, строки, карточки; заголовок секции окна карточки — `text-sm font-semibold`; название поля в «Основных параметрах» — `text-sm text-muted-foreground` обычной насыщенности (`<Label>` в строке — `font-normal leading-5`) |
| `text-xs` (12 px) | вторичное: счётчики, номер карточки, метаданные, бейджи, подсказки, полоса пустого дерева |
| `text-[10px]` | только плотная метка и мелкий аватар на фасаде карточки |

- **Насыщенность:** `font-semibold` — заголовки (страница, окно, доска, колонка верхнего уровня, дорожка);
  `font-medium` — кнопки, подписи полей, подколонки, выбранная строка; остальное — обычный.
- `font-mono` — номера карточек (`DEV-12`) и ключи пространств; `tabular-nums` — счётчики (цифры не прыгают).
- **Длинный текст:** однострочные названия (дерево, шапка доски, полоса дорожки, заголовок колонки, списки) —
  `truncate` с многоточием, полное название — в подсказке; название карточки на доске переносится. На доске и панели
  пространства — `TruncatedText` (`shared/components`, LATER-74): обрезанное название получает фокус (Tab) и показывает
  подсказку по наведению и по фокусу; целиком видное — без подсказки и без остановки Tab.
- Регистр — как в предложении; заглавными — только ключ пространства в поле ввода и инициалы в аватаре.

## 7. Состояния

| Состояние | Как выглядит |
|---|---|
| Наведение | строки, пункты меню, `ghost`/`outline` — фон `accent` и текст `foreground`; основная кнопка — `primary/90`; ссылка — подчёркивание; строка таблицы — `muted/50` |
| Фокус с клавиатуры | рамка `ring` вокруг элемента (`focus-visible:ring-[3px] ring-ring/50` у компонентов shadcn, `ring-2 ring-ring` у карточки); от щелчка мышью рамки нет (`focus-visible`) |
| Выбранное, активное | строка дерева — фон `accent` и `font-medium`; раздел полосы — `bg-primary/10 text-primary`; вкладка — белая на сером списке; пункт-флажок меню — галочка |
| Недоступное | `opacity-50`, без реакции на указатель; почему недоступно — в подсказке, если причина неочевидна (пункт «Левее» у доски, которая и так с края, — без подсказки). Для экранного диктора `aria-disabled` — только у действительно недоступного: карточка без права переноса открывается, поэтому она без `aria-disabled` и без инструкции переноса (LATER-76) |
| Появляется по наведению | «+ Карточка» под последней карточкой — `opacity-0` → видна по наведению и фокусу; место под неё занято заранее — соседи не сдвигаются |
| Перенос карточки | на месте броска — пунктирная рамка размера карточки (`outline-dashed`, фон `muted-foreground/10`, содержимое скрыто); ячейка под указателем — фон `muted`; переносимая копия — с наклоном и `shadow-lg`; кнопок «+ Карточка» во время переноса нет; свёрнутая дорожка бросок не принимает |
| Загрузка | текст «Загрузка…» серым (и на месте страницы, пока при первой загрузке приложения грузится её код — `RouteLoading`, HydrateFallback); кнопка отправки — «Сохранение…» и недоступна до ответа; заглушки досок не сдвигают то, что уже на экране: ряды ниже первого экрана скрыты, пока его доски не загрузились; ширина места доски в ряду известна до загрузки (по колонкам, задаёт CSS) — вход на страницу и возврат на вкладку «Доски» без «прыжка»; в ряду первого экрана, пока он грузится, видны только первая доска и доска из дерева — остальные строки ряда стояли бы под заглушками и «прыгали» (U-1 UX-ревью варианта Б) |
| Пусто | серый `text-sm`: почему пусто и что сделать (и кнопка действия, если оно доступно пользователю); общая строка — «Ничего не найдено»; пустая доска — пунктирное поле с подсказкой. Окно карточки: пустая секция (чек-листы, связи, блокировки, файлы, ссылки) не показывается — появляется через «+»; пустое описание — пунктирное поле с подсказкой «Добавьте описание…» |
| Ошибка | поле — красная граница и текст ошибки под ним (ошибки 422 раскладываются в поля); страница — `ErrorState` / `NotFoundState` с кнопкой; итог действия — уведомление (`sonner`, справа сверху) |
| Свёрнуто / развёрнуто | шеврон с `aria-expanded`; после переключения фокус остаётся на шевроне (новый элемент на месте старого получает фокус сам); свёрнутая дорожка — строка с названием и счётчиком во всю ширину доски, щелчок по строке разворачивает; свёрнутая доска — шапка «Название · N карточек», щелчок по шапке разворачивает; секция окна карточки — заголовок-кнопка со стрелкой, состояние запоминается в браузере для всех карточек («Сведения» свёрнуты сразу); доска, перешедшая при этом в другую строку ряда, не уезжает: холст держит её шапку на прежнем месте (у верха холста — насколько можно), шеврон с фокусом — на экране (U-2 UX-ревью варианта Б) |
| Перенос доски | за ⠿ (курсор «рука»): под указателем — копия шапки (`opacity-80`, `shadow-lg`), исходная доска — `opacity-50`, место — линия `bg-primary` 3 px там, где доска на самом деле встанет: вертикальная между досками строки; если рядом с соседкой слева доска не поместится — горизонтальная под строкой соседки, длиной в доску; отдельным рядом — горизонтальная во всю ширину между рядами (ответ PM 21.10); раскладка до отпускания не меняется |
| Блокировка, срочность, срок | на фасаде карточки — красная рамка или фон и значок с текстом для экранного диктора; срок — бейдж со значком |

Ни одно состояние не обозначается **только цветом**: рядом значок, текст или изменение формы (рамка, насыщенность).

## 8. Значки и подсказки

- Значки — только lucide. Эмодзи — иконка пространства и папки, которую задаёт администратор.
- **Значок без текста** (кнопка «⋯», шеврон, «+», значок на фасаде) — `aria-label` и **`Tooltip`** (`shared/ui/tooltip`) на
  элементе, который получает фокус, а не атрибут `title` (CLAUDE.md, фронтенд, правило 8; LATER-57). Подсказка — тем
  же текстом, что `aria-label`; короткая запись — `Hint` (`shared/components/Hint`). Фокус, который вернуло закрытое окно
  или меню «⋯», подсказку не открывает (`restoreFocusQuietly`, `shared/ui/restore-focus`): открытая подсказка забрала бы
  следующий Esc у окна под ней (LATER-94, U-5 UX-ревью UI-1a).
- **Меню «⋯»** — `ActionsMenu` (`shared/components`, LATER-75, LATER-80): подпись и подсказка — «Действия с <чем>
  «Название»»; пункт, который открывает окно, — через `opensDialog` (окно забирает фокус у «⋯», закрытое — возвращает).
  Подсказка — по наведению и по фокусу с клавиатуры; фокус, вернувшийся на «⋯» после щелчка мышью, подсказку не
  открывает (она висела бы, пока фокус не уйдёт).
- Обрезанное название — полный текст в подсказке Tooltip, видной и с клавиатуры (`TruncatedText`, раздел 6).

## 9. Тексты

- Все строки — через i18n (`locales/ru/*.json`), по-русски, без технических слов (id, API, коды ошибок). Это касается и
  текстов только для экранного диктора: `aria-label`, `aria-roledescription`, объявления при переносе.
- Регистр — как в предложении. Кавычки — «ёлочки», в том числе вокруг названий объектов в `aria-label` и подсказках
  («Действия с колонкой «Backlog»»). Многоточие — один символ «…»: у процессов («Загрузка…»,
  «Сохранение…») и у пунктов меню, которые открывают окно с вводом или выбором («Изменить…», «Переместить в…»,
  «Удалить…»).
- Кнопка называет действие глаголом («Сохранить», «Добавить участника»); в окне подтверждения кнопка повторяет действие
  («Удалить», а не «Да»), заголовок — вопрос или предупреждение с названием объекта.
- Числа с существительными — формами множественного числа i18next («1 карточка», «5 карточек»).
- Даты — относительные («2 дня назад»), точная дата — в подсказке (README Kaiten, раздел 02).
- Ошибки — человеческим языком: что не так и что сделать; текст 422 приходит с сервера.

## 10. Раскладка и прокрутка

- Окно браузера не прокручивается; прокручиваются `main` обычной страницы и холст страницы досок, тело доски — вбок
  (ADR-0019, ловушки CLAUDE.md). Шапка доски, заголовки колонок и полоса дорожки закреплены при прокрутке.
- Ширины, на которых проверяем: **1280** (узкое рабочее окно), **1440** (частый ноутбук: доска в 4 колонки — 1138 px —
  при открытом дереве уже шире холста) и **1920** (широкое); страницу пространства — ещё **768** и **1024** с рядом из 3–4
  досок (LATER-81). Меньше 768 px — дерево выезжающей панелью поверх страницы. **768 px и уже —
  доски в колонку**: рядом с деревом холсту остаётся около 450 px. Ряды — с 769 px, брейкпоинт `rows` (`rows:` /
  `max-rows:`), а не `md:` — у Tailwind `md` начинается с 768 включительно.
- Доска — блок на холсте: ширина по колонкам, высота по содержимому, фон холста — справа и снизу (ADR-0019).
- **Доска листается вбок** (шире видимой части): у края тела и строки заголовков колонок, за которым ещё есть колонки, —
  затенение: градиент `from-foreground/15` к прозрачному, 24 px (`w-6`); докручено до края — затенения нет, у доски уже
  холста — нет вовсе (U-7 UX-ревью варианта Б, дополнение PM 21.10). Полоса прокрутки на macOS скрыта — иначе не видно, что
  доска листается.
- **Заголовок колонки** (как в Kaiten, README Kaiten, раздел 03; LATER-77): название слева на всю оставшуюся ширину;
  справа — точка категории (`size-2` в цели `size-6`, с подсказкой Tooltip «Очередь» / «В работе» / «Готово», в порядке
  Tab; только у колонки верхнего уровня — подколонки наследуют категорию), счётчик карточек (`text-xs tabular-nums`), «+»
  и «⋯». Текстового бейджа категории нет — он съедал ширину названия.
- **Страница пространства:** панель над холстом — всегда одна строка: название, ключ, ⓘ, вкладки «Доски / Участники /
  Метки», сразу за ними «Архив досок» и «Создать доску» (как в Kaiten; только на вкладке «Доски»), справа — «Изменить»;
  правая часть панели — под «Фильтры» (этап 6). **Узкая панель** — по ширине самой панели, а не окна (container query,
  уже 56rem = 896 px; с открытым деревом — окно до ~1210 px): «Название · ключ · ⓘ · вкладки · ⋯», кнопки — пунктами
  меню «⋯» (только доступные; нет ни одного — нет и «⋯»). Название обрезается с подсказкой; на экране уже 480 px ключа
  нет, ⓘ остаётся (решения PM 20.10 и 21.10, LATER-74; мобильная версия целиком — отдельный кандидат). Новая панель
  или полоса с переменным набором кнопок — так же: узкий вид по её ширине (`@container`). Доски рядами, ряды — от левого
  края, доски ряда выровнены по верху. Доска из дерева —
  страница пространства, прокрученная так, что доска у верха холста; над ней — зазор между строками ряда (12 px), а не поле
  холста (16 px): край доски выше не торчит (U-6 UX-ревью варианта Б). Свернуть доску ˄ — последней кнопкой шапки, после «⋯».
- У кнопок блока доски, которых на странице несколько, в подписи — название доски («Действия с доской «Продукт»»,
  «Свернуть доску «Продукт»»).
- **Окно карточки** (UI-1a, README Kaiten, раздел 02): большое окно поверх своей доски или страницы пространства, адрес
  `/cards/KEY-N` (`/spaces/KEY/cards/KEY-N`). Закрытие — на то же место прокрутки: открытое с доски — шагом назад по
  истории, по прямой ссылке — заменой адреса. Сверху вниз: шапка (название правится на месте; «DEV-12 · Заказчик ФИО»;
  «Создана / Перемещена N назад») → ряд действий («+» — только разрешённые пункты, нет ни одного — нет «+»; «⋯») →
  активная блокировка → «Основные параметры» → «Описание» → чек-листы → связи → блокировки (история) → файлы → ссылки →
  «Сведения» → вкладки «Комментарии» / «История». Файл можно бросить на любое место окна. Новая секция или кнопка ряда
  действий — по этому порядку и README Kaiten.
- **Известное поведение (решение PM 20.10, U-12):** если свернуть последнюю дорожку, когда холст прокручен к её
  середине, холст упирается в конец прокрутки, и полоса дорожки уезжает от указателя вниз. Так и оставлено — не
  находка.

## 11. Доступность и контраст

- **Контраст (WCAG 2.2 AA):** текст — не меньше 4,5:1 (крупный — от 24 px или от 18,66 px полужирным — 3:1); границы и
  заливки, по которым узнают элемент управления и его состояние (фокус, выбранное), — не меньше 3:1 к соседнему цвету.
- **Клавиатура:** всё, что делается мышью, делается с клавиатуры; порядок Tab — как на экране (удержание фокуса в автотестах
  проверять переходом Tab с соседнего элемента, а не `element.focus()` — иначе ошибки вроде U-4 UX-ревью варианта Б не видно); Esc закрывает окно и
  меню, фокус возвращается на кнопку, которая их открыла (окно из пункта меню — на кнопку меню «⋯», окно карточки — на
  её плитку; `shared/ui/restore-focus`). **Окно карточки:** при открытии фокус — на самом окне (не в поле названия); Esc
  в поле с текстом выводит из поля (текст остаётся), в названии — отменяет правку; закрытие окна с несохранённым текстом
  (Esc, щелчок мимо, ✕, «Назад») спрашивает «Закрыть без сохранения?» (`useUnsavedText`, решение PM к UI-1a); у панели вкладки (`TabsContent`), внутри которой есть свои элементы с фокусом, —
  без `tabindex`, иначе невидимая остановка Tab; доска, открытая из дерева, получает фокус (место доски `tabIndex=-1`,
  без прокрутки) — следующий Tab ведёт в неё; карточку можно перенести с клавиатуры (пробел, стрелки,
  пробел; Esc — отмена). Элемент тела доски, получивший фокус с клавиатуры, — целиком в видимой части тела по горизонтали:
  тело прокручивается вбок само (Chrome не прокручивает частично видимое) с запасом в ширину затенения края (24 px), холст
  и окно — нет; так же строка заголовков колонок; щелчок мышью и фокус в меню доску не сдвигают (UX-ревью LATER-81, U-3).
- Шевроны сворачивания — `aria-expanded`; переключатели — `aria-pressed`; значки без текста — `aria-label`.
- Цели щелчка — не меньше 24×24 px.
- Видимая подпись кнопки входит в её доступное имя и стоит в начале (WCAG 2.5.3): голосовая команда «нажми Карточка»
  должна найти «+ Карточка».
