Решения по ходу работы:
- **Точка категории — справа, перед счётчиком**, а не перед названием: название колонки остаётся вровень с карточками
  (правила вида, раздел 3), у колонки и её подколонок названия на одной линии. Цвета точки — насыщенные (`slate-500`,
  `blue-600`, `emerald-600`): не меньше 3:1 к белому.
- **Подпись «+» колонки не менял** («Добавить карточку в начало To Do», без «ёлочек»): LATER-77 — «"+" и "⋯" как сейчас»,
  а «ёлочки» затронули бы 4 приёмочных теста. Осталось мелочью в разделе 12 правил вида.
- **Окно из «⋯» открывается кадром позже** (как у «⋯» доски с PR 3): окно забирает фокус у «⋯» и при закрытии
  возвращает его, Esc закрывает окно, а не подсказку. Теперь так у всех «⋯» (`ActionsMenu`).
- **419** обрабатывает клиент API (`shared/api/client.ts`) для всех запросов; одно обновление токена на все запросы,
  получившие 419 одновременно. Текст — в `getErrorMessage`, поэтому одинаков во всех формах.
- **Отступ над доской из дерева** — зазор между строками ряда (12 px); доска первой строки первого ряда остаётся на поле
  холста (16 px) — прокручивать к ней нечего.
- **Узкая панель на 375 px:** чтобы всё встало в одну строку, на узком экране плотнее зазоры, поля ключа и вкладок; названию
  остаётся около 40 px («Ра…» у «Разработки»), полное — в подсказке (по наведению и по фокусу). На 768 px с деревом
  «Разработка» видна целиком.
- **Затенение** — градиент от токена `foreground` (15 %), 24 px; у строки заголовков колонок — тоже (те же края).
