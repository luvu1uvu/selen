> Номера PR в этом документе — старого репозитория (архив: selen-archive — приватный `luvu1uvu/selen-archive`, ADR-0022).

Рабочий журнал этапа «Пространства, доступы, доски и движение карточек». Обновляется после каждого
крупного блока, чтобы новая сессия могла продолжить с того же места. Итоговый отчёт — `stage-1-report.md` (в конце 1c).

## Уточнения PM к плану

1. Подколонка у колонки с карточками → карточки переезжают в первую подколонку, `reason = column_split`.
2. Stacked PR без rebase; при конфликтах — `git merge main` в ветку. Уточнение после мёржа 1a: если предыдущий
   подэтап смёржен — ветка от свежего `main`; упавший CI чиним сами до отчёта.
3. `POST boards/{board}/move` — только перестановка внутри пространства; перенос между пространствами API не допускает.
4. Восстановление архивных колонок и дорожек — вне scope (в `docs/backlog.md`).
5. После каждого подэтапа — короткий отчёт PM; полный отчёт из 9 разделов — в конце 1c.

## Проблемы и находки

- Локальный `.env` (не в git) обновлён до `SESSION_LIFETIME=480`; на других машинах — поправить вручную и `make restart`.
- `sed -i` по `.env` создаёт новый файл, а bind-mount одного файла в контейнере продолжает указывать на старый —
  Laravel в контейнере перестаёт видеть `.env` (предупреждения `file_get_contents(.../.env)` в тестах). Лечится `make restart`.
- По умолчанию Laravel отдаёт разный текст 404 для «модель не найдена» и «отказ политики» — это раскрывало бы
  существование чужого пространства. Все 404 в `/api` унифицированы (`bootstrap/app.php`).
- `npx shadcn add` поставил посторонний npm-пакет `cn` вместо импорта нашей утилиты — откатили, записано в CLAUDE.md.
- Vite в Docker на Colima иногда не получает событие изменения файла — страница показывает старый код.
  Лечится `docker compose restart node` или `VITE_USE_POLLING=true` (runbook).
- В тестах с `travelTo()` в прошлое хелпер `browser()` считает cookie истёкшими (сравнение с реальными
  часами) — время в сквозных тестах двигаем только вперёд от текущего. Сессия 480 минут честно истекает
  при сдвиге больше чем на 8 часов — в сценарии участники входят заново.
- Предустановленные типы карточек созданы миграцией 1a с ULID в верхнем регистре, модели генерируют
  нижний — на работу не влияет (id — просто строки), миграцию не меняем (смёржена).
- Ключ пространства `E2E` отклонила проверка в БД (цифры запрещены) — для E2E взят ключ `QA`.
- Проверка здоровья nginx через `localhost` внутри контейнера шла на IPv6 (`::1`), а nginx слушает IPv4 —
  используется `127.0.0.1`.
- Тест фокуса после закрытия панели карточки был нестабилен под нагрузкой (Radix возвращает фокус
  асинхронно) — тест ждёт полного закрытия панели.
- Обычный `TRUNCATE event_log` теперь упирается во внешний ключ из `auth_audit`; тест append-only проверяет `TRUNCATE ... CASCADE`.
