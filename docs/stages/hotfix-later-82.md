# Хотфикс LATER-82: образ php без pecl.php.net — журнал работ

Карточка: **LATER-82** («Бэклог», «Взято в работу», заведена `make pm-task`). Ветка `hotfix/later-82` от main `bb45f86`.

## Задание PM (21.10)

E2E по PR #13 (коммит `3547bac`) трижды подряд падали на сборке образа php: pecl.php.net не отдавал pcov и redis
(«No releases available», «cannot download», 504; с машины сессии — тоже 504). Не ждать: отдельный хотфикс от свежего
main — сборка образа php без pecl.php.net: redis и pcov из исходников с GitHub (фиксированные версии и теги, проверка
контрольной суммы) или из другого надёжного источника; при желании — кеш слоёв Docker в CI. Сборка dev, стенда и CI —
тем же способом. Инфраструктура — точечный аудит безопасности. Мёрж — после «принято»; затем main — в `layout-3`
и зелёный CI по PR #13.

## Сделано

- **`docker/php/Dockerfile`** (один для dev, E2E/CI и стенда — `docker-compose.yml`, `docker-compose.e2e.yml`,
  `docker-compose.pm.yml`): `redis` 6.3.0 и `pcov` 1.0.12 — архивы GitHub по коммиту тега (`phpredis/phpredis` —
  `df4fab2`, `krakjoe/pcov` — `e16c08e`; сначала были по тегу, по коммиту — после аудита, S-2),
  liblzf — подмодуль phpredis (в архиве тега его папка пустая, а установщик собирает redis со сжатием lzf) — архив
  `nemequ/liblzf` по коммиту подмодуля тега 6.3.0. Версии, коммит и суммы sha256 — `ARG`; скачивание `curl --retry 5`,
  проверка `sha256sum -c` (как в официальных образах php); `install-php-extensions` получает пути к распакованным папкам
  (поддерживает папку с `package.xml`) — ничего не скачивает с PECL. Остальные расширения — из состава PHP, как раньше.
- **Версии те же, что были** (6.3.0, 1.0.12): `php -m`, `php --ri redis` (сжатие lzf, zstd, lz4; сериализаторы php,
  json) и `php --ri pcov` в новом образе совпадают с прежним построчно.
- **Проверено:** суммы архивов — по двум скачиваниям каждого; сборка с недоступным pecl.php.net
  (`--add-host pecl.php.net:127.0.0.1`) проходит — установщик пробует обновить канал PECL (`pecl channel-update … || true`),
  ошибку пропускает, установка из локальных папок сеть не трогает; неверная сумма останавливает сборку
  («pcov.tar.gz: FAILED»).
- **Кеш слоёв Docker в CI не добавлял:** после отказа от PECL сборка образа зависит от GitHub, Alpine CDN и Docker Hub,
  как и раньше; кеш (buildx + кеш GitHub Actions) — заметное усложнение `make e2e` в CI ради ~1,5 мин. Если сбои
  повторятся на других источниках — отдельной задачей.
- **Сверка с PECL** (вопрос аудитора — суммы взяты «с первого скачивания»): пакеты PECL `redis-6.3.0.tgz`
  и `pcov-1.0.12.tgz` (pecl.php.net снова отвечал 504 — взяты с зеркала исходников Alpine, sha512 совпал с рецептами
  Alpine `php84-pecl-redis` и `php84-pecl-pcov`) совпадают с деревьями коммитов GitHub файл в файл: redis — 63 файла
  (вместе с liblzf), pcov — 25, отличий нет.
- **Что ещё качает сборка:** по логу сборки — только эти три архива и пакеты Alpine (zstd и lz4 — из apk); установщик
  пробует обновить канал PECL, ошибку пропускает.
- `make lint`, `make test` (на новом образе: backend 1490, покрытие через pcov — 86,3 %), `make e2e` — 89/89.
- Документы: ADR-0001 («Изменения»), runbook (раздел 12 — сбой проверки суммы и как обновить redis или pcov),
  CLAUDE.md (ловушка).
