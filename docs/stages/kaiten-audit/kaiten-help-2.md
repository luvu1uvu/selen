## 1. Автоматизации и бизнес-правила

### Модуль «Автоматизация» (общее)
- **Модуль автоматизаций пространства** — правило «Когда (триггер) → и если (доп. условия) → Выполнить (одно или несколько действий)»; создаётся отдельно для каждого пространства, окно открывается значком «А» на правой панели пространства; вкладки «Создать», «Управление», «Кнопки», «Шаблонные чек-листы». [FAQ](https://faq-ru.kaiten.site/kak-avtomatizirovat-rabotu-v-kaiten) (на всех тарифах: без платного модуля лимит 5 автоматизаций на компанию на «Старт», 15 — на «Стандарт»/«Бизнес»; с модулем — без лимита)
- **Кто настраивает** — создают и меняют администраторы и редакторы пространства; удаляет только администратор пространства. [FAQ](https://faq-ru.kaiten.site/upravlenie-sozdannymi-avtomatizaciyami)
- **Условия проверяются в момент триггера** — если поле/тип добавили после события, правило не сработает; действия внутри одной автоматизации выполняются в произвольном порядке (рекомендация — одно действие на автоматизацию, если порядок важен). [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)
- **Автоматические действия не подчиняются «Ограничениям»** — запреты модуля «Ограничения» на автоматизации не распространяются, кроме автоматизаций по кнопке (кнопка = ручное действие пользователя). [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)

### Триггеры (событие «Когда»)
- **Карточка перемещена или создана в / создана в / перемещена в** — с указанием доски, колонки, дорожки. [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)
- **Добавлен комментарий / участник / ответственный** — срабатывает на добавление в карточку. [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)
- **Тип карточки изменён / Состояние карточки изменено** — состояние: запланирована → в работе → завершена (можно указать переход). [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)
- **Поле изменено / Срок изменён** — с условием «Изменённое поле» и конкретным значением (в т. ч. «установлено значение из списка / не из списка»). [FAQ](https://faq-ru.kaiten.site/primery-avtomatizaciy)
- **Добавлена / удалена метка**. [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)
- **Управление проектами Ресурсного планирования** — триггер на изменение проекта карточки. [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)
- **Пункт чек-листа выполнен / Все чек-листы выполнены**. [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)
- **Карточка заблокирована / разблокирована / Добавлена блокировка**. [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)
- **Изменено состояние дочерних задач** — с уточнением «изменилось расположение дочерних задач». [FAQ](https://faq-ru.kaiten.site/primery-avtomatizaciy)
- **Карточка является заявкой / автор заявки принадлежит к одной из организаций** — для Службы поддержки. [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)
- **Выполнены все условия** — составной триггер: срабатывает, когда набор условий выполнен в любом порядке. [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)

### Дополнительные условия («и если»)
- **Условия-фильтры** — расположение карточки, состояние, тип, метка, значение поля (в т. ч. поле «Голосование», «больше/меньше» для числовых полей), размер, сервис (Служба поддержки), статус блокировки, изменение в дочерних задачах, конкретный пункт чек-листа/участник/ответственный, организация автора заявки. [FAQ](https://faq-ru.kaiten.site/primery-avtomatizaciy)
- **Логика И / ИЛИ с вложенными группами** — кнопки «+ И» / «+ ИЛИ», группы условий со своей логикой (раньше требовалось несколько правил). [FAQ](https://faq-ru.kaiten.site/usloviya-v-avtomatizaciyah-cherez-i-i-ili) (облако; в API новый формат `conditions`)

### Действия («Выполнить»)
- **Пользователи** — назначить / снять ответственного (в т. ч. «автора события»), добавить / удалить участников, добавить группу пользователей. [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)
- **Поля карточки** — изменить тип, добавить поле, изменить значение (числового) поля, добавить поле в дочерние карточки, добавить размер, изменить срочность, установить/удалить срок и «напоминание о сроке», редактировать описание. [FAQ](https://faq-ru.kaiten.site/primery-avtomatizaciy)
- **Игнорировать автоматические корректировки плановых сроков** — отключает автосдвиг дат Ганта для карточки. [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)
- **Метки и комментарии** — добавить/удалить метки, добавить комментарий (текст задаётся в правиле). [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)
- **Перемещение** — переместить в указанное место (доска/колонка/дорожка в пределах доступного пространства), переместить в пределах доски (вверх колонки, в «Готово»), переместить в архив. [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)
- **Связи** — создать карточку, создать дочернюю, создать родительскую, добавить родительскую карточку. [FAQ](https://faq-ru.kaiten.site/sozdanie-avtomaticheskih-pravil)
- **Прочее** — отметить все пункты всех чек-листов, «Автосортировка»/отсортировать карточки в колонке, добавить шаблонный чек-лист, добавить или удалить SLA, привязать или изменить сервис Службы поддержки. [FAQ](https://faq-ru.kaiten.site/primery-avtomatizaciy)
- **«Создать карточку» (без связи)** — название с автоподстановкой `{{card.title}}`, путь исходной или любой другой, «Скопировать из исходной карточки» (описание, метки), доп. поля. [FAQ](https://faq-ru.kaiten.site/deystvie-sozdat-kartochku-v-avtomatizaciyah)
- **Автоподстановка полей в комментарий** — в действии «Добавить комментарий» блок «Поля для автоподстановки» (название, ID, любые поля); комментарий публикует Automation bot. [FAQ](https://faq-ru.kaiten.site/peredacha-znacheniy-poley-kartochki-v-kommentarii)
- **Заполнение поля «Пользователь»** — конкретным сотрудником, автором события, заказчиком карточки, случайным участником пространства или человеком из списка (балансировка назначений). [FAQ](https://faq-ru.kaiten.site/avtomatizaciya-zapolnenie-kastomnyh-poley-s-tipom-polzovatel)
- **Сроки со смещением** — «Установить срок» / дата-поле: точная дата или «через N дней/часов/минут после события»; «Добавить Timeline» — плановые начало и конец относительно события. [FAQ](https://faq-ru.kaiten.site/novoe-deystvie-dobavit-timeline-v-avtomatizaciyah)
- **Управление проектами РП** — добавить в проект / удалить из проекта / из всех проектов (по событию, кнопке или переходу Workflow); ошибка «Проект не найден» пишется в журнал. [FAQ](https://faq-ru.kaiten.site/upravlenie-proektami-cherez-avtomatizacii) (модуль «Гант и РП» + право «Ресурсное планирование»)
- **Наследование полей при создании родителя/ребёнка** — поля исходной карточки копируются в созданную связанную. [FAQ](https://faq-ru.kaiten.site/novoe-v-avtomatizaciyah-nasledovanie-i-dobavlenie-poley-pri-sozdanii-roditelskih-i-dochernih-kartochek)

### Управление автоматизациями
- **Переименование, редактирование** — меню «три точки» у автоматизации на вкладке «Управление». [FAQ](https://faq-ru.kaiten.site/upravlenie-sozdannymi-avtomatizaciyami)
- **Копирование внутри пространства** — открывает форму создания с заполненными полями. [FAQ](https://faq-ru.kaiten.site/upravlenie-sozdannymi-avtomatizaciyami)
- **«Копировать в» другое пространство** — переносится и включается сама; если в настройках есть недоступные в новом пространстве доска/пользователь — копия «с поломкой», не активна, Kaiten подсвечивает, что исправить, активировать вручную. [FAQ](https://faq-ru.kaiten.site/upravlenie-sozdannymi-avtomatizaciyami)
- **Деактивация / активация** — приостановить без удаления. [FAQ](https://faq-ru.kaiten.site/upravlenie-sozdannymi-avtomatizaciyami)
- **Порядок выполнения** — перетаскивание в списке: верхнее правило выполняется первым и может влиять на последующие (только для автоматизаций по событию). [FAQ](https://faq-ru.kaiten.site/upravlenie-sozdannymi-avtomatizaciyami)
- **API автоматизаций** — ресурс Automations в REST API. [API](https://developers.kaiten.ru/)

### Автоматизации по времени
- **Триггер по дате** — относительно срока карточки, срока пункта чек-листа или пользовательского поля типа «Дата»; варианты: срок наступил / наступил день срока / до срока осталось N / срок прошёл (+ время суток или интервал). [FAQ](https://faq-ru.kaiten.site/avtomatizacii-po-vremeni)
- **Однократность и часовой пояс** — для каждой карточки/пункта срабатывает один раз; срок без времени = 00:00 (т. е. «за 1 час до» сработает в 23:00 накануне); часовой пояс задаётся в настройках автоматизации. [FAQ](https://faq-ru.kaiten.site/avtomatizacii-po-vremeni)

### Кнопки ⚡ (ручной запуск)
- **Кнопки автоматизаций в карточке** — создаются на вкладке «Кнопки» (название + набор действий); в карточке значок молнии с «А» открывает список кнопок пространства; действия выполняются в карточке или связанных карточках (пример: метка + создать дочернюю). На кнопки действуют «Ограничения». [FAQ](https://faq-ru.kaiten.site/knopki-dlya-avtomatizaciy-v-kartochkah)

### Шаблоны и расписание
- **Шаблонные чек-листы** — раздел «Автоматизации → Шаблонные чек-листы»: шаблон (название + пункты) добавляется действием автоматизации «Добавить шаблонный чек-лист» при условии (напр., карточка попала в колонку); можно запретить перемещение, пока пункты шаблонного чек-листа не выполнены. [FAQ](https://faq-ru.kaiten.site/shablonnye-chek-listy-avtomaticheskoe-dobavlenie-v-kartochki)
- **Запланированные задачи (повторяющиеся карточки)** — значок циферблата на правой панели пространства: шаблон карточки (метки, участники, чек-листы, внешние ссылки, размер, срок — точная дата или «N дней после создания») + расписание: ежедневно с интервалом в днях, еженедельно по дням недели, ежемесячно по числам (квартал/год — «ежедневно» с интервалом 90/365); вкладка «История» — когда и где созданы карточки; при удалённой доске задание остаётся с пометкой «доска недоступна». [FAQ](https://faq-ru.kaiten.site/zaplanirovannye-zadaniya-sozdanie-kartochek-po-raspisaniyu) (создают редакторы/админы пространства или кастомная роль с правом создавать карточки и редактировать пространство)

### Правила доски и колонок (вне модуля, бесплатно)
- **Автоназначение создателя** — карточка, созданная сразу в колонке «В работе»/«Готово», получает автора как участника и ответственного (по умолчанию). [FAQ](https://faq-ru.kaiten.site/avtomaticheskoe-naznachenie-ispolniteley-i-otvetstvennogo)
- **Автоназначение автора перемещения** — доска → «⋯» → «Правила» → «Автоматически назначать автора перемещения…»: кто перенёс из «Очереди» в «В работе»/«Готово», становится исполнителем (и ответственным, если его не было). [FAQ](https://faq-ru.kaiten.site/avtomaticheskoe-naznachenie-ispolniteley-i-otvetstvennogo)
- **Автодвижение родителя по детям** — «Правила» доски → «Автоматически передвигать карточки в зависимости от статуса дочерних задач»: одна дочерняя в работе → родитель в «В работе»; все дочерние готовы (и все пункты чек-листа родителя) → родитель в «Готово»; опция «Разрешить автоматическое обратное возвращение»; требует колонок трёх типов в порядке Очередь→В работе→Готово; на доске детей можно отключить правило «двигать родителя в Готово». [FAQ](https://faq-ru.kaiten.site/avtomaticheskoe-peredvizhenie-svyazannyh-kartochek)
- **Автоархивация** — у колонок типа «Очередь» и «Готово»: «⋯» колонки → включить, указать срок пребывания; не архивируются заблокированные, с активными связями и публично доступные карточки. [FAQ](https://faq-ru.kaiten.site/avtomaticheskaya-arhivaciya-kartochek)
- **Скрытие давно не двигавшихся карточек** — у колонки любого типа: «⋯» → «Скрыть карточки, которые долго не двигались» + срок; кнопка «Показать скрытые карточки» показывает их с оранжевой подсветкой; заблокированные/блокирующие не скрываются. [FAQ](https://faq-ru.kaiten.site/kak-skryt-kartochki-kotorye-dolgo-ne-dvigalis)
- **Приостановка учёта SLA в колонке** — правило колонки «приостановить учёт времени по SLA» (ожидание подрядчика/согласования). [FAQ](https://faq-ru.kaiten.site/f3e1331a-a27a-4905-be09-858e10270c8b)

### Модуль «Ограничения» (запреты)
- **Ограничения** — правило «Если (условия) → запрет на перемещение или на создание карточки» на уровне пространства для всех пользователей; кнопка «Ограничения» на правой панели пространства, вкладки «Создать ограничение» / «Управление» (деактивация, удаление, «Создать копию», «Копировать в» другое пространство); при нарушении показывается текст ошибки. [FAQ](https://faq-ru.kaiten.site/27886468-0d61-4a2c-bca4-99b1dbe425ef) (бесплатно до 5 на компанию; «Стандарт»/«Бизнес» — 15 без модуля; с модулем — без лимита; в «Корпорации» включён; создают админы/редакторы пространства, удаляет админ)
- **Условие «Тип карточки»** — в списке / не в списке (пример: тип «Дизайн» нельзя перенести на доску маркетинга). [FAQ](https://faq-ru.kaiten.site/27886468-0d61-4a2c-bca4-99b1dbe425ef)
- **Условие «Предыдущий путь карточки»** — запрет, если карточка (не) была на этапе (нельзя в «Готово» в обход согласования). [Блог](https://kaiten.ru/blog/oghranichieniia-dlia-raboti/)
- **Условие «Значение поля»** — конкретное значение или пустое (обязательное поле при переходе). [FAQ](https://faq-ru.kaiten.site/27886468-0d61-4a2c-bca4-99b1dbe425ef)
- **Условие «Проект карточки» (Ресурсное планирование)** — в списке / не в списке / любой / не установлен; нужно право «Ресурсное планирование». [FAQ](https://faq-ru.kaiten.site/27886468-0d61-4a2c-bca4-99b1dbe425ef)
- **Условие «Учёт времени»** — в карточке нет записей времени (можно указать роль, чьи записи не учитываются): нельзя завершить без списания часов. [FAQ](https://faq-ru.kaiten.site/27886468-0d61-4a2c-bca4-99b1dbe425ef)
- **Условие «Количество связанных карточек»** — минимум дочерних/родительских. [FAQ](https://faq-ru.kaiten.site/27886468-0d61-4a2c-bca4-99b1dbe425ef)
- **Условие «Чек-листы» / «Шаблонный чек-лист»** — не выполнены все пункты. [FAQ](https://faq-ru.kaiten.site/27886468-0d61-4a2c-bca4-99b1dbe425ef)
- **Жёсткий WIP-лимит** — превышение WIP-лимита доски/колонки/дорожки/ячейки физически запрещает перенос (без ограничения лимит только подсвечивает колонку оранжевым); исключения по доскам/колонкам/дорожкам/ячейкам, «Готово» не проверяется. [FAQ](https://faq-ru.kaiten.site/27886468-0d61-4a2c-bca4-99b1dbe425ef)
- **Условие «Дочерние карточки не завершены»** — родителя нельзя в «Готово», пока открыты дети. [FAQ](https://faq-ru.kaiten.site/27886468-0d61-4a2c-bca4-99b1dbe425ef)
- **Условие «Статус блокировки»** — заблокирована / блокирует / заблокирована другими карточками. [FAQ](https://faq-ru.kaiten.site/27886468-0d61-4a2c-bca4-99b1dbe425ef)
- **Условие «Изменяется состояние карточки»** — только для перемещения: запланирована / в работе / завершена. [FAQ](https://faq-ru.kaiten.site/27886468-0d61-4a2c-bca4-99b1dbe425ef)
- **Планы: ограничение на изменение карточки** — правки только ответственным (анонсировано в блоге, не реализовано на момент статьи). [Блог](https://kaiten.ru/blog/oghranichieniia-dlia-raboti/)

### Workflow (схема переходов)
- **Workflow пространства** — схема этапов (этап = доска+колонка+дорожка) со стрелками разрешённых переходов; перенос вне схемы — ошибка, карточка возвращается назад; включается/выключается на пространстве. [FAQ](https://faq-ru.kaiten.site/chto-takoe-workflow) (только с платным модулем Канбан или Скрам; доступ — только кастомная роль с правом «Workflow» в разделе «Пространства», стандартный «Администратор» значка не видит)
- **Workflow аккаунта (шаблоны)** — админраздел «Workflow» → «Добавить Workflow»: шаблон этапов для всей компании, доступен в пространствах через панель Workflow → «Реестр»; можно создать пространство из Workflow (с досками). [FAQ](https://faq-ru.kaiten.site/kak-sozdat-workflow-dlya-vsego-akkaunta)
- **Переход из любого этапа** — опция этапа «Разрешить переходы из любого этапа» (для «Отменено», «Отклонено»); на схеме — подпись «Любой этап». [FAQ](https://faq-ru.kaiten.site/kak-razreshit-perehod-iz-lyubogo-etapa)
- **Блок Workflow в карточке** — показывает текущий этап и кнопки следующих разрешённых этапов (выпадающий список при нескольких); обычной кнопки «в следующую колонку» нет; порядок кнопок задаётся перетаскиванием в редакторе («Порядок переходов»). [FAQ](https://faq-ru.kaiten.site/upravlenie-kartochkami-v-workflow)
- **Ограничения на переходах** — на стрелке → «Настройки» → «Ограничения»: условие (пустой срок, невыполненный чек-лист и т. п.) + свой текст ошибки; на этапе появляется значок замка. [FAQ](https://faq-ru.kaiten.site/ogranicheniya-v-workflow)
- **Автоматизации на переходах** — на стрелке → «Автоматизации»: действия при переходе (назначить ответственного, добавить чек-лист, обновить поля), учитываются исходный/целевой этап и тип карточки; переход помечается молнией. [FAQ](https://faq-ru.kaiten.site/avtomatizaciya-v-workflow)

### SLA и сроки по колонкам
- **SLA (Служба поддержки)** — правила «Время первой реакции», «Время выполнения», «Время нахождения на этапе» (колонка входа → колонка выхода, напр. 4 ч на тестирование) + рабочий календарь (без календаря 24/7); SLA назначается вручную в карточке или автоматизацией «Добавить SLA». [FAQ](https://faq-ru.kaiten.site/f3e1331a-a27a-4905-be09-858e10270c8b)
- **Таймеры SLA в карточке и на фасаде** — оставшееся время по каждому правилу, нарушенные — красным; значок на фасаде серый/красный; кнопка «правила» показывает все таймеры; набор таймеров на фасаде — в персональном виде карточек. [FAQ](https://faq-ru.kaiten.site/f3e1331a-a27a-4905-be09-858e10270c8b)
- **Пересчёт SLA** — автоматический при смене календаря/правил для карточек в «Очереди» и «В работе»; для завершённых — кнопка «Пересчитать время». [FAQ](https://faq-ru.kaiten.site/f3e1331a-a27a-4905-be09-858e10270c8b)
- **SLA в API** — ресурс Card SLA (привязка SLA к карточке). [API](https://developers.kaiten.ru/)

## 2. Отчёты и аналитика

### Общее
- **Раздел «Отчёты» пространства** — в верхней панели пространства; отчёты строятся по доскам пространства с фильтрами в правой панели и кнопкой «Показать». [FAQ](https://faq-ru.kaiten.site/7c7e2a0e-280c-488b-b4af-467402fa4960) (CFD, контрольный график, спектральная, время блокировок, пропускная способность — модуль «Канбан»; burndown/velocity — модуль «Скрам»; на «Старт» — отчёты Канбан/Скрам включены, на бесплатном нет отчёта по завершённым задачам и распределения карточек [Тарифы](https://kaiten.ru/tariffs))
- **Выгружаемые форматы** — xlsx, png, jpeg, pdf, svg; выгрузка есть у досок, списков, таблицы, таймлайна, отчётов, архива, заявок, учёта времени; в мобильном — только доски и списки. [FAQ](https://faq-ru.kaiten.site/vygruzka-i-eksport-dannyh)

### Отчёты потока (Канбан)
- **Накопительная диаграмма потока (CFD)** — число карточек (или сумма размеров) на каждом этапе во времени; период: последний час поминутно / 7 / 14 дней / месяц / 3 месяца / свои даты; несколько досок (своя цветная область), выбор дорожек и колонок, фильтры по меткам (логика «И»), типам, «только срочные», «Зоны» (отрезок процесса), «Показать тренд» (две линии → прогноз даты завершения), разбивка по типам при наведении; клик по легенде скрывает этап. Подколонки не учитываются (для них — зоны). [FAQ](https://faq-ru.kaiten.site/nakopitelnaya-diagramma-potoka-cfd)
- **Время цикла (Cycle time)** — столбец на каждую задачу, сегменты по этапам, легенда — среднее время на этапе; начальная/конечная колонка, типы, метки, «только рабочие дни», исключение конкретных дат; в отчёт попадают только карточки, прошедшие весь выбранный путь. [FAQ](https://faq-ru.kaiten.site/vremya-cikla-cycle-time)
- **Контрольный график (Control chart)** — точка = задача (ось Y — дни, цвет — тип); начало пути (точка принятия обязательств, первое попадание) и конец пути (последнее попадание), «SLA» в днях — красная линия с % задач, уложившихся в срок; «Без размера», типы, метки; клик по точке открывает карточку. [FAQ](https://faq-ru.kaiten.site/kontrolnyy-grafik-control-chart)
- **Спектральная диаграмма (Spectral chart)** — гистограмма распределения времени выполнения: период, начало/конец пути, «Шаг» (дней в столбце), два перцентиля (напр., 50 и 85), дорожки, размеры, типы, метки, «не пропускать пустые значения по X», «Показать распределение Вейбулла» (коэффициенты детерминации, формы, масштаба); синяя линия — среднее, красная — перцентиль; клик по столбцу — список карточек. [FAQ](https://faq-ru.kaiten.site/spektralnaya-diagramma-spectral-chart)
- **Динамика времени цикла (Cycle time trends)** — среднее/медиана/перцентиль времени выполнения по периодам (неделя/месяц/3/6 мес.); несколько колонок начала/конца (с дорожками); разделение по дорожкам, типам, размеру, заказчикам, ответственным, пользовательским полям (кроме мультиселекта и многострочной строки); «только срочные». [FAQ](https://faq-ru.kaiten.site/dinamika-izmeneniy-vremeni-cikla-cycle-time-trends)
- **Пропускная способность (Throughput)** — число (или размер) завершённых карточек по неделям/месяцам за 1 нед.–6 мес.; начальная/конечная колонка; группировка по типу, дорожке (класс обслуживания), размеру, ответственному, заказчику, меткам, пользовательским полям; карточка, заархивированная не из «Готово», выпадает. [FAQ](https://faq-ru.kaiten.site/propusknaya-sposobnost-throughput)
- **Время разрешения блокировок (Block resolution time)** — суммарное время блокировки каждой задачи за период, причина и карточка при наведении; «Скачать отчёт» в Excel. [FAQ](https://faq-ru.kaiten.site/vremya-razresheniya-blokirovok-block-resolution-time)
- **Распределение карточек (Cards distribution)** — текущее распределение по владельцу (заказчику), ответственному, участнику, колонкам, размерам, меткам, типам, выполнению в срок; фильтры: доски/колонки/дорожки, включать архивные, только срочные. [FAQ](https://faq-ru.kaiten.site/raspredelenie-kartochek-cards-distribution)
- **Сроки по задачам (Due dates)** — переключатель «сроки карточек / сроки пунктов чек-листов»; диаграммы «выполнено в срок / с опозданием / не выполнено в срок / ожидает», распределение по ответственным, прогресс; таблица со ссылками (сортировка по сроку); фильтры: доски, период выполнения, ответственный, тип, метки, дата срока; сегменты кликабельны. [FAQ](https://faq-ru.kaiten.site/sroki-po-zadacham-due-dates)
- **Суммарный отчёт** — завершённые (в колонке «Готово») задачи за период по выбранным доскам с группировкой по типу/меткам/ответственному/участникам, колонка «Суммарное время» и суммы формульных полей; «Скачать» в xlsx (время в минутах). [FAQ](https://faq-ru.kaiten.site/summarnyy-otchet)

### Итерации / Scrum
- **Итерация — график сгорания (Burndown)** — по количеству карточек (осталось, идеальная линия, завершённые, добавленные, удалённые) и по размеру (story points); итоги «Запланировано / Выполнено / Добавлено / Удалено / Взято в итерацию / Скорость»; круговые диаграммы по типам и дорожкам; точка = состояние на конец дня в часовом поясе пользователя; «Скачать отчёт» в Excel; у завершённой итерации меню «Редактировать» (название, цель) / «Удалить» (только админ, необратимо). [FAQ](https://faq-ru.kaiten.site/burndown-chart-grafik-sgoraniya-iteracii) (спринты заменены итерациями с 01.10.2026)
- **Velocity (скорость команды)** — story points, закрытые за итерацию (значение из отчёта «Итерация — график сгорания»). [FAQ](https://faq-ru.kaiten.site/velocity-skorost-komandy)
- **Диаграмма сгорания дочерних задач** — в родительской карточке, раздел «Связи» → режим «Диаграмма сгорания»: остаток дочерних (по количеству или размеру) и добавленная работа, дата отсчёта настраивается; две линии тренда → прогноз даты завершения с учётом и без учёта новых задач; учитываются только «листовые» дети. [FAQ](https://faq-ru.kaiten.site/diagramma-sgoraniya-dochernih-zadach)

### Продажи
- **Воронка продаж** — по одной или нескольким доскам (объединяются в одну воронку): конверсия между этапами, потери, среднее время до успеха; колонки «успех» и «проигрыш», числовое поле суммы (напр. «Бюджет»), фильтры: период первого входа, типы, метки, дорожки, ответственный; блок по сотрудникам; настройки запоминаются для пространства; «Экспорт» в xlsx и csv. [FAQ](https://faq-ru.kaiten.site/voronka-prodazh)

### Трудозатраты (модуль «Учёт времени»)
- **Отчёт о вашем затраченном времени** — «Личное» → «Учёт времени»: табель «задачи × дни» с колонками «План» (из Ресурсного планирования, серым) и «Факт»; итоги; период неделя/месяц/свои даты; можно добавлять и править свои записи прямо в ячейках; экспорт в Excel. [FAQ](https://faq-ru.kaiten.site/otchet-o-vashem-zatrachennom-vremeni) (модуль «Учёт времени»)
- **Отчёт о затраченном времени сотрудников** — админраздел «Учёт времени»: записи всех пользователей, фильтры пространства/люди/доски/метки/период, группировка по карточкам или пользователям, выгрузка (значок облака). [FAQ](https://faq-ru.kaiten.site/7c7e2a0e-280c-488b-b4af-467402fa4960) (доступ — право админраздела «Учёт времени»)
- **Колонка «Суммарное время»** — в виде «Таблица», суммарном отчёте и архиве. [FAQ](https://faq-ru.kaiten.site/1e167b1a-f494-410e-96da-afc1b7e258d2)
- **Почасовая оплата через формулу** — поле «Число» со ставкой + поле «Формула» `prop("time_spent_sum")/60 * ставка`, итог — в суммарном отчёте. [FAQ](https://faq-ru.kaiten.site/8f269004-12bf-4209-8bb4-1fb2a0527776)

### Служба поддержки и SLA
- **Дашборд службы поддержки** — заявки по этапам (типам колонок) за период, среднее время ожидания (реакция) и в работе (решение), фильтр по сервису. [FAQ](https://faq-ru.kaiten.site/b83d031f-3f84-4da0-93ae-6aee00dcfe5c)
- **Статистика заявок** — динамика открытых/закрытых по месяцам, выполненные по ответственным, созданные по сервисам, время выполнения по месяцам (функция/перцентиль); экспорт. [FAQ](https://faq-ru.kaiten.site/b83d031f-3f84-4da0-93ae-6aee00dcfe5c)
- **Статистика по SLA** — график соответствия SLA, клик по столбцу → таблица заявок с нарушениями; фильтры: SLA, «Нарушено правило», исполнитель, сервис, период завершения; учитывает календари; «Скачать» (время в минутах). [FAQ](https://faq-ru.kaiten.site/f3e1331a-a27a-4905-be09-858e10270c8b)
- **Детальная аналитика SLA в API** — отдельные данные SLA по карточкам через API (новость окт. 2025). [FAQ](https://faq-ru.kaiten.site/detalnaya-analitika-sla-v-api-kaiten)

### Дашборды
- **Дашборды компании** — раздел «Дашборды» в левой панели → «Новый дашборд» (название, флажок «публичный»); виджеты по карточкам из нескольких пространств: «Список карточек», «Счётчик» (кол-во или сумма размера / времени / числового поля), «Распределение карточек» (по типу/пространству/полю; таблица, столбцы, круговая), «Динамика по времени» (по неделям); перетаскивание и изменение размера виджетов. [FAQ](https://faq-ru.kaiten.site/dashbordy) (тариф «Корпорация А+» с экспериментальными функциями, в облаке у всех; on-premise с версии 58.82.19)
- **Фильтры дашборда** — фильтр виджета по состоянию (любое/активные/архивные), общий фильтр на все виджеты, сохранённые наборы фильтров (доступны редакторам). [FAQ](https://faq-ru.kaiten.site/dashbordy)
- **Доступ к дашборду** — роли «Читатель» и «Редактор» (меняет виджеты, приглашает, но не удаляет); удаляет/передаёт только владелец; каждый видит цифры только по доступным ему данным; администрирование чужих дашбордов — право «Администрирование Дашбордов» (пользователю или группе). [FAQ](https://faq-ru.kaiten.site/dashbordy)
- **Копирование виджетов** — в свой или другой дашборд (где вы владелец/редактор) вместе с фильтрами. [FAQ](https://faq-ru.kaiten.site/dashbordy)
- **Обновление данных раз в час** — у виджета время последнего пересчёта и кнопка ручного обновления. [FAQ](https://faq-ru.kaiten.site/dashbordy)

## 3. Документы и базы знаний

### Структура и доступ
- **Документы в дереве** — документы и папки в общем дереве (в корне или внутри пространства/папки/Story map), неограниченная вложенность, порядок — перетаскиванием, иконки и эмодзи в названиях. [FAQ](https://faq-ru.kaiten.site/papki-i-sortirovka-dokumentov) (бесплатно на всех тарифах, кроме гостей)
- **Роли в документе** — Администратор (права, удаление), Редактор (создать, править, поделиться ссылкой), Комментатор (просмотр, копирование, комментарии — роль по умолчанию); удалить документ может только администратор (даже автор — нет); кастомные роли — с модулем «Группы». [FAQ](https://faq-ru.kaiten.site/kak-nastroit-dostup-k-dokumentu)
- **Уровень доступа** — «Только приглашённые» (по умолчанию) или «Все пользователи в компании (кроме гостей)» с общей ролью; отдельным людям можно поднять роль. [FAQ](https://faq-ru.kaiten.site/kak-nastroit-dostup-k-dokumentu)
- **Наследование** — права папки распространяются на содержимое («права папки всегда главнее», перенос личного документа в общую папку открывает его); действует максимальная роль; документы внутри пространства/Story map наследуют её участников и роли. ## 4. Продвинутые виды и методологии

### Workflow, Канбан-модуль
- **Модуль «Канбан»** — WIP-лимиты, подколонки, дорожки, отметки об устаревании карточек в колонке, отчёты потока (CFD, контрольный, спектральная, время блокировок, пропускная способность); с ним открывается Workflow. [Тарифы](https://kaiten.ru/tariffs) (+80 ₽/лиц./мес. сверх включённых модулей; на «Старт» включён)
- **FIFO** — не отдельная кнопка, а связка: автоматизация «карточка создана/перемещена → сортировать по дате создания / в конец колонки» + номера очереди в колонке пересчитываются; срочные — в отдельной дорожке. [FAQ](https://faq-ru.kaiten.site/fifo)
- **Динамические доски** — в пространстве «+» → «Динамическая доска»: только просмотр, карточки собираются из разных пространств по общим условиям (И/ИЛИ) и правилам колонок/дорожек (все фильтры досок, включая Service Desk, источники, вложенность); колонка «Оставшиеся карточки»; до 100 карточек на колонку/дорожку; автообновление каждые 60 с; открываются как Списки/Таблица/Таймлайн/Календарь; перетаскивать и создавать нельзя. [FAQ](https://faq-ru.kaiten.site/dinamicheskie-doski-2) (только «Корпорация» или on-premise, включить экспериментальные функции)

### Scrum и итерации
- **Модуль Scrum** — шаблон досок «Скрам» (доска бэклога + доска итерации), story points (в очках, часах или размерах маек), burndown, velocity. [FAQ](https://faq-ru.kaiten.site/skram-v-kaiten-chto-eto-i-kak-rabotaet) (на «Старт» включён, на «Стандарт»/«Бизнес» — модуль)
- **Итерации (вид пространства)** — вкладка «Итерации» в верхней панели пространства: слева бэклог «Нераспределённые задачи», справа список итераций (название обязательно, даты и цель — до запуска); итерация охватывает всё пространство, можно вести несколько одновременно; переупорядочивание списка. [FAQ](https://faq-ru.kaiten.site/novyy-vid-prostranstva-iteracii) (спринты на досках с 01.10.2026 создавать нельзя — только итерации)
- **Планирование итерации** — перетаскивание из бэклога/между итерациями, массовый выбор (Shift-диапазон, группа), «Добавить в итерацию» до 500 задач за раз, «Убрать из итерации» с отменой; поле «Итерация» в карточке. [FAQ](https://faq-ru.kaiten.site/novyy-vid-prostranstva-iteracii)
- **Доски, участвующие в итерациях** — при запуске в итерацию автоматически попадают все активные карточки отмеченных досок, а также созданные на них во время итерации; ушедшие с доски/архивированные незавершёнными выпадают; такую доску нельзя удалить/архивировать/перенести. [FAQ](https://faq-ru.kaiten.site/novyy-vid-prostranstva-iteracii)
- **Запуск и «Взято в итерацию»** — «Начать итерацию» (обязательна дата окончания), фиксируется объём на старте; панель «Активные итерации» над досками/списками/таблицей/таймлайном/календарём фильтрует пространство; плашка итерации на фасаде (зелёная — активная, серая — запланированная). [FAQ](https://faq-ru.kaiten.site/novyy-vid-prostranstva-iteracii)
- **Завершение итерации** — окно с выполненными/незавершёнными, перенос незавершённых в «Незапланированные», новую или запланированную итерацию; завершение в фоне со статусами «Завершается…» / «Не удалось завершить». [FAQ](https://faq-ru.kaiten.site/novyy-vid-prostranstva-iteracii)
- **Завершённые итерации** — раздел с группировкой по месяцам и поиском, «Сводка по карточкам» (были на старте / добавлены / удалены / выполнены) и «Хронология» событий; редактирование названия и цели. [FAQ](https://faq-ru.kaiten.site/novyy-vid-prostranstva-iteracii)
- **История итераций карточки** — «⋯» карточки → «Итерации»: дата, действие, пользователь. [FAQ](https://faq-ru.kaiten.site/istoriya-uchastiya-kartochki-v-iteraciyah)
- **Фильтр «Итерация»** — «это / не / любая / не установлена» в пространствах, дашбордах и виджетах. [FAQ](https://faq-ru.kaiten.site/novyy-vid-prostranstva-iteracii)
- **Права на итерации** — админ — всё, редактор — правка, комментатор — просмотр; в кастомной роли — право «Пространства → Итерации»; удалить итерацию может только Администратор (необратимо, с переносом карточек). [FAQ](https://faq-ru.kaiten.site/novyy-vid-prostranstva-iteracii)
- **Автодобавление карточек с досок в итерации / порядок итераций / несколько задач в итерацию** — обновления сен. 2026. [FAQ](https://faq-ru.kaiten.site/avtomaticheskoe-dobavlenie-kartochek-s-dosok-v-iteracii)
- **API итераций** — ресурс Iterations (BETA); старые Sprints — устаревший. [API](https://developers.kaiten.ru/)

### Timeline, Гант и ресурсное планирование
- **Вид «Timeline» (таймлайн)** — слева таблица карточек (настраиваемые колонки, сортировка до 5 критериев, группировка, сохранение настроек для пространства), справа шкала (часы/дни/недели/месяцы); отрезок создаётся кликом, растягивается и перетаскивается; родитель показывает прогресс по детям, перетаскивание делает карточку дочерней; рабочие дни и часы пространства. [FAQ](https://faq-ru.kaiten.site/vid-prostranstva-timeline-taymlayn) (базовый вид — без модуля; связи и ресурсы — модуль «Гант и РП»)
- **Выгрузка Timeline** — «Скачать» (таблица в браузере) и «Скачать развёрнутый отчёт» (Гант с закрашенными отрезками, ссылка на почту), 13 полей. [FAQ](https://faq-ru.kaiten.site/vid-prostranstva-timeline-taymlayn)
- **Зависимости задач** — протянуть линию от кружка задачи или вписать ID в «Предшествующие/Последующие карточки»; только тип «предшествующая → последующая»; лаг положительный или отрицательный (на стрелке); конфликт сроков — красная связь. [FAQ](https://faq-ru.kaiten.site/posledovatelnost-vypolneniya-zadach-upravlenie-vzaimosvyazyami) (модуль «Гант и Ресурсное планирование»)
- **Автопересчёт по связям** — переключатель «Автоматически обновлять смещения связей»: последующие сдвигаются за предшественником с сохранением длительности и лага; при раннем переносе в «Готово» плановое окончание сдвигается на конец дня (отдельная опция); ручной режим с «Восстановить смещение»; кнопка «Пересчитать сроки по связям» (двигает только карточки в «Очереди»). [FAQ](https://faq-ru.kaiten.site/posledovatelnost-vypolneniya-zadach-upravlenie-vzaimosvyazyami)
- **«Не сдвигать сроки по связям»** — флажок у карточки (или действие автоматизации «Игнорировать автокорректировки плановых сроков»): связь остаётся, сроки закреплены. [FAQ](https://faq-ru.kaiten.site/posledovatelnost-vypolneniya-zadach-upravlenie-vzaimosvyazyami)
- **Проекты (портфель)** — Timeline → режим «Проекты»: проекты не привязаны к пространствам, собирают карточки из любых доступных пространств; поиск по названию/ID, массовые действия «Управление проектами» (добавить/убрать, с детьми); поля проекта — отдельный блок в карточке; настройки проекта главнее настроек пространства. [FAQ](https://faq-ru.kaiten.site/kak-sozdavat-proekty-v-module-gant-i-resursnoe-planirovanie) (менять проект — право «Ресурсное планирование»)
- **Базовые планы** — несколько базовых планов на разные даты; утверждённый — чёрные линии на шкале, отклонения — красным в таблице. [FAQ](https://faq-ru.kaiten.site/kak-sozdavat-proekty-v-module-gant-i-resursnoe-planirovanie)
- **Вехи** — задача с флажком «веха» (ромб, начало = конец), связываются как задачи. [FAQ](https://faq-ru.kaiten.site/kak-sozdavat-proekty-v-module-gant-i-resursnoe-planirovanie)
- **Ресурсное планирование (загрузка людей)** — кнопка «Ресурсное планирование» в Timeline: таблица ресурсов с часами сотрудников по дням, задачи сотрудника из всех пространств, назначение ресурсов на задачу; длительность ≠ трудозатраты. [FAQ](https://faq-ru.kaiten.site/modul-diagramma-ganta1)
- **Три режима расчёта загрузки** — фиксированные трудозатраты (меняется длительность), фиксированная длительность (меняются часы/день, возможна перегрузка; только здесь ручная разбивка по неделям), фиксированные оба (только перераспределение часов). ## 5. Администрирование

### Пользователи и лицензии
- **Админраздел «Пользователи»** — список с фильтрами «Доступ к Kaiten» (участник / гость / запрещён), «Доступ к Службе поддержки», временно деактивированные; карточка пользователя с доступами, правами на админразделы, назначением владельца, передачей прав. [FAQ](https://faq-ru.kaiten.site/polzovateli-administrativnyy-razdel)
- **Приглашение по email** — вкладка «Приглашения» или «Пользователи» на правой панели элемента (+): сразу с доступом к пространству/папке/документу/Story map и ролью; ссылка живёт 7 дней, затем учётка автоматически деактивируется; дневной лимит приглашений (снимает поддержка). [FAQ](https://faq-ru.kaiten.site/15df0dba-5759-4755-901b-57c857a98863)
- **Приглашение коллегами по домену** — опция способа входа «Участники компании могут приглашать друг друга на пространства» + список доменов компании. [FAQ](https://faq-ru.kaiten.site/nastroyki-kompanii-administrativnyy-razdel)
- **Приглашение участника на пространство из карточки / добавление участников без запроса администратору / через запрос** — обновления 2026. [FAQ](https://faq-ru.kaiten.site/priglashenie-kollegi-na-prostranstvo-iz-kartochki)
- **Лицензии** — 1 лицензия = 1 активный участник (не гость); просмотр — фильтр «Участник»; освободить — деактивация или перевод в гости; докупка в «Оплата»; при превышении оплаченного числа система деактивирует лишних. [FAQ](https://faq-ru.kaiten.site/15df0dba-5759-4755-901b-57c857a98863)
- **Деактивация (удаления нет)** — «Доступ к Kaiten» → «Доступ запрещён»: вход закрыт, лицензия освобождается; кнопки удаления пользователя нет; удаление только из пространства лицензию не освобождает. [FAQ](https://faq-ru.kaiten.site/145b0014-dfab-4829-9d4a-e59fe7d578d7)
- **Передача прав доступа** — при деактивации/переводе в гости или кнопкой «Передать права доступа»: «Заменить» (права уходят другому) или «Добавить аналогичные» (оба сохраняют); «Детализация передачи» по каждому элементу и разделу; ответственные/участники переносятся только в активных незавершённых карточках; статус «Завершён/Ошибка» в колонке таблицы. [FAQ](https://faq-ru.kaiten.site/1ab3a1c1-5211-4b1e-b2b6-2df75c2d610d)
- **Временная деактивация** — чекбокс «Временно деактивирован»: мгновенный выход (и из API), лицензия освобождается, назначения/упоминания/история сохраняются, можно продолжать назначать на карточки, доступ к Службе поддержки остаётся; сценарии — отпуск, декрет, вахта (одна лицензия на сменщиков). [FAQ](https://faq-ru.kaiten.site/760bd3de-c7eb-4392-9fc9-a7f07693f434)
- **Деперсонализация (удаление ПДн)** — у пользователя с запрещённым доступом и к Kaiten, и к Службе поддержки кнопка «Деперсонализировать» → ввод email → «Обезличить»: удаляются ФИО, email, имя, аватар, идентификаторы, настройки интеграций; история и комментарии остаются анонимными. [FAQ](https://faq-ru.kaiten.site/kak-udalit-personalnye-dannye-polzovatelya) (только on-premise последней версии)
- **Удаление своего аккаунта** — самому нельзя: деактивация админом или полное удаление ПДн по запросу в поддержку (удаляются имя, email, аватар, часовой пояс; контент остаётся, владение передаётся участникам компаний). [FAQ](https://faq-ru.kaiten.site/udalenie-svoego-akkaunta-polzovatelya)
- **Виртуальные пользователи** — для ресурсного планирования; управление в админразделе «Ресурсное планирование». [FAQ](https://faq-ru.kaiten.site/upravlenie-virtualnymi-polzovatelyami) (модуль «Гант и РП»)
- **Модальное окно с информацией о пользователе** — по клику на пользователя. [FAQ](https://faq-ru.kaiten.site/modalnoe-okno-c-informaciey-o-polzovatele)

### Гости
- **Гостевой пользователь** — бесплатно (без лицензии): видит только элементы, куда добавлен; читает и комментирует карточки, получает уведомления, может быть заказчиком (но не ответственным/участником); не видит общедоступные документы и USM, не входит в группы и «Все пользователи», не создаёт пространства; роль не выше «Комментатора»; значок G. [FAQ](https://faq-ru.kaiten.site/a2cfe62b-55a9-4a77-9251-d1c5a8bd2917) (бесплатный — до 5 гостей, «Старт» — до 15, далее без лимита)
- **Перевод гость ↔ участник** — в карточке пользователя; при переводе в гости — передача прав. [FAQ](https://faq-ru.kaiten.site/a2cfe62b-55a9-4a77-9251-d1c5a8bd2917)
- **Запрет приглашать гостей напрямую** — настройка ролей компании: админы сущностей не могут звать гостей, только через «Пользователи»/«Дерево сущностей». [FAQ](https://faq-ru.kaiten.site/nastroyki-kompanii-administrativnyy-razdel)

### Владелец
- **Владелец аккаунта** — все админразделы и настройки компании, по умолчанию единственный с доступом к журналам, дереву, хранилищу; отдельные рабочие элементы ему могут быть недоступны; удаление аккаунта — только он. [FAQ](https://faq-ru.kaiten.site/vladelec-akkaunta)
- **Передача владения с подтверждением** — в карточке пользователя, с обязательным подтверждением. [FAQ](https://faq-ru.kaiten.site/podtverzhdenie-pri-peredache-prav-vladelca-akkaunta)

### Роли и права
- **Стандартные роли элемента** — Администратор, Редактор, Комментатор (+ Гость); роль назначается на каждый элемент (пространство, папку, документ, Story map) отдельно; стандартные роли не редактируются. [FAQ](https://faq-ru.kaiten.site/kakie-est-roli-polzovateley-v-kaiten)
- **Модификатор «только свои карточки»** — к роли добавляется условие: пользователь видит только карточки, где он участник или владелец (заказчик). [FAQ](https://faq-ru.kaiten.site/modifikator-urovnya-dostupa-k-prostranstvu) (с тарифа «Бизнес»)
- **Настраиваемые роли** — «Пользователи» → «Роли» → «Создать роль» (можно на основе «Комментатора»): блок «Разделы» + настройки для пространств, документов, папок, Story map; флаг «выдавать новые действия по умолчанию»; у группы несколько ролей — права суммируются. [FAQ](https://faq-ru.kaiten.site/7a90694b-428e-4501-99ef-0a066367dbfb) (модуль «Группы пользователей»)
- **Права в кастомных ролях (известные)** — просмотр пространств/досок, редактирование досок, удаление досок и колонок, создание/редактирование/перемещение карточек (в т. ч. запрет перемещения), управление автоматизациями и ограничениями, интеграции, Workflow, Итерации, создание элементов (по видам), перемещение и создание внутри иерархии. [FAQ](https://faq-ru.kaiten.site/ogranichenie-prav-na-peremeshchenie-kartochek-v-nastraivaemyh-rolyah)
- **Скрытие полей карточек ролью** — роль → «Карточки» → «Поля» → «Ограниченный доступ»: снять просмотр конкретных полей (зарплата, стоимость) — скрыты в карточках, таблицах, отчётах; разрешения на доске в нескольких пространствах агрегируются до максимума. [FAQ](https://faq-ru.kaiten.site/nastraivaemye-roli-polzovateley-ogranichenie-na-prosmotr-poley-kartochek)
- **Права на редактирование/удаление конкретных полей** — в роли отметить поля с правом «редактирование»/«удаление»; неотмеченные становятся нередактируемыми, новые поля — закрыты до включения. [FAQ](https://faq-ru.kaiten.site/regulirovanie-dostupa-k-polzovatelskim-polyam)
- **Настройка ролей компании** — вкладка «Настройка ролей»: какие роли доступны для назначения, роли по умолчанию для новых/импортированных сущностей и для гостей. [FAQ](https://faq-ru.kaiten.site/nastroyki-kompanii-administrativnyy-razdel) (модуль «Группы»)
- **Права на админразделы (28 галочек)** — метки, типы карточек, учёт времени, пользователи, нерабочие дни, настройки, оплата, дерево сущностей, журнал событий, календари, дополнения (портал разработчиков), экспорт данных, приглашение в аккаунт, создание пользовательских полей, «Открыть общий доступ к карточке», чтение записей коллег в учёте времени, ресурсное планирование, «Вид карточек», конвертация карточек в заявки, настройки/заявки/аналитика Службы поддержки, журнал аудита, категории блокировки, Workflows, хранилище, External webhooks, администрирование дашбордов. [FAQ](https://faq-ru.kaiten.site/polzovateli-administrativnyy-razdel)
- **Права по умолчанию для новых пользователей** — галочки в «Настройках компании» (на уже добавленных не влияют). [FAQ](https://faq-ru.kaiten.site/nastroyki-kompanii-administrativnyy-razdel)
- **Права на корень меню** — по умолчанию группа «Все пользователи» может создавать и перемещать элементы в корне; право снимается, владелец сохраняет его всегда. [FAQ](https://faq-ru.kaiten.site/2822dc7f-9590-4588-860f-63ca33e3c4da)

### Доступ и наследование
- **Наследование по иерархии** — доступ к верхнему элементу (папке) даёт доступ ко всему вложенному с той же ролью; удаление сверху лишает доступа ко всему ниже; на вложенном элементе роль можно только повысить. [FAQ](https://faq-ru.kaiten.site/regulirovanie-dostupov-k-prostranstvam-papkam-dokumentam-i-story-maps)
- **Уровень доступа элемента** — «Все пользователи (кроме гостей)» с общей ролью или «Только приглашённые». [FAQ](https://faq-ru.kaiten.site/derevo-sushchnostey-administrativnyy-razdel)
- **Перемещение в иерархии** — нужно право перемещения в исходном и создания в целевом элементе, иначе «Недостаточно прав для перемещения»; перенос может изменить доступы. [FAQ](https://faq-ru.kaiten.site/regulirovanie-dostupov-k-prostranstvam-papkam-dokumentam-i-story-maps)
- **«Запросить доступ»** — на закрытом элементе с пояснением; уходит тем, кто может приглашать (и админам сущности — опция компании); выдать роль / отклонить / «исполнено»; новый запрос нельзя, пока не рассмотрен старый; отключаемо. [FAQ](https://faq-ru.kaiten.site/529c07ce-979e-4dc6-9a6d-c4a740a7e599)
- **Публичный доступ к пространствам, папкам и Story Map** — публичные ссылки (в т. ч. с правом редактирования карточек на «Стандарт»+), визуальные значки публичных элементов. [FAQ](https://faq-ru.kaiten.site/publichnyy-dostup-k-prostranstvam-papkam-i-story-map-2)

### Группы
- **Группы пользователей** — «Пользователи» → «Группы»: группа добавляется в пространства/папки/документы/Story maps (вкладка «Сущности») с ролью; опция «Разрешить приглашать группу на пространства, в карточки и фильтрацию»; права на админразделы для группы (вкладка «Настройки»). [FAQ](https://faq-ru.kaiten.site/2822dc7f-9590-4588-860f-63ca33e3c4da) (модуль «Группы пользователей»; на «Стандарт»/«Бизнес» — модуль, от 100 лицензий подключается автоматически)
- **Приоритет групп** — роль в элементе задаёт группа (может понизить личную); права нескольких групп суммируются; доступ ко всем карточкам главнее «только своих». [FAQ](https://faq-ru.kaiten.site/prioritet-dostupov-grupp-nad-vsemi-ostalnymi-dostupami)
- **Администратор группы** — вкладка «Администраторы»: управляет составом своей группы без доступа к разделу «Пользователи». [FAQ](https://faq-ru.kaiten.site/administrator-gruppy-polzovateley)
- **Деактивация групп** — группа выключается без удаления. [FAQ](https://faq-ru.kaiten.site/vozmozhnost-deaktivacii-grupp-polzovateley)
- **Быстрое отключение уволенного** — удаление из всех пространств, досок и карточек за пару кликов. [FAQ](https://faq-ru.kaiten.site/eb605b76-029d-44d9-94d1-6d4a6d20ef68)

### Вход и безопасность
- **Способы входа** — PIN-код на почту (по умолчанию), пароль, «пароль + PIN-код на почту» (2FA), Google Workspace (SAML), LDAP, OpenID Connect (с/без secret: Keycloak, AD на Windows Server 2019); у способа — список доменов. [FAQ](https://faq-ru.kaiten.site/nastroyki-kompanii-administrativnyy-razdel)
- **Двухфакторный вход «пароль + PIN»** — «Настройки компании» → «Добавить способ аутентификации» → «Аутентификация с помощью пароля и PIN-кода на почту», опционально для доменов. [FAQ](https://faq-ru.kaiten.site/dvuhfaktornaya-avtorizaciya-po-parolyu-i-pin-kodu) (в мобильном приложении входа по паролю нет)
- **Multi SSO** — несколько провайдеров с кнопками на странице входа (названия задаёт админ), подсказка кнопки по домену email. [FAQ](https://faq-ru.kaiten.site/multi-sso-directory-user-sync) (модуль «Группы»; в РФ с 01.01.2025 нельзя SSO на доменах иностранных компаний)
- **Отключение стандартной авторизации при SSO** — убрать PIN и пароль со страницы входа. [FAQ](https://faq-ru.kaiten.site/otklyuchenie-standartnoy-avtorizacii-pri-sso-2)
- **Синхронизация с директорией (LDAP/AD)** — автосоздание сотрудников, синхронизация групп (маппинг по UID), деактивация выбывших из выборки (освобождает лицензии), синхронизация аватаров. [FAQ](https://faq-ru.kaiten.site/multi-sso-directory-user-sync)
- **Строгая синхронизация групп** — состав групп по AD, ручная правка запрещена (значок), удалённая в AD группа деактивируется. [FAQ](https://faq-ru.kaiten.site/strogaya-sinhronizaciya-grupp-polzovateley-s-direktoriey)
- **Проверка доступа в директории при входе через SSO** — на вкладке «Синхронизация»: при входе пользователь без доступа в каталоге сразу деактивируется и его сеанс завершается (по `objectFilter`). [FAQ](https://faq-ru.kaiten.site/proverka-dostupa-v-ldap-direktorii-pri-vhode-cherez-sso) (бета)
- **Запрет редактирования профиля** — для синхронизированных с директорией пользователей (действует во всех их компаниях). [FAQ](https://faq-ru.kaiten.site/zapret-na-redaktirovanie-dannyh-lichnogo-profilya)
- **SCIM 2.0** — `https://<домен>.kaiten.ru/scim/v2`: Users и Groups — list/get/POST/PATCH (без DELETE/PUT), Bearer API-ключ. [API](https://developers.kaiten.ru/scim)
- **Ограниченный доступ к файлам** — файлы не открываются по прямой ссылке без авторизации; запрет загрузки через публичный REST API; на «Корпорации» — отключение загрузки из Dropbox/Google Drive/с устройства. [FAQ](https://faq-ru.kaiten.site/upravlenie-globalnymi-funkciyami-na-tarifah-enterprise)
- **Сессии, политика паролей, ограничение по IP** — в публичной справке не найдено (кроме завершения сеанса при деактивации/проверке LDAP).

## 6. Импорт/экспорт, API, вебхуки, интеграции

### Импорт
- **Мастер импорта** — «Добавить» → «Импортировать» в пустом пространстве/при создании доски; только веб-версия; по окончании письмо. [FAQ](https://faq-ru.kaiten.site/b577083e-3d48-4760-80af-cfd687955c38)
- **Jira** — по API-токену (облако) или паролю (Server): один проект за раз; типы issue → типы карточек, ключи → выбранное поле, sub-tasks → чек-лист или дочерние, комментарии, вложения, внешние ссылки, кастомные поля (тип «jira»), watchers, история переходов, связи (Blocked by → блокировка, Relates → ссылка, эпик → родитель); почты пользователей вручную; импорт Confluence (пространства → папки документов с сохранением вложенности и заменой ссылок). [FAQ](https://faq-ru.kaiten.site/kak-perenesti-zadachi-iz-jira-v-kaiten-confluence)
- **Jira через Convertinator** — из архива выгрузки Jira, с выбором проектов и пользовательских ключей. [FAQ](https://faq-ru.kaiten.site/import-iz-jira-cherez-convertinator-119a137a-39b2-4a58-a2cc-684068e5a206)
- **Confluence (только документы)**. [FAQ](https://faq-ru.kaiten.site/kak-perenesti-dokumenty-iz-confluence-v-kaiten)
- **Trello** — OAuth, выбор доски (+архивные карточки), типы колонок, сопоставление почт; переносятся колонки, карточки, комментарии, участники, файлы, поля date/list/number/text; вложения-ссылки Trello — ссылками. [FAQ](https://faq-ru.kaiten.site/kak-perenesti-zadachi-iz-trello-v-kaiten)
