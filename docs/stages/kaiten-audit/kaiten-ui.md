# Наблюдения в интерфейсе Kaiten (пробный аккаунт, 27.10)
## Каркас
- Полоса слева: Уведомления, Личное, Избранное, Дерево, Talks (чат), внизу — Шаблоны пространств, Администрирование.
- Верх: логотип, счётчик триала, поиск «Найти» по центру, кнопка «Kaiten · AI» (AI Transcribe), справка (?), аватар.
- Под верхом: «+ Добавить» → Карточку / Пространство / Папку / Документ / Story map / Импортировать; справа — «Полный вид карточек» (переключатель вида фасадов).
- Главная (/space): «Доступные пространства» списком.
## Пространство — панель сверху
- Виды: Доски, Списки, Таблица, Timeline, Календарь, Итерации, Файлы; кнопки «Отчёты», «Архив», «+ Добавить»; справа «Фильтры», «Полный вид карточек» (переключатель полный/компактный фасад), «Свернуть все доски», звезда «в избранное». В шапке окна — эмодзи-иконка пространства (сменить) и переименование по щелчку.
## Пространство — правая полоса инструментов (sm=…)
- Пользователи (sm=users): участники с ролями, «Деактивированные пользователи — загрузить список».
- Активность (sm=activity): «Последние обновления» — лента действий по пространству с фильтрами Пользователи / Действия / Начиная с / До.
- Запланированные задания (sm=schedules): повторяющееся создание карточек — название, тип повторения, интервал (ежедневно…), дата начала, время, интервал в днях, часовой пояс; путь карточки (доска, в начало/конец, колонка, дорожка); поля карточки (тип, «добавить поле»).
- Массовые действия (sm=batch): выбрать несколько карточек щелчками → перетащить разом или «Архивировать», «Переместить в», «Выбрать действие».
- Автоматизация: вкладки События / Сроки / Кнопки / Шаблонные чек-листы. Правило «Когда <событие> [+ условия «И», путь] → Выполнить <действия…>»; исполнитель — автор события / заказчик / выбранный / случайный участник пространства / случайный из списка / по кругу (round-robin).
  - События: карточка перемещена или создана; создана; перемещена; добавлен комментарий; добавлен участник; добавлен ответственный; тип изменён; состояние изменено; поле изменено; срок изменён; пункт чек-листа выполнен; все чек-листы выполнены; изменено состояние дочерних задач; добавлена/удалена метка; заблокирована; разблокирована; добавлена блокировка (каждый блокер); «выполнены все условия».
  - Действия: назначить/снять ответственного; добавить/удалить участников; добавить группы пользователей; изменить тип; добавить/удалить метки; добавить поле; изменить значение поля; добавить поле в дочерние; добавить размер; добавить Timeline; игнорировать автокорректировку плановых сроков; изменить срочность; установить/удалить срок; переместить в (другую доску) / в пределах доски / в архив; создать карточку / дочернюю / родительскую; добавить родительскую; добавить шаблонные чек-листы; отметить пункты всех чек-листов; отсортировать карточки; добавить комментарий; редактировать описание; добавить/удалить SLA; привязать сервис (Service desk); управление проектами.
- Ограничения: «Создать ограничение» на пространстве.
- Дополнения: Sipuni (телефония), GitLab, GitHub, Google Docs, TestOps TMS, Yandex Disk — включаются на пространстве.
- Поделиться (sm=share): внутренняя ссылка, «Публичный доступ».
- Workflow: «Workflow / Шаблоны» — workflow для управления процессом на пространстве (создать).
  - Условия правила (И; путь доска/колонка/дорожка с «ИЛИ»): новое местоположение; предыдущее расположение; тип; состояние карточки; состояние дочерних; метка; поле; срок; автор события; карточка является заявкой; автор заявки; статус блокировки; связи карточки; сервис; размер.
  - Вкладка «Сроки»: «Когда … и Наступил срок» + часовой пояс + условия → действия; пример по умолчанию — «Сортировать по сроку выполнения, по возрастанию, в пределах дорожки / во всей колонке».
  - Вкладка «Кнопки»: наименование + список действий (те же) — ручные кнопки ⚡.
  - Вкладка «Шаблонные чек-листы»: название + пункты (подключаются действием автоматизации).
- Ограничения (restrictions): название, текст ошибки, запреты «Запретить перемещение» / «Запретить создание», «Если (все условия верны)»: тип карточки; предыдущий путь; значение поля; в учёте времени нет записей; количество связанных карточек; не выполнены пункты чек-листов; не выполнен шаблонный чек-лист; превышен WIP-лимит; не завершены дочерние; статус блокировки; изменяется состояние; проект карточки.
- Workflow (пространство): редактор этапов (тип этапа: Очередь «ожидание/бэклог» / В работе «активный этап» / Готово «финальный статус») и переходов между ними, флажок «Активен», «Применяется к типам карточек»; проверка «N проблемы». Шаблоны workflow — в администрировании («Workflow»).
## Пространство — «+ Добавить» на панели пространства
- Карточку / Пространство / Папку / Документ / Story map / Доску / **Доску из другого пространства** (одна доска в нескольких пространствах) / Импортировать.
## Меню доски (⋮ в шапке доски, по наведению; открывается панелью справа)
- Переименовать; Добавить в избранное (доску); Скопировать ссылку; Добавить описание; Клонировать доску (с вариантами); Переместить доску на другое пространство; Экспортировать в xlsx; Тип карточки по умолчанию (текущий + выбор из типов: Card, Bug, Feature…); Предлагаемые к заполнению поля карточек; Сумма по карточкам; Установить предупреждение о застоявшихся карточках; Ограничение НЗП (WIP) (на доску); Управление архивными дорожками; Удалить.
- Правила доски (флажки): первая загруженная картинка — обложка карточки; сбрасывать время нахождения на доске при смене дорожки; скрывать выполненный чек-лист; скрывать выполненный шаблонный чек-лист только в «Готово»; автоматически передвигать родительские карточки в «Готово»; автоматически передвигать карточки по статусу дочерних; разрешить автоматическое обратное перемещение; автоматически назначать автора перемещения ответственным (или участником) при переходе в «В работе»/«Готово» (по типу колонки первого уровня).
- В шапке доски по наведению: «+» (добавить), значок ссылки, ⋮, «˄» свернуть.
- «Сумма по карточкам» (доска): поле для суммирования (числовое поле или «Размер»), показывать сумму на доске / по колонкам / по дорожкам.
## Меню колонки (⋮ в заголовке колонки)
- Переименовать; Скопировать ссылку; Управление карточками → «Переместить все карточки в "Готово"», «Переместить все карточки в…», «Отсортировать карточки»; Установить ограничение НЗП (WIP) — по количеству карточек или по размеру; нулевой лимит = «этап нужно пропускать»; Переместить (колонку); **Информировать меня о перемещениях** (подписка на колонку); Тип колонки — очередь / в работе / готово; Формат — карточки / список; Правила колонки — «Чек-листы должны быть отмечены», «Приостановить учёт времени по SLA»; Установить предупреждение о застоявшихся карточках; Скрыть карточки, которые долго не двигались; Удалить.
- В заголовке колонки — «+» (карточка) и ⋮.
## Окно карточки
- Режим открытия (значок справа): Боковая панель / По центру / На весь экран. Справа на краю окна: Закрыть, Открытие карточки, «Добавить карточку в избранное», «Подписаться».
- Шапка: название, «#id · Заказчик», «Создана … назад»; лупа «Показать расположение карточки на пространстве».
- Ряд действий: «+» (большая), ▶ «Запустить таймер», «→ ГОТОВО» (следующая колонка), ⚡ «Автоматизация», «!» «Заблокировать карточку», «Поделиться» (внутренняя ссылка + флажок «Открыть публичный доступ»), ⋮ «Меню».
- «+»: Основное — Срок, Метки, Чек-лист, Ссылка, Загрузить файл; Связи — Родительская, Дочерняя; Остальное — Критерии приёмки, Google Drive, Dropbox; Поля — Создать новое поле, Трудозатраты, Итерация, Размер, Timeline, Тип. Сверху промо «AI приведёт текст в порядок и разобьёт задачу на шаги».
- ⋮ Меню: Скопировать (номер #, ссылку, форматы — выпадающий список); Переместить; Дублировать; Учёт времени; Показать историю; Итерации; Подписаться; Привязать к сервису (Service desk); Экспортировать; Комментарии по email (подменю); Заблокировать; Архивировать; Удалить.
- Учёт времени в карточке: секция «Записи, часы», «Записать время» → дата, время (часы), роль (например, Employee — роли учёта времени), комментарий.
- Файлы: «Скачать все файлы», «Действия»; у файла ⋮. Чек-лист: прогресс-полоса 0/5, пункты с ⋮, «Добавить пункт».
- Комментарии (правая колонка): вкладки «Комментарии» / «Спросить ИИ»; кнопки «Запись экрана» (видео), микрофон (голос), «Расширить секцию комментариев», ⋮; фильтр «Все».
