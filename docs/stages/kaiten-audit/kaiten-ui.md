# Наблюдения в интерфейсе Kaiten (пробный аккаунт, 27.10)
## Каркас
- Полоса слева: Уведомления, Личное, Избранное, Дерево, Talks (чат), внизу — Шаблоны пространств, Администрирование.
- Верх: логотип, счётчик триала, поиск «Найти» по центру, кнопка «Kaiten · AI» (AI Transcribe), справка (?), аватар.
- Под верхом: «+ Добавить» → Карточку / Пространство / Папку / Документ / Story map / Импортировать; справа — «Полный вид карточек» (переключатель вида фасадов).
- Главная (/space): «Доступные пространства» списком.
## Пространство — панель сверху
- Виды: Доски, Списки, Таблица, Timeline, Календарь, Итерации, Файлы; кнопки «Отчёты», «Архив», «+ Добавить»; справа «Фильтры», «Полный вид карточек» (переключатель полный/компактный фасад), «Свернуть все доски», звезда «в избранное». В шапке окна — эмодзи-иконка пространства (сменить) и переименование по щелчку.
## Пространство — правая полоса инструментов (sm=…)
- Пользователи (sm=users): участники с ролями, «Деактивированные пользователи — загрузить список».
- Активность (sm=activity): «Последние обновления» — лента действий по пространству с фильтрами Пользователи / Действия / Начиная с / До.
- Запланированные задания (sm=schedules): повторяющееся создание карточек — название, тип повторения, интервал (ежедневно…), дата начала, время, интервал в днях, часовой пояс; путь карточки (доска, в начало/конец, колонка, дорожка); поля карточки (тип, «добавить поле»).
- Массовые действия (sm=batch): выбрать несколько карточек щелчками → перетащить разом или «Архивировать», «Переместить в», «Выбрать действие».
- Автоматизация: вкладки События / Сроки / Кнопки / Шаблонные чек-листы. Правило «Когда <событие> [+ условия «И», путь] → Выполнить <действия…>»; исполнитель — автор события / заказчик / выбранный / случайный участник пространства / случайный из списка / по кругу (round-robin).
  - События: карточка перемещена или создана; создана; перемещена; добавлен комментарий; добавлен участник; добавлен ответственный; тип изменён; состояние изменено; поле изменено; срок изменён; пункт чек-листа выполнен; все чек-листы выполнены; изменено состояние дочерних задач; добавлена/удалена метка; заблокирована; разблокирована; добавлена блокировка (каждый блокер); «выполнены все условия».
  - Действия: назначить/снять ответственного; добавить/удалить участников; добавить группы пользователей; изменить тип; добавить/удалить метки; добавить поле; изменить значение поля; добавить поле в дочерние; добавить размер; добавить Timeline; игнорировать автокорректировку плановых сроков; изменить срочность; установить/удалить срок; переместить в (другую доску) / в пределах доски / в архив; создать карточку / дочернюю / родительскую; добавить родительскую; добавить шаблонные чек-листы; отметить пункты всех чек-листов; отсортировать карточки; добавить комментарий; редактировать описание; добавить/удалить SLA; привязать сервис (Service desk); управление проектами.
- Ограничения: «Создать ограничение» на пространстве.
- Дополнения: Sipuni (телефония), GitLab, GitHub, Google Docs, TestOps TMS, Yandex Disk — включаются на пространстве.
- Поделиться (sm=share): внутренняя ссылка, «Публичный доступ».
- Workflow: «Workflow / Шаблоны» — workflow для управления процессом на пространстве (создать).
  - Условия правила (И; путь доска/колонка/дорожка с «ИЛИ»): новое местоположение; предыдущее расположение; тип; состояние карточки; состояние дочерних; метка; поле; срок; автор события; карточка является заявкой; автор заявки; статус блокировки; связи карточки; сервис; размер.
  - Вкладка «Сроки»: «Когда … и Наступил срок» + часовой пояс + условия → действия; пример по умолчанию — «Сортировать по сроку выполнения, по возрастанию, в пределах дорожки / во всей колонке».
  - Вкладка «Кнопки»: наименование + список действий (те же) — ручные кнопки ⚡.
  - Вкладка «Шаблонные чек-листы»: название + пункты (подключаются действием автоматизации).
- Ограничения (restrictions): название, текст ошибки, запреты «Запретить перемещение» / «Запретить создание», «Если (все условия верны)»: тип карточки; предыдущий путь; значение поля; в учёте времени нет записей; количество связанных карточек; не выполнены пункты чек-листов; не выполнен шаблонный чек-лист; превышен WIP-лимит; не завершены дочерние; статус блокировки; изменяется состояние; проект карточки.
- Workflow (пространство): редактор этапов (тип этапа: Очередь «ожидание/бэклог» / В работе «активный этап» / Готово «финальный статус») и переходов между ними, флажок «Активен», «Применяется к типам карточек»; проверка «N проблемы». Шаблоны workflow — в администрировании («Workflow»).
## Пространство — «+ Добавить» на панели пространства
- Карточку / Пространство / Папку / Документ / Story map / Доску / **Доску из другого пространства** (одна доска в нескольких пространствах) / Импортировать.
## Меню доски (⋮ в шапке доски, по наведению; открывается панелью справа)
- Переименовать; Добавить в избранное (доску); Скопировать ссылку; Добавить описание; Клонировать доску (с вариантами); Переместить доску на другое пространство; Экспортировать в xlsx; Тип карточки по умолчанию (текущий + выбор из типов: Card, Bug, Feature…); Предлагаемые к заполнению поля карточек; Сумма по карточкам; Установить предупреждение о застоявшихся карточках; Ограничение НЗП (WIP) (на доску); Управление архивными дорожками; Удалить.
- Правила доски (флажки): первая загруженная картинка — обложка карточки; сбрасывать время нахождения на доске при смене дорожки; скрывать выполненный чек-лист; скрывать выполненный шаблонный чек-лист только в «Готово»; автоматически передвигать родительские карточки в «Готово»; автоматически передвигать карточки по статусу дочерних; разрешить автоматическое обратное перемещение; автоматически назначать автора перемещения ответственным (или участником) при переходе в «В работе»/«Готово» (по типу колонки первого уровня).
- В шапке доски по наведению: «+» (добавить), значок ссылки, ⋮, «˄» свернуть.
- «Сумма по карточкам» (доска): поле для суммирования (числовое поле или «Размер»), показывать сумму на доске / по колонкам / по дорожкам.
## Меню колонки (⋮ в заголовке колонки)
- Переименовать; Скопировать ссылку; Управление карточками → «Переместить все карточки в "Готово"», «Переместить все карточки в…», «Отсортировать карточки»; Установить ограничение НЗП (WIP) — по количеству карточек или по размеру; нулевой лимит = «этап нужно пропускать»; Переместить (колонку); **Информировать меня о перемещениях** (подписка на колонку); Тип колонки — очередь / в работе / готово; Формат — карточки / список; Правила колонки — «Чек-листы должны быть отмечены», «Приостановить учёт времени по SLA»; Установить предупреждение о застоявшихся карточках; Скрыть карточки, которые долго не двигались; Удалить.
- В заголовке колонки — «+» (карточка) и ⋮.
## Окно карточки
- Режим открытия (значок справа): Боковая панель / По центру / На весь экран. Справа на краю окна: Закрыть, Открытие карточки, «Добавить карточку в избранное», «Подписаться».
- Шапка: название, «#id · Заказчик», «Создана … назад»; лупа «Показать расположение карточки на пространстве».
- Ряд действий: «+» (большая), ▶ «Запустить таймер», «→ ГОТОВО» (следующая колонка), ⚡ «Автоматизация», «!» «Заблокировать карточку», «Поделиться» (внутренняя ссылка + флажок «Открыть публичный доступ»), ⋮ «Меню».
- «+»: Основное — Срок, Метки, Чек-лист, Ссылка, Загрузить файл; Связи — Родительская, Дочерняя; Остальное — Критерии приёмки, Google Drive, Dropbox; Поля — Создать новое поле, Трудозатраты, Итерация, Размер, Timeline, Тип. Сверху промо «AI приведёт текст в порядок и разобьёт задачу на шаги».
- ⋮ Меню: Скопировать (номер #, ссылку, форматы — выпадающий список); Переместить; Дублировать; Учёт времени; Показать историю; Итерации; Подписаться; Привязать к сервису (Service desk); Экспортировать; Комментарии по email (подменю); Заблокировать; Архивировать; Удалить.
- Учёт времени в карточке: секция «Записи, часы», «Записать время» → дата, время (часы), роль (например, Employee — роли учёта времени), комментарий.
- Файлы: «Скачать все файлы», «Действия»; у файла ⋮. Чек-лист: прогресс-полоса 0/5, пункты с ⋮, «Добавить пункт».
- Комментарии (правая колонка): вкладки «Комментарии» / «Спросить ИИ»; кнопки «Запись экрана» (видео), микрофон (голос), «Расширить секцию комментариев», ⋮; фильтр «Все».
- «Комментарии по email»: у карточки свой адрес — письмо на него (или копия) становится комментарием с содержимым письма.
## Виды пространства (все — с общей кнопкой «Фильтры»)
- **Списки** (/lists): те же доски, но колонки — вертикальными списками карточек друг под другом (доска → колонка → карточки).
- **Таблица** (/grid): строки-карточки, группировка (по доске), сортировка (дорожка, колонка, порядок); столбцы: Название, ID, Дорожка, Колонка, Размер, Срок, Заказчик, Ответственный, Участники, Метки, Доска, Тип (+ поля); строка «Суммы цифровых полей»; «Скачать» (выгрузка), «Настройки» (набор столбцов, сохранённые настройки «Выбрать настройку»), ширина колонок.
- **Timeline** (/timeline): Гант — слева таблица (Название, ID, Планируемое начало, Запланированный конец, Рабочая длительность, Предшествующие карточки, Ответственный, Участники, Трудозатраты, Тип), справа шкала по месяцам с «Сегодня»; группировка по доске; кнопки «Проекты», «Скачать развёрнутый отчёт», «Скачать», «Настройки».
- **Календарь** (/calendar): карточки по сроку (переключатель «Срок» — по какой дате), Месяц / Неделя / День, «Сегодня».
- **Итерации** (/iterations, спринты): «Нераспределённые задачи» таблицей (как «Таблица», с суммами), список итераций, «Добавить итерацию», «Завершённые», выбор досок, участвующих в итерациях.
- **Файлы** (/files): все вложения пространства таблицей или плиткой — имя, тип, карточка, автор, дата, размер; фильтры Тип / Период / Автор / Источник; постранично (50).
## Архив пространства (/archive)
- Таблица архивных карточек: Название, Доска, Колонка, Дорожка, ID, Дата создания, Взята в работу, Выполнена, Срок, Заказчик, Метки, Суммарное время, Суммарное время блокировок, Размер, Трудозатраты, Тип, Ответственный, Участники; «Скачать», «Настройки», сохранённые настройки, фильтры.
## Отчёты пространства (/charts) — 12 видов, у каждого панель «Фильтр» и «Показать»
- **Суммарный отчёт**: период, колонки «готово», группировка; «Скачать».
- **Сроки по задачам**: карточки и пункты чек-листов со сроком (в очереди/в работе + завершённые за период); доски, период карточек, период пунктов.
- **Воронка продаж**: период, типы, метки, ответственный, доски, колонки «Выиграно» / «Проиграно», поле суммы.
- **Накопительная диаграмма потока (CFD)**: период, зоны (добавить), доски, ось Y — количество или размер, метки, типы, только срочные, показать тренд, распределение по типам.
- **Контрольный график**: период, начало пути (колонки), конец пути, SLA (дни), типы, метки, только срочные.
- **Спектральная диаграмма**: период, начало/конец пути, «первое вхождение», шаг, два перцентиля, типы, метки, только срочные.
- **Динамика изменений времени цикла**: группировка по месяцу…, период (даты), начало/конец пути, первое вхождение, функция (среднее…).
- **Пропускная способность**: даты, группировка (по месяцу), начальная/конечная колонка, ось Y — количество или размер, группировка по (полю), метки, только срочные.
- **Распределение карточек**: доски, типы, только срочные, включая архивные.
- **Время цикла**: постранично; период, начальная/конечная колонка, метки, типы, **учитывать дни недели (ПН…ВС)**, **исключить даты**, только срочные.
- **Время разрешения блокировок**: дата начала, категории блокировок, доски.
- **Итерация — график сгорания** (burndown): выбор итерации, «Показать описание графика».
## Фильтры пространства («Фильтры» справа на панели)
- «Добавить фильтр» — по полю: Название, Заказчик, Заказчик заявки службы поддержки, Участник, Ответственный, ID, Срочность, Статус блокировки, Метка, Итерация, Проект, Родительская, Дочерняя, Статус, Тип, Размер, Завершена, Создана, Последнее перемещение, Обновлена, Взята в работу, Планируемое начало, Запланированный конец, Срок, Суммарное время, Сервис, Путь, «Новый комментарий был добавлен», Организация, Источник создания (+ пользовательские поля).
- Условие: «это / не» + значение (для людей — «не назначен»), «Добавить». Фильтр общий для всех видов пространства.
## Левая полоса разделов
- **Уведомления**: список с фильтром «Все», «Отметить все как прочитанные», «Настроить уведомления».
- **Личное** (/mine): Карточки — мои карточки видом «Списки» с фильтром по умолчанию «Ответственный = я И статус = запланирована ИЛИ в работе», фильтр можно «Сохранить» / «Очистить», «Развернуть»; Блокеры — таблица моих блокировок (карточка, текст, карточка-блокер, дата, срок, участники, категории); Активности — моя лента действий; Учёт времени — мои записи таблицей за период (по умолчанию текущая неделя), «Скачать»; Записи встреч — видео встреч (превью, название, тип, дата, статус, длина, расположение).
- **Избранное**: «Пока нет избранного», счётчик.
- **Дерево**: «+» и ⋮ у узлов, «Настройки пространства» у пространства; в дереве — документ «Первый документ» рядом с пространством; внизу — блок пробного периода.
- **Шаблоны пространств** (/entities-templates): галерея готовых пространств по категориям (Управление IT-проектами, Поддержка и бэк-офис, Маркетинг, Продажи, Стратегия, Управление персоналом): «Канбан для разработки», «Upstream & Downstream», «Scrum-команда», «Web-разработка: интернет-магазин»…; «Предпросмотр» / «Выбрать».
## Администрирование (левая полоса → «Администрирование»), разделы
Учёт времени, Служба поддержки, Типы карточек, Виды карточек, Хранилище, Метки, Оплата, Дерево сущностей, Настройки компании, Пользователи, Роли пользователей, Пользовательские поля, Каталоги, Журнал событий, Экспорт данных компании, Календари, External webhooks, Журнал аудита, Ресурсное планирование, Категории блокировки, Workflows.
- **Настройки компании** (/settings; вкладки «Настройки компании» / «Настройка ролей»): наименование, часовой пояс раздела «Timeline»; «Способы аутентификации» (таблица: название, тип, домены, статус; по умолчанию «Аутентификация с помощью PIN-кода» — вход по одноразовому коду на почту; «Добавить способ аутентификации»); «Права доступа по умолчанию» — какие административные разделы и функции получает новый пользователь (раздел «Метки», «Типы карточек», приглашение новых пользователей…).
- **Пользователи** (/members), вкладки: Пользователи (Владелец + «Изменить»; таблица: полное имя, имя пользователя, эл. почта, последняя активность; фильтры), Нерабочие дни, Роли, Группы, Запросы на доступ, Приглашения, Сессии.
- **Роли пользователей** (/user-roles): «Добавить роль».
- **Пользовательские поля** (/custom-properties): активные / деактивированные; «Поле для отображения прогресса в карточках»; «Добавить пользовательское поле».
- **Каталоги** (/custom-directories): справочники с произвольной структурой для хранения данных («Добавить каталог»).
- **Типы карточек** (/card-types): название, дата, автор, «Поля, предлагаемые к заполнению», «Предлагать прочие поля», «Использование ограничено»; по умолчанию Card, Bug, Feature.
- **Виды карточек** (/admin-card-views): сохранённые виды/фильтры пользователей — название, владелец, «Владелец: доступ к Kaiten», действия (администратор видит все).
- **Хранилище** (/admin-files): общий объём, число файлов, средний размер, прирост за 30 дней, рост по месяцам (6/12), по типам (документы, изображения, видео, архивы, другое), по местам (карточки, документы).
- **Метки компании** (/tags): название, число карточек, действия.
- **Дерево сущностей** (/admin-entities-tree): все пространства и документы — название, автор, дата, доступ («По приглашению»), фильтры.
- **Журнал событий** (/activity-logs): предупреждение «право позволяет восстанавливать удалённые карточки и доски вне доступа к ним»; события (событие, название, расположение, дата, автор), фильтры — по сути корзина/восстановление.
- **Журнал аудита** (/audit-logs): категория (аутентификация…), событие (успешный вход, запрос PIN, выход), дата, автор, описание; фильтры; «Скачать».
- **Экспорт данных компании** (/company-export): «Начать экспорт», история экспортов 30 дней.
- **Календари** (/work-calendars): рабочие календари, «Импорт производственного календаря РФ».
- **External webhooks** (/external-webhooks): вебхуки уровня организации, создаёт администратор.
- **Ресурсное планирование** (/resource-planning): «Виртуальные пользователи» (плановые ресурсы без учётной записи).
- **Категории блокировки** (/blocker-categories): справочник категорий блокировок.
- **Workflows** (/workflows): шаблоны workflow компании.
- **Учёт времени** (/timesheets): отчёт по записям времени всей компании — фильтры (начало, окончание, группы пользователей, пользователи, метки), единицы (часы…), карточки (любые…), группировка, «с распределением по дням»; «Настройка полей», «Скачать».
- **Служба поддержки** (/service-desk): портал заявок `<компания>/sd`; Дэшборд, Статистика, Статистика по SLA, Заявки, Сервисы (форма приёма заявок со своими полями, правами, статусами и доской), Доступ к службе поддержки, Настройки, Шаблонные ответы, Организации, Пользователи, SLA, Telegram-бот для клиентов, бот MAX Messenger.
- Права доступа по умолчанию (полный список): разделы «Метки», «Типы карточек», «Виды карточек»; приглашение новых пользователей; открыть общий доступ к карточке (поделиться); администрирование дашбордов; функциональность Kaiten; открытие публичного доступа; запросы на доступ; автоматическое одобрение запросов нерабочего времени; разрешить бета-функции. Внизу — «Удаление аккаунта компании».
- Настройка ролей: роль владельцу при создании сущности в корне; роль по умолчанию без явной роли; роль по умолчанию для гостей; роль для импортированных пользователей; возможность приглашать гостей из сущности; роли, разрешённые к использованию из сущностей (Администратор, Редактор, Комментатор).
- Способы аутентификации — типы: Google Workspace, OpenID Connect (with secret), LDAP; у способа — название, текст кнопки входа, домены, статус. Стандартный вход — PIN-код на почту (без пароля).
- Пользователи → вкладки: Нерабочие дни (сотрудники — отпуска/отсутствия), Роли (Администратор, Редактор, Комментатор, «Редактор в корне меню», «Пользователь для публичных сущностей»; «Создать роль»: корень меню — создание/перемещение/импорт; разделы — создание, чтение, редактирование, перемещение внутри/за пределы иерархии, удаление, управление доступом, группы пользователей, импорт, открытие публичного доступа; по сущностям: пространства, документы, папки, Story Maps; флаг «выдавать права на новые действия по умолчанию»), Группы (активные/деактивированные, встроенная «Все пользователи компании», «Создать группу»), Запросы на доступ (пользователь, кто запросил, сущность, доступ, дата, комментарий), Приглашения (email, «как гостевого пользователя», «на пространство, папку, документ или Story Map» с ролью), Сессии («Сбросить все сессии», список).
