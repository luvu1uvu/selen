# Каталог функций Kaiten по публичной справке — часть 1

Источники: справочный центр Kaiten https://faq-ru.kaiten.site (сам работает на Kaiten, адреса статей — UUID или транслит),
лента обновлений «Что нового» https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6 (2021 — окт. 2026),
блог kaiten.ru/blog. Дата сбора — 27.10.2026. Формат строки: **Функция** — как работает. [источник] (тариф/ограничение).
Сокращение «ЧН» = лента «Что нового». Тарифы Kaiten: Free, Start, Standard, Business, Corporation/Enterprise, on-premise; платные модули подключаются отдельно.

## 1. Структура и навигация

- **Иерархия сущностей** — 4 типа элементов: пространство (доски и карточки), документ, Story Map, папка; любой можно вложить в любой, любой может быть корневым («узел» = верхний элемент + вложенные). [Дерево](https://faq-ru.kaiten.site/251d5a85-b237-4cff-bb0b-b6af8a847e92)
- **Левая панель (дерево)** — показывает все доступные элементы аккаунта по иерархии; плюс разделы Уведомления, Личное, Избранное, Чат, Шаблоны пространств, Администрирование (набор зависит от прав). [Интерфейс](https://faq-ru.kaiten.site/interfeys-kaiten)
- **Наследование доступа по дереву** — доступ к родителю даёт доступ ко всему вложенному с той же ролью; доступ только к пространству — видно только его; перенос элемента в другую ветку меняет его доступ («права папки всегда главнее»). [Дерево](https://faq-ru.kaiten.site/251d5a85-b237-4cff-bb0b-b6af8a847e92), [Папки](https://faq-ru.kaiten.site/papki-i-sortirovka-dokumentov)
- **Кнопка «+» в дереве** — рядом с поиском вверху меню: создать Пространство, Story map, Папку, Документ (неактивна без права «редактирование корня меню»). [Дерево](https://faq-ru.kaiten.site/251d5a85-b237-4cff-bb0b-b6af8a847e92), [Создать пространство](https://faq-ru.kaiten.site/kak-sozdat-prostranstvo)
- **Вложение перетаскиванием** — зажать элемент и бросить на другой → станет вложенным; бросить между элементами → только смена порядка; справка предупреждает, что вложение меняет доступ. [Дерево](https://faq-ru.kaiten.site/251d5a85-b237-4cff-bb0b-b6af8a847e92)
- **Ошибка «Недостаточно прав для перемещения»** — нужны право перемещения у источника и право создания в цели (Редактор/Администратор/кастомная роль); владелец видит вложенность в админ-разделе «Дерево сущностей» (бывш. «Пространства»). [Дерево](https://faq-ru.kaiten.site/251d5a85-b237-4cff-bb0b-b6af8a847e92)
- **Поиск по дереву** — поле поиска вверху дерева (и в мобильном «Дереве»). [Интерфейс](https://faq-ru.kaiten.site/interfeys-kaiten), [Моб. приложение](https://faq-ru.kaiten.site/f831cd50-92b9-40b3-96ea-8c53b28266e1)
- **Создание пространства** — «+» → «Пространство»: название, по желанию доступ для групп; создатель становится администратором; число пространств не ограничено; создавать может любой, кроме гостей; после создания предлагается создать доску или импорт. [Создать пространство](https://faq-ru.kaiten.site/kak-sozdat-prostranstvo)
- **Вложенные пространства** — пространство можно прикрепить к папке, другому пространству или Story Map; участники родителя автоматически получают ту же роль во вложенных. [Доступ к вложенным](https://faq-ru.kaiten.site/dostup-k-vlozhennym-prostranstvam)
- **Папки** — контейнер навигации: внутри документы, папки, пространства, Story Map; доступ к папке распространяется на всё содержимое; сортировка только ручная (перетаскивание). [Папки](https://faq-ru.kaiten.site/papki-i-sortirovka-dokumentov)
- **Глобальная кнопка «Добавить»** — в верхней панели под поиском, работает из любого раздела: Карточка (обязательны название, путь, тип; проверка Workflow), Пространство (родитель, ключ, из шаблона или из Workflow), Папка (ключ), Документ, Story Map (ключ, описание), Импорт. [Кнопка «Добавить»](https://faq-ru.kaiten.site/globalnaya-knopka-dobavit) (on-prem ≥ 57.602.6)
- **Избранное** — личный список: карточки, доски, документы, папки, пространства, Story Map; добавить — ⋯ у элемента в меню → «Добавить в избранное», у доски — в её меню, у карточки — звёздочка (горячая клавиша `w`); убрать — так же. [Избранное](https://faq-ru.kaiten.site/razdel-izbrannoe)
- **Раздел «Личное» → Карточки** — все карточки из доступных пространств в одном месте, вид таблица или список (колонки Очередь / В работе / Готово по типу колонки); кнопка «Фильтр» (по умолчанию «Ответственный» = я; очистить → все доступные карточки аккаунта); группировка по пространству (таблица); сортировка до 5 критериев. [Личное](https://faq-ru.kaiten.site/razdel-lichnoe)
- **Личное → Активности** — лента собственных действий (перемещения карточек, отметки чек-листов, назначения). [Личное](https://faq-ru.kaiten.site/razdel-lichnoe)
- **Личное → Блокеры** — все блокировки, где пользователь участвует, в одном окне: причины, сроки, участники. [Личное](https://faq-ru.kaiten.site/razdel-lichnoe)
- **Личное → Учёт времени / Записи встреч** — своё время за неделю/месяц/период; записи встреч из AI-расширения. [Интерфейс](https://faq-ru.kaiten.site/interfeys-kaiten) (учёт времени — модуль)
- **Иконки и эмодзи у сущностей** — у пространств, папок, документов, Story Map: эмодзи или иконка (вкладки, поиск, цвет иконки), удаление — корзина; из шапки открытой сущности, над названием (папка/документ) или ⋯ в меню → «Изменить иконку»; в мобильном — так же. [Иконки](https://faq-ru.kaiten.site/ikonki-i-emodzi-v-nazvaniyah-sushchnostey)
- **Переименование в один клик** — клик по названию в верхней панели, правка, Enter; только редактор/администратор. [Иконки](https://faq-ru.kaiten.site/ikonki-i-emodzi-v-nazvaniyah-sushchnostey)
- **Меню ⋯ пространства (в дереве)** — удалить; сменить группу пользователей с доступом; иконка; фон; «Подписаться на все карточки»; «Создать копию»; добавить в избранное. [Опции пространства](https://faq-ru.kaiten.site/nastroyki-i-opcii-prostranstva)
- **Настройки ⚙ пространства** — переименование; «Свойства» (ключ, вид по умолчанию); «Вид» — общая настройка Таблицы/Timeline/Архива; скрытые типы карточек; интеграции: календарь, Webhooks, GitHub, GitLab, email. [Опции пространства](https://faq-ru.kaiten.site/nastroyki-i-opcii-prostranstva)
- **Фон пространства** — картинка/цвет фона за досками (не копируется при копировании). [Опции пространства](https://faq-ru.kaiten.site/nastroyki-i-opcii-prostranstva)
- **Стартовое пространство** — профиль → «Языки и пространство по умолчанию»: какое пространство открывается при входе. [Пространство по умолчанию](https://faq-ru.kaiten.site/prostranstvo-po-umolchaniyu)
- **Вид пространства по умолчанию** — личная настройка: для всех пространств (профиль → Внешний вид) или для одного (⚙ → Свойства); настройка пространства важнее глобальной. [Вид по умолчанию](https://faq-ru.kaiten.site/vid-prostranstva-po-umolchaniyu)
- **Пользовательские ключи** — короткий код у пространства/папки/Story Map (DEV) → номера карточек вида DEV-123, ключ наследуется от ближайшего контейнера, пересчитывается при переносе; старые ссылки работают, пока ключ существует. [Ключи](https://faq-ru.kaiten.site/polzovatelskie-klyuchi-dlya-prostranstv-papok-i-storymap) (только on-premise, экспериментальная функция)
- **Короткие ссылки по ключу** — `https://<компания>.kaiten.ru/<КЛЮЧ>` открывает пространство/папку/Story Map. [Ключи](https://faq-ru.kaiten.site/polzovatelskie-klyuchi-dlya-prostranstv-papok-i-storymap)
- **Последние обновления пространства** — правый верхний угол пространства: лента действий (карточки, пользователи и роли, доски, дорожки, колонки, чек-листы) с фильтрами по пользователю, типу действия, периоду. [Последние обновления](https://faq-ru.kaiten.site/poslednie-obnovleniya-prostranstva)
- **Удаление пространства** — только после удаления всех его досок (при удалении доски — куда перенести карточки или «не переносить»); ⋯ → «Удалить пространство» → подтверждение. [Удалить пространство](https://faq-ru.kaiten.site/kak-udalit-prostranstvo)
- **Копирование сущностей («Создать копию»)** — ⋯ у любой сущности корня: выбор родителя, «глубокое копирование» (вся вложенность) или только сама сущность; копирует доски (колонки, дорожки, подколонки), карточки, стандартные и польз. поля, блокировки, документы, Story Map; НЕ копирует фон, участников, связи родитель-ребёнок, комментарии, правила доски, ограничения, автоматизации, запланированные задания; идёт в фоне с уведомлением. [Копирование](https://faq-ru.kaiten.site/kopirovanie-prostranstv) (Free: 1 операция/3 сущности; Start: 3/5; Standard+: 10/без лимита)
- **Шаблоны пространств** — раздел в левой панели над «Администрированием»: 17 шаблонов (IT, поддержка, маркетинг, продажи, стратегия), предпросмотр (глаз), «Выбрать шаблон» → имя → создаётся в фоне; кнопка «Написать в поддержку» — заказать свой шаблон; галерея kaiten.ru/shablony. [Шаблоны](https://faq-ru.kaiten.site/48b0dcc5-f383-4d4e-ac84-6ad8da94ac9f) (все тарифы; своего шаблона из интерфейса нет)
- **Создание пространства из Workflow** — готовое пространство с применённым маршрутом этапов из шаблона. [ЧН март 2026](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Публичный доступ к пространству/папке/Story Map** — «Поделиться» → тумблер «Публичный доступ», срок действия ссылки; публикуется всё вложенное; гость видит только чтение (виды список, таблица, timeline, календарь, архив), без ФИО/аватаров участников и без комментариев. [Публичный доступ](https://faq-ru.kaiten.site/publichnyy-dostup-k-prostranstvam-papkam-i-story-map)
- **«Импортировать к себе» публичную сущность** — копия чужого публичного пространства в свой аккаунт (структура, карточки с вложениями и блокировками, связи, основные поля; без польз. полей, комментариев, участников); облако↔on-prem не смешиваются. [Публичный доступ](https://faq-ru.kaiten.site/publichnyy-dostup-k-prostranstvam-papkam-i-story-map)
- **Хлебные крошки и новая навигация** — путь к открытой сущности в верхней панели, профиль и помощь — справа вверху, на мобильном то же сверху; новый сайдбар и чат — для всех с сент. 2026. [Навигация](https://faq-ru.kaiten.site/obnovlennaya-navigaciya), [ЧН](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Единое окно выбора пути** — одно окно «куда» везде (перемещение, массовое перемещение, создание карточки, дочерние карточки, автоматизации, динамические доски, удаление доски): полный путь, поиск, вкладка «Недавно использованные», дерево. [Окно выбора пути](https://faq-ru.kaiten.site/s-4-fevralya-edinoe-okno-vybora-puti-v-strukture-kaiten)
- **Быстрый доступ в окне перемещения** — домашнее (стартовое) пространство сверху, недавние места, избранное. [Перемещение карточки](https://faq-ru.kaiten.site/peremeshchenie-kartochki)
- **Кнопка «Запросить доступ»** — на сущности без доступа можно отправить запрос администратору. [ЧН янв. 2025](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Значок публичных элементов в навигации** — публичные сущности помечены иконкой в дереве. [ЧН июль 2024](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Глобальный поиск** — см. раздел 5. [Глобальный поиск](https://faq-ru.kaiten.site/globalnyy-poisk)
- **Журнал событий (админ)** — события аккаунта с автором и временем; восстановление удалённых досок, дорожек, карточек. [Последние обновления](https://faq-ru.kaiten.site/poslednie-obnovleniya-prostranstva)

## 2. Доски и виды

### Доски
- **Несколько досок в пространстве** — неограниченно; доски располагаются вертикально или горизонтально (вид «Доски») / только горизонтально (вид «Списки»). [Формат и вид](https://faq-ru.kaiten.site/format-i-vid-otobrazheniya-prostranstv), [Несколько досок](https://faq-ru.kaiten.site/neskolko-dosok-na-odnom-prostranstve)
- **Создание доски** — пустое пространство: «Создать доску» в центре; иначе «Добавить» → «Доску»; или «+» у пространства в меню → «Добавить доску»; выбор шаблона. [Создать доску](https://faq-ru.kaiten.site/kak-sozdat-dosku)
- **Шаблоны досок** — простая канбан (Очередь/В работе/Готово), доска с дорожками, Scrum-доска (бэклог + доска итерации). [Виды досок](https://faq-ru.kaiten.site/vidy-dosok-v-kaiten)
- **Одна доска в нескольких пространствах** — «Добавить» → «Доску из другого пространства» (или «+» у пространства в меню); изменения видны везде; права на доску = роль в пространстве, где её открыли; добавлять можно только из пространств, где ты ≥ редактор; удаление из одного пространства не удаляет из других. [Одна доска в нескольких](https://faq-ru.kaiten.site/odna-doska-v-neskolkih-prostranstvah) (по блогу — Standard и выше: [5 фишек](https://kaiten.ru/blog/5-fishiek-kaiten-kotoryie-ekonomiat-vriemia-i-uskoriaiut-rabotu/))
- **Основная доска и доски-ссылки** — первая доска — основная, её пространство — «главное»; в других пространствах — ссылки со значком; меню доски → «Сделать основной доской»; при удалении основной — выбрать новое главное пространство; подтверждение удаления перечисляет все пространства с этой доской. [Основные доски](https://faq-ru.kaiten.site/osnovnye-doski-i-doski-ssylki), [ЧН ноя 2021](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Доска, привязанная к пространству** — для закрепления верхнеуровневых задач (с дочерними рядом), OKR или инструкций. [Виды досок](https://faq-ru.kaiten.site/vidy-dosok-v-kaiten)
- **Описание доски** — ⋯ доски → описание: правила работы команды; тот же редактор, что у карточки (заголовки, картинки, видео, код), режим Markdown; значок описания на доске (у одноколоночной доски — только через «редактировать»). [Описание доски](https://faq-ru.kaiten.site/opisanie-doski)
- **Переименование доски** — через меню доски. [Доски](https://faq-ru.kaiten.site/doski)
- **Порядок досок в пространстве** — перетаскивание за точки слева от названия доски. [Переместить доску](https://faq-ru.kaiten.site/kak-peremestit-dosku)
- **Перенос доски в другое пространство** — ⋯ доски → «Переместить доску на другое пространство»; только администратор; архив доски переезжает вместе с ней. [Переместить доску](https://faq-ru.kaiten.site/kak-peremestit-dosku), [Архив](https://faq-ru.kaiten.site/arhiv)
- **Клонирование доски** — ⋯ → «Клонировать доску»: только структура или структура + карточки. [Клонировать](https://faq-ru.kaiten.site/kak-sozdat-dublikat-doski)
- **Удаление доски** — ⋯ → «Удалить»: спрашивает, куда перенести карточки (и архивные), либо «не переносить». [Удалить пространство](https://faq-ru.kaiten.site/kak-udalit-prostranstvo), [Архив](https://faq-ru.kaiten.site/arhiv)
- **Восстановление доски** — Администрирование → «Журнал событий» → значок восстановления; вернётся в прежнее пространство или в выбранное, если то удалено. [Восстановить доску](https://faq-ru.kaiten.site/kak-vosstanovit-dosku)
- **Правила доски** — ⋯ доски → «Правила», флажки: обложка из первой картинки описания; сброс времени на доске при смене дорожки; скрывать выполненный чек-лист; скрывать выполненный шаблонный чек-лист только в «Готово»; родитель → «Готово», когда все дети готовы; двигать родителя по статусу детей; разрешить обратное автодвижение; назначать автора перемещения из «Очереди» ответственным. [Правила доски](https://faq-ru.kaiten.site/pravila-doski)
- **Автодвижение связанных карточек** — родитель в «В работе», когда хоть один ребёнок в работе, и в «Готово», когда все готовы (и все пункты его чек-листа отмечены); работает только на доске ровно из 3 колонок с типами Очередь→В работе→Готово; опция обратного движения. [Автодвижение](https://faq-ru.kaiten.site/avtomaticheskoe-peredvizhenie-svyazannyh-kartochek)
- **Предлагаемые/обязательные поля доски** — ⋯ доски → «Предлагаемые к заполнению поля карточек»: «Добавить поле», выбрать дорожки (и колонки) и типы карточек, флажок обязательности, порядок перетаскиванием (только польз. поля). [Обязательные поля доски](https://faq-ru.kaiten.site/obyazatelnye-polya-dlya-kartochek-na-doske)
- **Тип карточки по умолчанию для доски/дорожки** — ⋯ доски или дорожки → «Тип карточки по умолчанию»; действует на новые и перемещённые сюда карточки; дорожка важнее доски. [Типы карточек](https://faq-ru.kaiten.site/tipy-kartochek)
- **Сумма по карточкам** — ⋯ доски → «Сумма по карточкам»: поле «Размер» или польз. «Число» (с единицей, напр. ₽); показ под названием колонки, у дорожки, общая — подсказка у значка Σ. [Сумма](https://faq-ru.kaiten.site/summa-kartochek-na-doske)
- **Экспорт доски в xlsx** — ⋯ доски → «Экспорт в xlsx», файл приходит на почту; даты входа в каждую колонку; без чек-листов, описаний, файлов и польз. полей. [Выгрузка](https://faq-ru.kaiten.site/vygruzka-i-eksport-dannyh)
- **Динамическая доска** — «+» у пространства → динамическая доска: сама собирает карточки из нескольких пространств по критериям (глобальные условия И/ИЛИ + условия колонок/дорожек + колонка «остальные карточки»); только просмотр (нельзя перетаскивать и создавать), без архивных; ≤100 карточек на колонку/дорожку; автообновление раз в 60 с и кнопка обновления. [Динамические доски](https://faq-ru.kaiten.site/dinamicheskie-doski) (on-premise или «Корпорация», эксп. функция)
- **Свернуть доску / «Свернуть/Развернуть все доски»** — кнопка рядом с «Избранным» (виды Доски и Списки), состояние сохраняется при смене вида; горячая клавиша `−`; свёрнутая доска в «Списках» — вертикальная полоса с названием. [Свернуть все](https://faq-ru.kaiten.site/knopka-svernut-razvernut-vse-doski), [Горячие клавиши](https://faq-ru.kaiten.site/94793baa-e6cf-415a-82e6-809bb830daf1)

### Колонки, подколонки, дорожки, ячейки
- **Колонки** — этапы процесса, без ограничения числа; «+» справа вверху доски → колонка (новая — в конец, тип «В работе») или «+» у колонки → «Создать колонку» слева/справа. [Добавление колонок](https://faq-ru.kaiten.site/16cfa08d-513a-4a0d-a921-d360add50763)
- **Подколонки** — «+» у колонки → добавить две подколонки (второй уровень); на статус не влияют. [Виды досок](https://faq-ru.kaiten.site/vidy-dosok-v-kaiten), [Типы колонок](https://faq-ru.kaiten.site/4703c052-d591-45eb-bc45-be8481b6a05f)
- **Типы колонок** — ⋯ колонки → «Тип колонки»: Очередь / В работе / Готово (тип ≠ название). [Типы колонок](https://faq-ru.kaiten.site/4703c052-d591-45eb-bc45-be8481b6a05f)
- **Эффекты типа колонки** — перенос в «В работе»/«Готово» добавляет перемещающего участником и, если нет ответственного, ответственным (отключаемо); «Готово» останавливает таймеры, красит срок зелёным/красным, снимает блокировки, где эта карточка — блокер; смена типа колонки на «Готово» завершает все карточки в ней. [Типы колонок](https://faq-ru.kaiten.site/4703c052-d591-45eb-bc45-be8481b6a05f)
- **Автоназначение при создании** — создатель карточки в колонке «В работе»/«Готово» сразу становится участником и ответственным. [Автоназначение](https://faq-ru.kaiten.site/avtomaticheskoe-naznachenie-ispolniteley-i-otvetstvennogo)
- **Дорожки** — горизонтальные полосы (приоритет, исполнитель, заказчик, направление, бэклог); «+» справа вверху → дорожка (добавляется вниз); можно свернуть. [Дорожки](https://faq-ru.kaiten.site/990d1304-0a1d-4702-aea8-d47aedf23a91), [Удаление колонок](https://faq-ru.kaiten.site/16cfa08d-513a-4a0d-a921-d360add50763)
- **Ячейки** — пересечение колонки и дорожки; свои правила и WIP, действуют вместе с правилами колонки и дорожки. [Колонки, дорожки, ячейки](https://faq-ru.kaiten.site/chto-takoe-kolonka-dorozhka-i-yacheyka)
- **WIP-лимит (НЗП)** — ⋯ колонки / дорожки (справа вверху) / ячейки (справа внизу) → «Установить ограничение НЗП»: по числу карточек или по сумме размеров; превышение — колонка краснеет; карандаш — изменить, корзина — удалить; только в пространстве типа «Доски». [WIP](https://faq-ru.kaiten.site/ogranicheniya-wip)
- **Нулевой WIP-лимит** — 0 = «этап пропускать»/«не брать новое»: зелёный значок в колонке/ячейке или штриховка (если нет фона). [WIP](https://faq-ru.kaiten.site/baa1bf5a-e39e-4efc-b3b6-9af94ee30439)
- **Строгий WIP (запрет)** — ограничение на создание/перенос карточек при превышении WIP — через модуль «Ограничения». [ЧН апр. 2024](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6) (платный модуль; WIP по людям в справке не найден)
- **Предупреждение о застоявшихся карточках** — ⋯ колонки → «Установить предупреждение…»: период, после которого на карточке красный бейдж «сколько стоит». [Застоявшиеся](https://faq-ru.kaiten.site/preduprezhdenie-o-zastoyavshihsya-kartochkah)
- **Скрыть долго не двигавшиеся карточки** — ⋯ колонки → «Скрыть карточки, которые долго не двигались» (период в днях): не архив, связи сохраняются; «Показать скрытые карточки» — подсветка оранжевым; заблокированные/блокирующие не скрываются. [Скрыть](https://faq-ru.kaiten.site/kak-skryt-kartochki-kotorye-dolgo-ne-dvigalis)
- **Автоархивация** — ⋯ колонки типа «Готово» или «Очередь» → через заданный срок карточки уходят в архив; исключения: заблокированные, с активными связями, публичные. [Автоархивация](https://faq-ru.kaiten.site/avtomaticheskaya-arhivaciya-kartochek)
- **Заархивировать все карточки колонки** — ⋯ внизу колонки → «Управление карточками» → «Заархивировать все карточки» (саму колонку архивировать нельзя). [Колонки и дорожки](https://faq-ru.kaiten.site/16cfa08d-513a-4a0d-a921-d360add50763)
- **Сортировка карточек в колонке** — ⋯ → «Управление карточками» → «Отсортировать карточки»: по названию, сроку, дате создания, размеру, польз. полям (select — по частоте); выбор дорожки и направления. [Сортировка](https://faq-ru.kaiten.site/sortirovka-kartochek-v-kolonke)
- **Формат колонки «Карточки / Список»** — ⋯ колонки → «Формат»: «Карточки» (название, метки, ссылки, картинка) или «Список» (минимум, одинаковая высота — для очередей). [Формат колонки](https://faq-ru.kaiten.site/c3636f1b-706a-41d1-80e9-a5cb852927ab)
- **Правило колонки «чек-листы должны быть отмечены»** — ⋯ колонки → Правила: карточка с незакрытым чек-листом в этой колонке получает красное предупреждение. [Чек-листы](https://faq-ru.kaiten.site/chek-listy-v-kartochkah)
- **Подписка на колонку** — ⋯ колонки → «Информировать меня о перемещениях»: по моим/подписанным карточкам или по всем. [Уведомления](https://faq-ru.kaiten.site/kak-nastroit-uvedomleniya-v-kaiten)
- **Удаление колонки/дорожки** — ⋯ → «Удалить»: перенести карточки на эту/другую доску или «Не перемещать карточки»; дорожка восстанавливается с карточками через Журнал событий; про колонку справка противоречива (статья: «нельзя, пишите в поддержку», ЧН дек. 2024: «восстановление удалённых колонок через журнал»). [Удаление](https://faq-ru.kaiten.site/16cfa08d-513a-4a0d-a921-d360add50763), [ЧН](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Архивация и восстановление колонок/дорожек** — убрать с доски, сохранив карточки, и вернуть обратно. [Колонки, дорожки, ячейки](https://faq-ru.kaiten.site/chto-takoe-kolonka-dorozhka-i-yacheyka)
- **Перестановка колонок и дорожек** — пункт «Переместить» в ⋯. [Виды досок](https://faq-ru.kaiten.site/vidy-dosok-v-kaiten)
- **Создание карточки наведением** — наведите на колонку → появляется прямоугольник «создать». [Создать карточку](https://faq-ru.kaiten.site/kak-sozdat-kartochku)

### Виды пространства
- **Переключатель видов** — значки в верхней панели: Доски, Списки, Таблица, Timeline, Календарь, Итерации, Файлы, Архив, Отчёты; горячие клавиши 1 Доски, 2 Timeline, 3 Таблица, 4 Календарь, 5 Архив, 6 Отчёты. [Формат и вид](https://faq-ru.kaiten.site/format-i-vid-otobrazheniya-prostranstv), [Горячие клавиши](https://faq-ru.kaiten.site/94793baa-e6cf-415a-82e6-809bb830daf1)
- **Вид «Доски»** — канбан, доски вертикально или горизонтально; сворачивание, фильтры, сортировка в колонке, компактный вид, формат колонки. [Формат и вид](https://faq-ru.kaiten.site/format-i-vid-otobrazheniya-prostranstv)
- **Вид «Списки»** — доски только горизонтально, свёрнутая доска — вертикальная полоса; дорожек нет. [Формат и вид](https://faq-ru.kaiten.site/format-i-vid-otobrazheniya-prostranstv)
- **Вид «Таблица»** — строки = карточки по порядку досок (название доски фиолетовым); дочерние карточки сворачиваются под родителем; ширина колонок запоминается; перетаскивание карточки за ручку (в блок детей → предложит создать связь); строка итогов (размер, время блокировок, суммарное время, Число/Формула/Коллективная оценка/Голосование); выполненные свёрнуты; группировка: доска / статус (колонка) / ответственный / тип карточки; сортировка 1–5 критериев; настройка полей и порядка; «Скачать» XLSX (время в минутах). [Таблица](https://faq-ru.kaiten.site/vid-prostranstva-tablica)
- **Сортируемые поля таблицы** — название, ID, колонка, дорожка, пространство, размер, срок, срочно, трудозатраты, блокировка, прогресс, даты создания/последнего перемещения/взятия/завершения, суммарное время, время блокировок, дата последнего комментария, план. начало/конец, польз. ключ; польз.: число, колл. оценка, дата, флажок, select, формула. Нельзя: метки, тип, ответственный, участники, строка, multiselect, справочник и др. [Таблица](https://faq-ru.kaiten.site/vid-prostranstva-tablica)
- **Сохранённые настройки вида** — набор «поля + сортировка + группировка» сохраняется с именем (личный) для Таблицы, Timeline, Архива. [Таблица](https://faq-ru.kaiten.site/vid-prostranstva-tablica)
- **Общая настройка вида для команды** — ⚙ пространства → «Вид» → Таблица/Timeline/Архив: порядок полей, группировка, сортировка по умолчанию для всех; личная важнее, её можно сбросить. [Общая настройка](https://faq-ru.kaiten.site/obshchaya-nastroyka-poley-v-tablicah-taymlane-i-arhive)
- **Вид «Timeline»** — таблица карточек слева + шкала справа (часы/дни/недели/месяцы); полоса создаётся кликом по ячейке, тянется за края, переносится; иконка человека — назначить ответственного, корзина — убрать даты; добавить карточку в виде; перетаскивание строки — смена колонки/дорожки; группировка и сортировка (1–5); ширины запоминаются. [Timeline](https://faq-ru.kaiten.site/vid-prostranstva-timeline-taymlayn)
- **Зависимости в Timeline** — тянуть кружок полосы на другую карточку; конфликтующие — красным; при сдвиге конца зависимые сдвигаются с учётом рабочих дней/часов; удалить — клик по линии или крестик в карточке. [Timeline](https://faq-ru.kaiten.site/vid-prostranstva-timeline-taymlayn)
- **Расчётные даты родителя** — у родителя показываются min/max дат детей; прогресс родителя = доля готовых детей. [Timeline](https://faq-ru.kaiten.site/vid-prostranstva-timeline-taymlayn)
- **Фиксация плановых дат задачи** — отключить автосдвиг дат у отдельной карточки; переключатель авто/ручного пересчёта связей и кнопка «пересчитать». [ЧН сент. 2026, июль 2026](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Выгрузка Timeline** — «Скачать» (таблица, в браузере) и «Скачать расширенный отчёт» (на сервере, ссылка на почту, вид Ганта). [Timeline](https://faq-ru.kaiten.site/vid-prostranstva-timeline-taymlayn)
- **Гант и ресурсное планирование** — из Timeline → «Ресурсное планирование»: таблица загрузки людей по часам, проекты из нескольких пространств, базовый план, вехи, лаги, рабочие часы и календари (произв. календарь РФ), нерабочие дни, виртуальные пользователи, ручное распределение часов. [Модуль Гант](https://faq-ru.kaiten.site/modul-diagramma-ganta1) (платный модуль на Standard/Business, в «Корпорации» включён)
- **Вид «Календарь»** — карточки с «Сроком», польз. «Датой» или Timeline (выбор источника слева вверху); месяц/неделя/день; перетаскивание меняет дату; клик по ячейке создаёт карточку; цвет = тип, 🔥 у «Срочно»; фильтры. [Календарь](https://faq-ru.kaiten.site/vid-prostranstva-kalendar)
- **Вид «Итерации»** — слева нераспределённые задачи, справа итерации: создать (имя, даты, цель), запустить (нужна дата конца; фиксирует объём), завершить (куда незавершённые), несколько активных одновременно, «доски, участвующие в итерациях», до 500 задач за раз, история итераций карточки, просмотр завершённых (сводка, хронология), панель активных итераций над другими видами, бейдж на фасаде, фильтр «Итерация». [Итерации](https://faq-ru.kaiten.site/novyy-vid-prostranstva-iteracii) (модуль Scrum; спринты на досках — нельзя создавать с 01.10.2026)
- **Вид «Файлы»** — все вложения карточек и комментариев пространства: имя/тип, карточка, автор, дата, размер; поиск по имени, фильтры тип/период/автор/источник; сортировка; список или плитка; массовое скачивание ZIP и удаление (удаляет и из карточки). [Файлы](https://faq-ru.kaiten.site/vse-fayly-prostranstva-v-odnom-meste)
- **Вид «Архив»** — см. раздел 3 «Архив». [Архив](https://faq-ru.kaiten.site/arhiv)
- **Вид «Отчёты»** — 16 отчётов: CFD, распределение карточек, сроки по задачам, время цикла, контрольный график, спектральная диаграмма, динамика времени цикла, время разрешения блокировок, пропускная способность, burndown итерации, velocity, burndown дочерних задач (из карточки), суммарный отчёт, моё время, время сотрудников, воронка продаж. [Отчёты](https://faq-ru.kaiten.site/polnoe-rukovodstvo-po-otchetam)
- **«Пользователи» пространства** — значок в правой панели: список участников, приглашение (+), индикатор запросов на доступ. [Интерфейс](https://faq-ru.kaiten.site/interfeys-kaiten), [Запрос участника](https://faq-ru.kaiten.site/dobavlenie-uchastnikov-v-kartochku-cherez-zapros)
- **Правая панель пространства** — Пользователи, последние обновления, запланированные задания, массовые действия, автоматизации, ограничения, дополнения, «Поделиться» (публичный доступ), Workflow. [Интерфейс](https://faq-ru.kaiten.site/interfeys-kaiten)

### Вид карточек (фасад)
- **Полный / компактный вид карточек** — кнопка карточек справа вверху → панель видов (вкладки Все/Мои/Команды/Системные) с превью; применить к текущему пространству или ко всем. Полный: участники, польз. поля, срок, метки, ссылки и вложения, связи, чек-листы, размер, блокировки; компактный: название, тип, участники, срок, блокировки. [Вид карточек](https://faq-ru.kaiten.site/polnyy-kompaktnyy-i-polzovatelskiy-vid)
- **Пользовательский вид карточек** — «Создать вид»: набор и порядок полей (только польз. поля с флажком «показывать на фасаде»), опции: общий для коллег, показывать названия полей, однострочные карточки (в формате «Список»), показывать родителей; админ-раздел «Виды карточек». [Вид карточек](https://faq-ru.kaiten.site/polnyy-kompaktnyy-i-polzovatelskiy-vid) (свои виды — Standard/Business/Corporation; общие — платный аккаунт; в мобильном не создаются)
- **Родители на фасаде дочерней карточки** — ссылка на родителя в один клик, до 10 родителей из других пространств, по возрастанию ID. [Родитель/ребёнок](https://faq-ru.kaiten.site/roditelskie-i-dochernie-kartochki)
- **Подсветка номеров карточек** — клавиша `i` на пространстве показывает ID карточек. [Горячие клавиши](https://faq-ru.kaiten.site/94793baa-e6cf-415a-82e6-809bb830daf1)
- **Бейдж нерабочего дня на аватаре** — красная метка на аватаре на время отпуска/больничного, даты по наведению. [Нерабочие дни на аватаре](https://faq-ru.kaiten.site/3a243a27-ea68-4f42-b349-95736a6529c1)
- **Карточка пользователя при наведении на аватар** — всплывающая информация о пользователе. [ЧН апр. 2024](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)

## 3. Карточки

### Создание
- **Создание в колонке** — навести на колонку и кликнуть появившийся прямоугольник, или «+» у колонки → карточка; «Добавить» в шапке пространства; клавиша `c` — диалог новой карточки. [Создать карточку](https://faq-ru.kaiten.site/kak-sozdat-kartochku), [Горячие клавиши](https://faq-ru.kaiten.site/94793baa-e6cf-415a-82e6-809bb830daf1)
- **Несколько карточек из списка** — вставить многострочный текст в название создаваемой карточки → «Создать»/Shift+Enter → «Создать несколько»: одна строка = одна карточка. [Из списка](https://faq-ru.kaiten.site/sozdanie-neskolkih-kartochek-iz-spiska)
- **Карточки из картинок** — Ctrl/Cmd+V над колонкой/дорожкой: каждая картинка → карточка с обложкой, имя файла → название; прочие файлы — вложениями. [Создать карточку](https://faq-ru.kaiten.site/kak-sozdat-kartochku)
- **Создание в Календаре и Timeline** — клик по ячейке даты / «Добавить карточку» в Timeline. [Календарь](https://faq-ru.kaiten.site/vid-prostranstva-kalendar)
- **Карточка из письма** — у пространства генерируется email-адрес, привязанный к доске/колонке/дорожке; письмо → карточка, вложения ≤ 20 МБ суммарно; адрес меняется при смене места. [Email-интеграция](https://faq-ru.kaiten.site/64790f58-7fd0-4b40-b8bc-0adfca8c8a15) (настраивает админ пространства)
- **Карточка из мессенджеров** — Telegram (@KaitenBot: текст → карточка, выбор пути, сохранённые пути `/options`), Slack (из сообщения), Max. [Telegram](https://faq-ru.kaiten.site/kak-nastroit-telegram-uvedomleniya)
- **Карточка из браузера (AI-расширение)** — выделить текст на любой странице → карточка с заполненными названием и описанием. [AI](https://faq-ru.kaiten.site/ai-v-kaiten) (экспериментально)
- **Количество карточек** — не ограничено. [Создать карточку](https://faq-ru.kaiten.site/kak-sozdat-kartochku)

### Встроенные поля
- **Добавление поля в карточку** — фиолетовая кнопка «+» слева вверху карточки → список полей (Срок, Размер, Метки, Ссылка, Чек-лист, Файл, Дочерняя/Родительская карточка, польз. поля, «Создать своё поле»). [Срок](https://faq-ru.kaiten.site/srok-dedlayn-kartochki)
- **Название** — клик по названию → правка → «Сохранить»/Enter. [Создать карточку](https://faq-ru.kaiten.site/kak-sozdat-kartochku)
- **Описание** — см. «Описание». [Основные поля](https://faq-ru.kaiten.site/osnovnye-polya-v-kartochke)
- **Заказчик** — создатель карточки автоматически; меняется кликом по имени. [Участники](https://faq-ru.kaiten.site/uchastniki)
- **Участники (исполнители)** — «Добавить участников»: пользователи с доступом к пространству или целая группа (вкладка «Группы»). [Участники](https://faq-ru.kaiten.site/uchastniki)
- **Ответственный** — ровно один на карточку: клик по аватару участника → «Сделать ответственным»; «Исключить из карточки»; горячие клавиши `a` (назначить), `i` (себя). [Участники](https://faq-ru.kaiten.site/uchastniki), [Горячие клавиши](https://faq-ru.kaiten.site/94793baa-e6cf-415a-82e6-809bb830daf1)
- **Пригласить в карточку человека не из пространства** — «+» в «Участниках» → пригласить: человек добавляется и в карточку, и в пространство с выбранной ролью. [Участники](https://faq-ru.kaiten.site/uchastniki) (нужно право приглашения в аккаунт или доступ к админ-разделу «Пользователи»)
- **Запрос на добавление участника** — комментатор / «только свои карточки» отправляет запрос (логин/email + комментарий) → решают админ «Пользователей» или владелец; уведомления о запросе/решении; право роли «Приглашать участников пространства в карточки» снимает необходимость запроса. [Запрос](https://faq-ru.kaiten.site/dobavlenie-uchastnikov-v-kartochku-cherez-zapros)
- **Срок** — дата + опционально время («Установить время»); время по часовому поясу браузера; «Убрать дату»; нельзя ставить в колонке «Готово»; после завершения зелёный (вовремя) / красный (позже). [Срок](https://faq-ru.kaiten.site/srok-dedlayn-kartochki)
- **«Срочно»** — флажок в окне срока: красная плашка «Срочно» на фасаде, 🔥 в календаре. [Срок](https://faq-ru.kaiten.site/srok-dedlayn-kartochki)
- **«Не позднее» (ASAP-бомба)** — флажок: задача теряет смысл после даты, на фасаде значок бомбы. [Срок](https://faq-ru.kaiten.site/srok-dedlayn-kartochki)
- **Напоминание о сроке** — клик по сроку → «Напомнить» → время; получают участники и подписчики. [Уведомления](https://faq-ru.kaiten.site/kak-nastroit-uvedomleniya-v-kaiten)
- **Плановые даты (Timeline)** — поле Timeline: план. начало/конец (+ расчётные у родителя). [Timeline](https://faq-ru.kaiten.site/vid-prostranstva-timeline-taymlayn)
- **Размер** — свободное значение (часы, SP, рубли, S/M/L), на фасаде с молнией; суммы по колонке/дорожке/доске, WIP по размеру, burndown/velocity. [Размер](https://faq-ru.kaiten.site/razmer-kartochki-zadachi)
- **Тип карточки** — один из справочника, цветная полоса слева вверху на фасаде (клик по ней — смена типа). [Типы карточек](https://faq-ru.kaiten.site/tipy-kartochek)
- **Метки** — цветные, без ограничения числа на карточку; создаются прямо в карточке, видны только в доступных пространствах; клик по метке на фасаде — фильтр; правка/удаление — у кого есть админ-раздел «Метки» (там же колонка «Карточки» для поиска неиспользуемых); горячая клавиша `l`. [Метки](https://faq-ru.kaiten.site/metki-tegi-leybly)
- **Ссылки** — без ограничений: внешний URL + описание, или карточка/документ/Story Map по названию/ID; видны на фасаде; ⋯ — изменить/удалить. [Ссылки](https://faq-ru.kaiten.site/ssylki)
- **Файлы** — см. «Вложения». [Основные поля](https://faq-ru.kaiten.site/osnovnye-polya-v-kartochke)
- **Обложка** — ⋯ у картинки → «Сделать обложкой» (из вложений или комментария); правило доски — первая картинка из описания становится обложкой; убрать обложку, оставив файл. [Обложка](https://faq-ru.kaiten.site/oblozhka-kartochki)
- **Поле Workflow** — блок в карточке с текущим этапом и разрешёнными переходами. [ЧН янв. 2026](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Поле «Итерация»** — название итерации в карточке, смена, переход, удаление из итерации. [Итерации](https://faq-ru.kaiten.site/novyy-vid-prostranstva-iteracii)
- **Расположение (путь)** — поле «Расположение» в карточке, клик → окно перемещения. [Перемещение](https://faq-ru.kaiten.site/peremeshchenie-kartochki)
- **Прогресс карточки** — (отмеченные пункты чек-листов + готовые дети) / (все пункты + все дети); можно заменить формулой (для всего аккаунта). [Родитель/ребёнок](https://faq-ru.kaiten.site/roditelskie-i-dochernie-kartochki), [Формула](https://faq-ru.kaiten.site/polzovatelskoe-pole-formula)
- **Правило 10 %** — поле, заполненное примерно в 10 % карточек доски/типа, автоматически появляется (пустым) во всех; удалить из карточки нельзя; отключается в типе карточки. [Правило 10 %](https://faq-ru.kaiten.site/pochemu-v-kartochke-avtomaticheski-poyavlyayutsya-polya-pravilo-10)
- **Порядок полей в карточке** — системные → поля типа карточки (в порядке типа) → поля доски → поля по правилу 10 % → добавленные вручную (по алфавиту). [Порядок полей](https://faq-ru.kaiten.site/kak-formiruetsya-poryadok-poley-v-kartochke)
- **Сворачиваемые разделы** — у описания, файлов, чек-листов, ссылок, связей, блокировок, Workflow, полей — кнопка свернуть; в свёрнутом виде сводка (число файлов, X/Y пунктов, этап, начало текста); состояние запоминается для карточки. [Сворачиваемые разделы](https://faq-ru.kaiten.site/svorachivaemye-razdely-v-kartochkah-7f41cb10-7e94-4f18-a73a-ba377b789e23) (on-prem ≥ 57.651.0)

### Типы карточек
- **Типы карточек** — Администрирование → «Типы карточек» → «Добавить»: название, эмодзи или буква, цвет, шаблон описания, предлагаемые и обязательные поля (порядок перетаскиванием), флажок автопредложения полей (10 %); по умолчанию тип «Карточка» (не показывается). [Типы](https://faq-ru.kaiten.site/tipy-kartochek)
- **Удаление типа** — с заменой на другой тип у затронутых карточек. [Типы](https://faq-ru.kaiten.site/tipy-kartochek)
- **Скрытые типы в пространстве** — ⚙ пространства: отметить типы, которые скрыть (новые типы видны сразу); скрытый не предлагается нигде, включая автоматизации; для доски на нескольких пространствах — по текущему. [Скрытые типы](https://faq-ru.kaiten.site/skrytye-tipy-kartochek-na-prostranstve)
- **Пути использования типа** — в типе карточки указать сущности (и вложенные), где его можно выбирать; уже назначенный тип остаётся у карточек; набор типов доски — по её главному пространству. [Пути](https://faq-ru.kaiten.site/puti-ispolzovaniya-tipov-kartochek) (Start, Standard, Business, on-prem)
- **Шаблон описания** — у типа карточки задаётся текст-шаблон описания (аналог «шаблона карточки»; отдельной функции «шаблоны карточек» в справке нет). [Типы](https://faq-ru.kaiten.site/tipy-kartochek)

### Чек-листы
- **Чек-листы в карточке** — несколько на карточку; «+» → «Чек-лист»; создают редакторы и админы; прогресс-бар; у отмеченного пункта — кто и когда; «Скрыть отмеченные». [Чек-листы](https://faq-ru.kaiten.site/chek-listy-v-kartochkah)
- **Вставка списка в чек-лист** — вставить многострочный текст → кнопка «Добавить N пунктов». [Чек-листы](https://faq-ru.kaiten.site/chek-listy-v-kartochkah)
- **Ответственный и срок пункта** — клик по пункту: «Добавить ответственного» (один) и «Добавить срок выполнения» (дата + напоминание); цвета: зелёный — вовремя, красный — позже, жёлтый — сегодня. [Чек-листы](https://faq-ru.kaiten.site/chek-listy-v-kartochkah)
- **Чек-лист на фасаде** — название и прогресс-бар; клик по нему на доске открывает подробный прогресс без открытия карточки. [Чек-листы](https://faq-ru.kaiten.site/chek-listy-v-kartochkah)
- **Конвертация чек-листа в дочерние карточки** — ⋯ чек-листа → «Конвертировать…»: доска/колонка/дорожка, сроки, размер, тип; удалить или оставить чек-лист; создавать ли связь с родителем. [Чек-листы](https://faq-ru.kaiten.site/chek-listy-v-kartochkah) (Standard/PRO)
- **Перенести / скопировать чек-лист в другую карточку** — ⋯ → «Перенести…»/«Скопировать…», выбор пунктов (по умолчанию копируются только невыполненные; у переноса — флажок «только невыполненные»). [Чек-листы](https://faq-ru.kaiten.site/chek-listy-v-kartochkah)
- **Общий чек-лист** — ⋯ → «Сделать общим чек-листом» с другой карточкой: изменения синхронны везде. [Чек-листы](https://faq-ru.kaiten.site/chek-listy-v-kartochkah)
- **Копировать чек-лист в буфер / удалить** — ⋯ чек-листа. [Чек-листы](https://faq-ru.kaiten.site/chek-listy-v-kartochkah)
- **Шаблонные чек-листы** — Автоматизации → «Шаблонные чек-листы»: создать шаблон; добавляется в карточки автоматизацией (действие «Добавить шаблонный чек-лист», напр. при входе в колонку); можно запретить перемещение, пока не выполнен. [Шаблонные](https://faq-ru.kaiten.site/shablonnye-chek-listy-2)
- **Чек-листы и Markdown** — пункт чек-листа поддерживает редактор/Markdown. [Описание](https://faq-ru.kaiten.site/opisanie-kartochki)

### Связи и блокировки
- **Родительские и дочерние карточки** — «+» → «Дочерняя/Родительская карточка»: создать новую (выбор доски/колонки, обязательные поля) или привязать существующую (дерево/поиск); у карточки может быть несколько родителей; глубина не ограничена; блок «Связи» с режимом «Таблица». [Родитель/ребёнок](https://faq-ru.kaiten.site/roditelskie-i-dochernie-kartochki), [Гайд Trello](https://faq-ru.kaiten.site/gayd-dlya-teh-kto-pereshel-iz-trello-v-kaiten)
- **Фильтры в блоке связей** — три кнопки скрывают связанные в очереди / в работе / готовые. [Родитель/ребёнок](https://faq-ru.kaiten.site/roditelskie-i-dochernie-kartochki)
- **Порядок детей** — по положению на доске (левее колонка, выше в колонке — раньше). [Родитель/ребёнок](https://faq-ru.kaiten.site/roditelskie-i-dochernie-kartochki)
- **Ребёнок перетаскиванием** — Alt/Option + перетаскивание карточки; Shift+C — создать дочернюю, Shift+K — привязать к существующей как к родителю. [Горячие клавиши](https://faq-ru.kaiten.site/94793baa-e6cf-415a-82e6-809bb830daf1)
- **Burndown дочерних задач** — отчёт из блока «Связи» родителя. [Отчёты](https://faq-ru.kaiten.site/polnoe-rukovodstvo-po-otchetam)
- **Горизонтальные связи** — «+» → «Ссылка» → карточка по названию/ID/URL; видна в обеих (если есть доступ), удаление с одной стороны удаляет обе. [Горизонтальные](https://faq-ru.kaiten.site/gorizontalnye-svyazi-kartochek)
- **Архив разрывает связи** — архивация ребёнка/родителя удаляет связь (ребёнок, архивированный из «Готово», остаётся в архивном родителе); альтернатива — скрытие застоявшихся. [Родитель/ребёнок](https://faq-ru.kaiten.site/roditelskie-i-dochernie-kartochki)
- **Блокировка** — кнопка «!» в карточке → причина → «Заблокировать»; на фасаде красное поле; несколько независимых блокировок на карточке (счётчик на фасаде, выпадающий список причин); клавиша `b`. [Блокировка](https://faq-ru.kaiten.site/blokirovka-kartochki)
- **Карточка-блокер** — «Добавить карточку-блокер» (существующая или новая); обе карточки показывают связь; блокировка снимается сама, когда блокер попадает в «Готово». [Блокировка](https://faq-ru.kaiten.site/blokirovka-kartochki)
- **Атрибуты блокировки** — срок, категории (правки, баг, отпуск, ждём ответа…), участники (получают уведомления). [Блокировка](https://faq-ru.kaiten.site/blokirovka-kartochki)
- **Разблокировка** — «Разблокировать»; также из Slack. [Блокировка](https://faq-ru.kaiten.site/blokirovka-kartochki)
- **Статус блокировки в фильтре** — «заблокирована» / «блокирует другие». [Фильтр](https://faq-ru.kaiten.site/filtraciya-zadach)

## 4. Пользовательские поля и формулы

- **Где создаются** — Администрирование → «Пользовательские поля» (компания-уровень) или «+» в карточке → «Создать своё поле»; создают владелец и имеющие доступ к разделу. [Создать поле](https://faq-ru.kaiten.site/kak-sozdat-polzovatelskoe-pole)
- **Привязка поля к сущностям** — выбор сущностей (пространств), где поле применяется, и где оно показывается при создании карточки. [ЧН дек. 2025](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Строка** — однострочная или многострочная, лимит мин/макс символов (Markdown-символы считаются). [Типы полей](https://faq-ru.kaiten.site/tipy-polzovatelskih-poley), [Ограничения значений](https://faq-ru.kaiten.site/kak-ustanovit-ogranichenie-znacheniy-v-polzovatelskih-polyah)
- **Число** — мин/макс значение (вне диапазона не сохранить); на фасаде; фильтр; сумма по доске. [Типы полей](https://faq-ru.kaiten.site/tipy-polzovatelskih-poley)
- **Email** — отправка письма из карточки. [Типы полей](https://faq-ru.kaiten.site/tipy-polzovatelskih-poley)
- **Телефон** — звонок из карточки. [Типы полей](https://faq-ru.kaiten.site/tipy-polzovatelskih-poley)
- **Селект** — одно значение из списка; опция «пользователи могут добавлять значения» (имеющие право на поля могут всегда). [Типы полей](https://faq-ru.kaiten.site/tipy-polzovatelskih-poley)
- **Мультиселект** — несколько значений, та же опция добавления. [Типы полей](https://faq-ru.kaiten.site/tipy-polzovatelskih-poley)
- **Дата** — дата и время, на фасаде, в фильтрах, источник для Календаря. [Типы полей](https://faq-ru.kaiten.site/tipy-polzovatelskih-poley)
- **Флажок** — отмечен — может показываться на фасаде, не отмечен — не виден; используется в фильтрах, отчётах, автоматизациях, ограничениях. [Типы полей](https://faq-ru.kaiten.site/tipy-polzovatelskih-poley)
- **Пользователь** — заинтересованные лица без участия в задаче (эксперт, согласующий); «Множественный выбор» нельзя изменить после сохранения; люди из поля получают уведомления. [Типы полей](https://faq-ru.kaiten.site/tipy-polzovatelskih-poley), [ЧН март 2024](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Справочник** — мини-CRM: записи с любым числом текстовых полей (первое обязательно и на фасаде), общий цвет; записи в разделе «Записи» или из карточки (можно запретить); импорт из .xls с сопоставлением колонок. [Типы полей](https://faq-ru.kaiten.site/tipy-polzovatelskih-poley), [Импорт справочника](https://faq-ru.kaiten.site/import-dannyh-v-spravochnik-iz-faylov-xls)
- **Коллективная оценка** — несколько человек вводят оценку (planning poker, RICE/ICE): «Пригласить коллег» копирует ссылку; итог: минимум, максимум, медиана, среднее или своё значение. [Колл. оценка](https://faq-ru.kaiten.site/kollektivnaya-ocenka-razmera-kartochki-2)
- **Голосование** — эмодзи-шкала или набор эмодзи; индивидуальный (новая оценка заменяет) или коллективный (среднее); на фасаде. [Типы полей](https://faq-ru.kaiten.site/tipy-polzovatelskih-poley)
- **Вложение** — файлы по правилам: допустимые расширения, макс. число. [Типы полей](https://faq-ru.kaiten.site/tipy-polzovatelskih-poley)
- **Формула** — вычисление по числовым/строковым полям, другим формулам и встроенным метрикам; авто-пересчёт; пустое исходное поле → не считается. [Формула](https://faq-ru.kaiten.site/polzovatelskoe-pole-formula)
- **Синтаксис формулы** — `prop("Имя поля")`, инфиксные операторы и скобки, `;` между выражениями (результат — последнее), присваивание `res = …`, тернарный `усл ? a : b`, неявное умножение `2 pi`; функции `sqrt`, `log(x, base)`, `sin`… (библиотека math.js); константы e, pi, phi, tau, LN2, LN10, SQRT2, null…; зарезервированы mod, to, in, and, xor, or, not, end. [Формула](https://faq-ru.kaiten.site/polzovatelskoe-pole-formula)
- **Встроенные метрики в формуле** — `size`, `goals_total`, `goals_done`, `children_count`, `children_done`, `parents_count`, `time_spent_sum` (мин), `time_blocked_sum` (мин), `children_number_properties_sum.size`, `children_number_properties_sum.time_spent_sum`, `estimate_workload`. [Формула](https://faq-ru.kaiten.site/polzovatelskoe-pole-formula)
- **Формула как прогресс** — выбрать поле-формулу полем прогресса: % на фасаде, в Timeline и Таблице; действует на все пространства, прогресс по чек-листам/детям скрывается. [Формула](https://faq-ru.kaiten.site/polzovatelskoe-pole-formula)
- **Пример: оплата по часам** — `prop("time_spent_sum")/60 * prop("Ставка")` + суммарный отчёт за период. [Оплата](https://faq-ru.kaiten.site/8f269004-12bf-4209-8bb4-1fb2a0527776)
- **Обязательность** — у типа карточки («Обязательное», звёздочка, жёлтое предупреждение на фасаде) или у доски (по дорожкам/колонкам и типам); блокировать перемещение без заполнения — через модуль «Ограничения» (сообщение называет незаполненные поля). [Обязательные поля](https://faq-ru.kaiten.site/obyazatelnye-polya), [ЧН март 2026](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Обязательные поля при создании связанных карточек** — при создании дочерней/родительской нужно заполнить обязательные поля цели. [Родитель/ребёнок](https://faq-ru.kaiten.site/roditelskie-i-dochernie-kartochki)

- **Скрытие полей ролью** — кастомная роль может скрывать отдельные поля карточки; доступ к полям на уровне ролей. [ЧН март 2024, авг. 2023](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)

## 5. Фильтры, поиск, сохранённые фильтры

- **Кнопка «Фильтры»** — в верхней панели пространства; добавить один критерий → «Развернуть» — расширенное окно; Shift+F — свернуть/развернуть панель фильтров. [Фильтр](https://faq-ru.kaiten.site/filtraciya-zadach), [Горячие клавиши](https://faq-ru.kaiten.site/94793baa-e6cf-415a-82e6-809bb830daf1)
- **Критерии: люди** — название (содержит/не содержит), заказчик, автор заявки СП, участник (в любой роли, вкл./искл.), ответственный. [Фильтр](https://faq-ru.kaiten.site/filtraciya-zadach)
- **Критерии: идентификаторы** — ID и польз. ключ: одно значение или список, «в списке / не в списке». [Фильтр](https://faq-ru.kaiten.site/filtraciya-zadach)
- **Критерии: атрибуты** — срочность, статус блокировки, метки (любая/конкретные/исключить), тип (задан/нет), размер (задан, точное/относительное), польз. поля, источник (API, Telegram, автоматизации…), итерация (это/не/любая/не установлена), проект ресурсного планирования, сервис и организация СП. [Фильтр](https://faq-ru.kaiten.site/filtraciya-zadach), [Итерации](https://faq-ru.kaiten.site/novyy-vid-prostranstva-iteracii)
- **Критерии: расположение** — статус (тип колонки) и путь (конкретная колонка/дорожка, показать/скрыть). [Фильтр](https://faq-ru.kaiten.site/filtraciya-zadach)
- **Критерии: связи** — есть родитель/ребёнок, связь с конкретными карточками. [Фильтр](https://faq-ru.kaiten.site/filtraciya-zadach)
- **Критерии: даты** — завершена, создана, последнее перемещение, обновлена (без комментариев, чек-листов, меток и т.п.), взята в работу, план. начало/конец, срок (есть; выполнена ли в срок), последний комментарий; точные или относительные (последние 7 дней, до даты…). [Фильтр](https://faq-ru.kaiten.site/filtraciya-zadach)
- **Группы условий И/ИЛИ** — внутри группы И или ИЛИ; между группами — один оператор на все; число групп не ограничено. [Фильтр](https://faq-ru.kaiten.site/filtraciya-zadach)
- **Сохранённые (личные) фильтры** — сохранить набор под именем; по умолчанию во всех пространствах, можно ограничить текущим (и вложенными). [Фильтр](https://faq-ru.kaiten.site/filtraciya-zadach)
- **Публичные фильтры** — «Фильтры» → сохранить → флажок «Публичный фильтр» (+ «распространять на вложенные»): вкладка «Публичные» видна всем участникам, менять нельзя; создают админы или роль с правом «Управление публичными фильтрами». [Фильтр](https://faq-ru.kaiten.site/filtraciya-zadach)
- **Фильтр по клику на метку** — клик по метке на фасаде показывает все карточки с ней. [Метки](https://faq-ru.kaiten.site/metki-tegi-leybly)
- **Фильтр через активную итерацию** — клик по итерации на панели над видами. [Итерации](https://faq-ru.kaiten.site/novyy-vid-prostranstva-iteracii)
- **Фильтры во всех видах** — доски, списки, таблица, timeline, календарь, архив, выбор карточек в документах; на дашбордах — сохраняемые наборы. [ЧН март 2025, авг. 2026](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Фильтр в «Личном»** — по любым параметрам по всем пространствам. [Личное](https://faq-ru.kaiten.site/razdel-lichnoe)
- **Глобальный поиск** — строка в самом верху (Ctrl/Cmd+K — быстрый поиск): по карточкам, документам, папкам, Story Map; по названиям или названиям + содержимому (описание, чек-листы, комментарии); фильтры для карточек: пространство, статус (активные/архивные/любые), метки, тип. [Глобальный поиск](https://faq-ru.kaiten.site/globalnyy-poisk)
- **Поиск по номеру** — число сначала ищется как точный ID (первым в выдаче), затем в тексте. [Глобальный поиск](https://faq-ru.kaiten.site/globalnyy-poisk)
- **Синтаксис поиска** — слова через И, подстрока по умолчанию; `~` — нечёткий (1 символ); `*` — часть числа (`123*`); `"…"` — точная фраза; `\` — разбить длинное число. [Глобальный поиск](https://faq-ru.kaiten.site/globalnyy-poisk)
- **Выдача поиска** — подсветка совпадений, значок типа, фрагмент с местом совпадения (описание/чек-лист/комментарий), сортировка по дате изменения; при возврате — прежние результаты и подсветка последнего открытого; настройки поиска запоминаются до перезагрузки. [Глобальный поиск](https://faq-ru.kaiten.site/globalnyy-poisk)
- **Поиск в архиве** — Фильтры → Название (содержит / начинается с / равно), по ID. [Архив](https://faq-ru.kaiten.site/arhiv), [ЧН](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Поиск в окне перемещения/выбора пути** — по названию пространства/доски/колонки с полным путём. [Окно выбора пути](https://faq-ru.kaiten.site/s-4-fevralya-edinoe-okno-vybora-puti-v-strukture-kaiten)
- **Поиск файлов** — в виде «Файлы» по имени (без учёта регистра). [Файлы](https://faq-ru.kaiten.site/vse-fayly-prostranstva-v-odnom-meste)

## 6. Учёт времени

- **Модуль «Учёт времени»** — сотрудники пишут время на задачи, руководители видят загрузку, расчёт почасовой оплаты. [Модуль](https://faq-ru.kaiten.site/5374ee81-166a-445a-948e-50a5ac4da2f6) (платный модуль)
- **Таймер** — значок ▶ вверху карточки → дата и время начала, комментарий, роль → «Запустить таймер»; тикает в верхней панели Kaiten; стоп — клик по времени → «Остановить таймер и сохранить»; клавиша `q`. [Таймер](https://faq-ru.kaiten.site/e17b01ef-1bfc-4999-ba18-8b4f7f99d7bf)
- **Автостоп таймера** — перенос карточки в колонку «Готово» останавливает таймеры. [Типы колонок](https://faq-ru.kaiten.site/4703c052-d591-45eb-bc45-be8481b6a05f)
- **Ручная запись** — ⋯ карточки → «Учёт времени» → «Записать время» → «Добавить». [Учёт в карточке](https://faq-ru.kaiten.site/uchet-vremeni-raboty-s-kartochkoy)
- **Комментарий к записи** — что сделано за это время. [Учёт в карточке](https://faq-ru.kaiten.site/uchet-vremeni-raboty-s-kartochkoy)
- **Роли учёта времени** — «Дизайнер», «Верстальщик»… (не роли доступа); создаются в админ-разделе «Роли пользователей»; руководитель видит время по видам работ. [Учёт в карточке](https://faq-ru.kaiten.site/uchet-vremeni-raboty-s-kartochkoy)
- **Редактирование записи** — только автор (ни владелец, ни админ); в карточке или в табличном виде «Личного». [Редактирование](https://faq-ru.kaiten.site/7e76a81a-6409-44d6-9506-e7f022787f0c)
- **Видимость чужого времени в карточке** — по умолчанию видно только своё; право «Чтение записей коллег в разделе карточки "Учёт времени"» (Пользователи → Редактировать). [Учёт в карточке](https://faq-ru.kaiten.site/uchet-vremeni-raboty-s-kartochkoy)
- **Личный отчёт о времени** — Личное → «Учёт времени»: период неделя/месяц/свой; таблица по дням, колонки «План» (из ресурсного планирования, серым) и «Факт»; итоги; дописать забытое время прямо в ячейке; «Скачать» Excel. [Мой отчёт](https://faq-ru.kaiten.site/f605e20b-239d-47f1-8f29-4fd1a50b6c9a)
- **Отчёт по сотрудникам (админ)** — раздел «Учёт времени»: записи всех; фильтры пространства, сотрудники, метки, доски, колонки, период; группировка по карточке или пользователю; экспорт Excel. [Время сотрудников](https://faq-ru.kaiten.site/1e167b1a-f494-410e-96da-afc1b7e258d2), [Отчёты](https://faq-ru.kaiten.site/polnoe-rukovodstvo-po-otchetam)
- **Суммарное время в таблице/архиве/суммарном отчёте** — поле «Суммарное время» (в xlsx — минуты); есть «Время блокировок». [Таблица](https://faq-ru.kaiten.site/vid-prostranstva-tablica)
- **Время в формулах** — `time_spent_sum`, сумма по детям. [Формула](https://faq-ru.kaiten.site/polzovatelskoe-pole-formula)
- **Ограничение по учёту времени** — модуль «Ограничения» может запрещать действия с карточкой без записей времени. [ЧН июнь 2023](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Нет в справке** — блокировки периода (закрытие месяца), одновременность таймеров, удаление записи — не описаны.

## 7. Уведомления

- **Каналы** — внутренние (колокольчик/панель), email, Telegram (@KaitenBot), Slack, Max, мобильный push; у каждого свой переключатель и свой набор событий; ничего не отмечено — ничего не придёт. [Настройка](https://faq-ru.kaiten.site/kak-nastroit-uvedomleniya-v-kaiten), [Уведомления](https://faq-ru.kaiten.site/uvedomleniya-v-kaiten)
- **События (11)** — назначен ответственным; добавлен участником; исключён; упоминание; ответственный за пункт чек-листа; блокировка; разблокировка; новый комментарий; изменено описание; изменён срок; карточка перемещена/создана в колонке; плюс «Напоминание о сроке», «Запросы на доступ к сущностям». [Настройка](https://faq-ru.kaiten.site/kak-nastroit-uvedomleniya-v-kaiten), [Запрос](https://faq-ru.kaiten.site/dobavlenie-uchastnikov-v-kartochku-cherez-zapros)
- **Кому приходит** — участник, ответственный, заказчик, подписчик карточки/колонки/пространства, люди в польз. поле «Пользователь», участники блокировки. [Не приходят](https://faq-ru.kaiten.site/chto-delat-esli-uvedomleniya-ne-prihodyat), [Блокировка](https://faq-ru.kaiten.site/blokirovka-kartochki)
- **Не о своих действиях** — автор действия (включая самоупоминание) уведомление не получает. [Не приходят](https://faq-ru.kaiten.site/chto-delat-esli-uvedomleniya-ne-prihodyat)
- **Подписка на карточку** — ⋯ → «Подписаться». [Настройка](https://faq-ru.kaiten.site/kak-nastroit-uvedomleniya-v-kaiten)
- **Подписка на пространство** — ⋯ у пространства → «Подписаться на все карточки» (напоминания о сроках по ней не идут). [Настройка](https://faq-ru.kaiten.site/kak-nastroit-uvedomleniya-v-kaiten)
- **Подписка на колонку** — «Информировать меня о перемещениях»: только мои/подписанные или все карточки; управление подписками — и в профиле. [Настройка](https://faq-ru.kaiten.site/kak-nastroit-uvedomleniya-v-kaiten)
- **Ежедневная сводка дедлайнов** — «Ежедневное оповещение о дедлайнах»: утром список сроков своих и подписанных карточек, за 7 дней до срока; без «Готово» и архива. [Настройка](https://faq-ru.kaiten.site/kak-nastroit-uvedomleniya-v-kaiten)
- **Напоминания о сроке** — у карточки (участникам и подписчикам) и у пункта чек-листа (только ответственному за пункт), время выбирается. [Настройка](https://faq-ru.kaiten.site/kak-nastroit-uvedomleniya-v-kaiten)
- **Задержка уведомления о комментарии** — ~1 минута (чтобы попала правка). [Комментарии](https://faq-ru.kaiten.site/kommentirovanie-kartochek)
- **Панель уведомлений** — счётчик непрочитанных, фильтр «все/непрочитанные», «прочитать все», вход в настройки. [Моб. приложение](https://faq-ru.kaiten.site/f831cd50-92b9-40b3-96ea-8c53b28266e1)
- **Telegram: личные подписки** — `/subscriptions` → «Личные сообщения» → аккаунт/пространство/доска/колонка/дорожка → события. [Telegram](https://faq-ru.kaiten.site/kak-nastroit-telegram-uvedomleniya)
- **Telegram: групповые чаты** — `/subscriptions` → «Групповые чаты»: подписать чат на пространства/доски/колонки/дорожки, разные события для разных колонок; видят все в чате независимо от личных настроек. [Telegram](https://faq-ru.kaiten.site/kak-nastroit-telegram-uvedomleniya)
- **Telegram: действия из уведомления** — «Добавить комментарий», «Ответить @username», файлы. [Telegram](https://faq-ru.kaiten.site/kak-nastroit-telegram-uvedomleniya)
- **Slack** — бот ставит админ компании (Профиль → Уведомления → «Боты» → «Настроить Slack-bot»); `/kaiten authorize email`, `/kaiten help`, `/kaiten subscribe`; блок/разблок из уведомления; ссылка на карточку разворачивается в сводку; статус пространства (лимиты, блоки, сроки). [Slack](https://faq-ru.kaiten.site/kak-nastroit-slack-uvedomleniya)
- **Max** — личные уведомления, создание карточек, комментарии, Service Desk в мессенджере Max. [Max](https://faq-ru.kaiten.site/integraciya-s-maks)
- **Мобильный push** — переключатель «Мобильное приложение» + разрешение ОС; в PWA push не работает. [Не приходят](https://faq-ru.kaiten.site/chto-delat-esli-uvedomleniya-ne-prihodyat)
- **Уведомления чатов** — Профиль → Уведомления → вкладка «Уведомления из Talks»: личные сообщения, сообщения и упоминания в группах, браузерные уведомления (по запросу разрешения; по умолчанию выкл.), звук (выбор/выкл.); прочитанное на компьютере не дублируется на телефон. [Чаты](https://faq-ru.kaiten.site/nastroyka-uvedomleniy-iz-chatov)
- **Уведомление о завершении фоновых операций** — копирование, создание из шаблона, импорт. [Копирование](https://faq-ru.kaiten.site/kopirovanie-prostranstv)
- **Календарная подписка (iCal)** — личная (мои сроки) и по пространству (выбранный тип карточек, опц. сроки пунктов чек-листа): ссылка для Google/Яндекс/Outlook/Apple; события на время срока (не «весь день»), статус в названии; обновление на стороне календаря; смена настроек → новая ссылка. [Календарь](https://faq-ru.kaiten.site/e049a6f1-3762-41dd-8e34-07eb690e37a3) (нужен включённый публичный доступ компании)
- **Нет в справке** — «не беспокоить»/тихие часы, дайджест по времени (кроме утренней сводки сроков), подписка на доску целиком (есть только в Telegram/Slack).

### Горячие клавиши (полный список справки) — [Горячие клавиши](https://faq-ru.kaiten.site/94793baa-e6cf-415a-82e6-809bb830daf1)
- **Пространство** — `i` подсветить номера карточек; `Shift+Enter` вставить многострочный список (несколько карточек); `Shift+клик` выбор для массовых действий; `−` свернуть/развернуть все доски; `c` новая карточка; `h` справочный центр → раздел горячих клавиш; `F1` (Mac `fn+F1`) справочный центр; `Ctrl+K` быстрый поиск; `t` или `[` открыть/закрыть дерево; `Shift+F` свернуть/развернуть панель фильтров; `Alt/Option+перетаскивание` создать дочернюю карточку.
- **Виды** — `1` Доски, `2` Timeline, `3` Таблица, `4` Календарь, `5` Архив, `6` Отчёты.
- **Открытая карточка** — `Esc` закрыть/выйти из режима; `f` на весь экран; `Shift+C` создать дочернюю; `Shift+K` связать с существующей (как родитель); `a` назначить ответственного; `i` назначить себя; `m` к комментарию; `l` метки; `d` переместить (окно «Переместить в»); `w` избранное; `q` таймер старт/стоп; `b` панель блокировки; `Shift+S` поделиться; `.` меню действий; `Shift+T` наверх колонки; `Shift+B` вниз колонки.
- **Timeline** — `Ctrl+Alt(Opt)+1/2/3/4` масштаб часы/дни/недели/месяцы; `+`/`−` следующий/предыдущий масштаб; `Ctrl+Alt(Opt)+A` «Видимые поля»; стрелки — прокрутка.
- **Другие** — `Ctrl/Cmd+V` над колонкой — карточки из картинок; в карточке — вложение из буфера; отдельная страница «Горячие клавиши для работы с документами». [Создать карточку](https://faq-ru.kaiten.site/kak-sozdat-kartochku), [Документы](https://faq-ru.kaiten.site/goryachie-klavishi-dlya-raboty-s-dokumentami)

### Профиль (аватар справа вверху → «Настройки профиля») — [Профиль](https://faq-ru.kaiten.site/nastroyki-lichnogo-profilya)

- **Смена email** — «Изменить email» + PIN на старый адрес. [Профиль](https://faq-ru.kaiten.site/nastroyki-lichnogo-profilya)
- **Пароль** — по умолчанию вход по PIN из письма; можно задать/сменить пароль; 2FA (пароль + PIN на почту) для компаний без SSO. [Профиль](https://faq-ru.kaiten.site/nastroyki-lichnogo-profilya), [ЧН сент. 2026](https://faq-ru.kaiten.site/053a6657-07a1-4de7-9c99-fe468b3f97b6)
- **Тема** — тёмная/светлая («Внешний вид»). [Профиль](https://faq-ru.kaiten.site/nastroyki-lichnogo-profilya)
- **Вид пространств по умолчанию и способ открытия карточки** — «Внешний вид». [Вид по умолчанию](https://faq-ru.kaiten.site/vid-prostranstva-po-umolchaniyu), [Способ открытия](https://faq-ru.kaiten.site/vybor-sposoba-otkrytiya-kartochki)
- **Язык интерфейса и стартовое пространство** — «Языки и пространство по умолчанию». [Профиль](https://faq-ru.kaiten.site/nastroyki-lichnogo-profilya)
- **Уведомления, подписки на пространства и колонки, боты** — в профиле. [Профиль](https://faq-ru.kaiten.site/nastroyki-lichnogo-profilya)
- **Интеграция с календарём** — личная iCal-ссылка. [Календарь](https://faq-ru.kaiten.site/e049a6f1-3762-41dd-8e34-07eb690e37a3)
- **Личный API-ключ** — сгенерировать токен для интеграций. [Профиль](https://faq-ru.kaiten.site/nastroyki-lichnogo-profilya)
- **Нерабочие дни** — сам пользователь отмечает отпуск/больничный/командировку (даты, причина); автоодобрение (зелёный) или заявка руководителю (жёлтый); бейдж на аватаре; учитывается в Timeline/Ганте. [Нерабочие дни](https://faq-ru.kaiten.site/d766b2af-a236-4902-a8ab-67f2cea46e9f)
