## 1. Структура и навигация
- **Компании** — есть — у каждой свои дерево, группы («Все сотрудники»), метки, типы карточек, приглашения и журнал; учётная запись одна на весь Selen, членство «дом»; создаёт и переименовывает только Владелец, справочники новой компании — из шаблона в коде — П2b-1/П2b-2, ADR-0024, `admin/companies`
- **Человек в нескольких компаниях («дома»)** — есть — дерево с заголовками компаний (у кого компания одна — названий нигде нет); его учётной записью управляет только Владелец — П2b-2
- **Гости (доступ к пространствам чужой компании, срок по желанию)** — по плану: П2c — ADR-0024
- **Архив и удаление компаний** — идея без решения — ADR-0024, «Отложено»
- **Папки** — есть — вложенность до 4 уровней, эмодзи-иконка, переименование, «Переместить в…» и «Выше/Ниже», архив (только без активного содержимого), возврат с галочкой «вместе с пространствами», удаление навсегда (только пустой) — этап 3b, ADR-0013, LATER-43
- **Доступ через папки (наследование)** — по плану: П2d — сейчас папки доступа не дают (ADR-0013)
- **Пространства** — есть — название, ключ (2–10 латинских заглавных, неизменяемый, общий на весь Selen), описание, эмодзи в дереве, архив и возврат; удаление навсегда — только если карточек в нём никогда не было — этап 1, ADR-0005, LATER-43
- **Дерево (сайдбар)** — есть — папки → пространства → доски; показывает только доступное (пустые папки видит только Владелец); поиск «Найти…» на клиенте; раскрытые узлы запоминаются; «+» и «⋯» в строке по правам; значок «доступно всем» с Tooltip — 3b, 3c, ADR-0013, LATER-88
- **«Структура»** — есть — полная структура компании в админке, архивное на своих местах, пометка «Не видно в вашем дереве» — 3b, 3c
- **Перетаскивание в дереве и «Структуре»** — идея без решения (сейчас меню) — LATER-5≈
- **Поиск по дереву на сервере** — идея без решения (вместе с поиском этапа 6) — LATER-30
- **Полоса разделов слева** — частично — есть «Дерево» и «Администрирование», выбор запоминается; «Уведомления», «Избранное» и «Моё» встанут по мере появления — 3b, README Kaiten 01
- **Избранное** — по плану: этап 7 — раздел в полосе и пункт «Добавить в избранное» в «⋯» — LATER-2≈
- **«Моё»** — не упоминается (есть только в описании Kaiten, README 01)
- **Главная** — есть — список доступных пространств с ролью — HomePage
- **Ссылка на недоступное** — есть — `/cards/X`, `/boards/ID`, `/spaces/KEY` ведут на главную с одинаковым уведомлением «нет доступа или не существует» — П2b-2
- **Копия пространства или папки** — по плану: этап 7 — диалог «что копировать» — LATER-3≈
- **Одна доска в нескольких пространствах** — идея без решения — только внутри одной компании — LATER-17

## 2. Доски и виды
- **Доски** — есть — шаблоны «Простая», «Разработка», «Пустая»; переименование, порядок, архив и возврат («Архив досок») — этап 1
- **Описание доски** — есть — за значком ⓘ у названия; задать, изменить, стереть — LATER-64
- **Колонки** — есть — создать, переименовать, переставить (через меню), архивировать (только пустую); категория «Очередь / В работе / Готово», смена категории пишет переходы; предупреждение «нет колонки Готово» — этап 1, ADR-0006, ADR-0007
- **Подколонки** — есть — второй уровень; категория — только у первого — этап 1
- **Дорожки** — есть — «Основная» по умолчанию (заголовок скрыт, пока дорожка одна); создать, переименовать, переставить, архивировать; полоса со счётчиком; личное сворачивание — этап 1, пакет раскладки PR 2, LATER-55
- **Восстановление архивных колонок и дорожек** — идея без решения — LATER-6
- **Перестановка колонок и дорожек перетаскиванием** — идея без решения (сейчас меню) — LATER-25
- **WIP-лимиты** — по плану: этап 6 — бейдж «5/7», превышение — предупреждающим цветом — README Kaiten 03
- **Перетаскивание карточек** — есть — между колонками и дорожками, автопрокрутка, перенос с клавиатуры; изменение сразу на экране с откатом при ошибке — этап 1, раскладка PR 1
- **Перенос карточки на другую доску пространства** — есть — «Переместить…» и «Расположение» в окне карточки — этап 1, UI-1a
- **Добавление карточки на доске** — есть — «+ Карточка» по наведению под последней карточкой, «+» в заголовке листовой колонки — LATER-44
- **Автоназначение при переходе в «В работе» / «Готово»** — есть — настройка доски — этап 2a
- **Раскладка доски** — есть — доска блоком на холсте по ширине колонок, закреплённые шапка и заголовки колонок, прокрутка внутри доски, полоса прокрутки внизу окна — раскладка PR 1, LATER-4, LATER-50, ADR-0019
- **Экран пространства** — есть — все доски рядами, перестановка за ⠿ и через меню, личное сворачивание досок, вкладки «Доски / Участники / Метки», «Создать доску»; отдельный адрес `/boards/ID` остаётся — раскладка PR 3, LATER-55, LATER-79, LATER-81
- **Фасад карточки** — частично — сейчас есть: номер, тип, метки, аватар ответственного, срок с подсветкой, «Срочно», общий прогресс чек-листов, блокировка (рамка и значок), счётчики файлов и комментариев. По плану: люди чипами, чек-листы строками, полоса типа (этап 7), поля на фасаде (этапы 5 и 7) — этап 2, README 03
- **Прогресс дочерних карточек на фасаде** — идея без решения — LATER-27≈
- **Вид «Таблица»** — по плану: этап 6
- **Виды «Таймлайн» и «Календарь»** — по плану: этап 11
- **Виды «Список» и «Файлы»** — не упоминается (только в описании панели Kaiten)
- **Быстрое открытие больших пространств (рисовать только карточки у экрана)** — отложено, пока пространство на пилоте не открывается дольше ~500 мс — LATER-83 (в неё влита LATER-37)
- **Ограничение типов карточек по доскам** — идея без решения — LATER-19≈

## 3. Карточки
- **Номер `KEY-N`** — есть — без гонок и повторов, адрес `/cards/DEV-123` — этап 1
- **Окно карточки как в Kaiten** — есть — большое окно со своим адресом, на узком экране — во весь экран. Шапка: название правится на месте, номер копирует ссылку, заказчик, «Создана / Перемещена». Сворачиваемые «Основные параметры» и «Описание», вкладки «Комментарии» и «История» — UI-1a, LATER-90
- **Меню «+»** — есть — «Основное» (срок, метки, чек-лист, ссылка, файл, «План, ч»), «Связи», «Остальное» (блокировка); колонка «Поля» — заглушка до этапа 5 — UI-1a, LATER-97
- **Меню «⋯»** — есть — переместить, архивировать и вернуть, скопировать ссылку, удалить в корзину — UI-1a
- **Кнопки «→ следующая колонка», «!» и «поделиться»** — по плану: этап 7 — README 02
- **Люди** — есть — заказчик (по умолчанию автор), ответственный, участники; деактивированные остаются на карточке с бейджем — этап 2
- **Встроенные поля** — есть — срок (дата или дата со временем в часовом поясе профиля, подсветка как в Kaiten), «Срочно», «План, ч» с шагом 0,5 — этап 2
- **Типы карточек** — есть — справочник компании (Задача, Баг, История, Эпик и свои), название и цвет, архив; раздел админки «Типы карточек» — этап 1, П2b-1
- **Набор полей по типу карточки** — по плану: этап 5 — LATER-97
- **Метки** — есть — метки компании (ведёт админ компании) и метки пространства (ведёт его админ), название и цвет, архив — этап 2
- **Описание** — есть — редактор Tiptap: заголовки, списки, чекбоксы, ссылки, код, цитаты, Markdown-сокращения; сервер пропускает только разрешённое; картинки из буфера и перетаскиванием — этап 2, ADR-0009
- **Комментарии** — есть — тот же редактор, доступны всем ролям; правка с пометкой «изменено», мягкое удаление, отправка по Ctrl+Enter — этап 2
- **Упоминания @** — есть — упомянуть можно только того, кто видит карточку; хранятся в таблице mentions; уведомлений нет (этап 4) — этап 2, ADR-0009
- **Чек-листы** — есть — несколько на карточку, отметка пунктов, перестановка мышью и с клавиатуры, прогресс — этап 2
- **Ссылки** — есть — http/https с названием — этап 2
- **Вложения** — есть — до 100 МБ, хранятся на диске вне public или в S3. В браузере открываются картинки, видео (mp4, webm, mov) и PDF (свой CSP); SVG и HTML — только скачиванием; файл можно бросить на окно — этап 2, UI-1b, ADR-0010
- **Прямая ссылка на файл** — есть — `/files/{id}`; без входа — страница входа и возврат к файлу; пункт «Скопировать ссылку на файл» — UI-1b, LATER-51
- **Миниатюры картинок** — идея без решения — LATER-7≈
- **Перекодирование видео HEVC → H.264** — идея без решения — LATER-26≈
- **Связи родитель / дочерняя** — есть — внутри пространства, несколько родителей, без циклов, прогресс дочерних в окне — этап 2c, ADR-0011
- **Блокировки** — есть — эпизоды в card_blocks, несколько одновременно, причина текстом и/или блокирующей карточкой; снимается сама, когда блокирующая входит в «Готово»; плашка в окне — этап 2c, ADR-0011
- **Комментарий при снятии блокировки** — идея без решения — LATER-28≈
- **История карточки** — есть — лента перемещений и изменений «было / стало», скрытые карточки замаскированы — этап 2c, ADR-0006
- **Архив карточек** — есть — архивировать и вернуть; архив доски с поиском по номеру и названию — этап 2c
- **Корзина карточек** — есть — мягкое удаление; удаляет и восстанавливает админ компании (раздел «Корзина»); с П2d — право роли «Администратор» — LATER-45, ADR-0015
- **«Только свои карточки»** — есть — чужая карточка везде даёт 404, в связях — «Скрытая карточка»; с П2a — это область роли — этап 2, ADR-0008
- **Перенос карточки в другое пространство** — идея без решения — с историей, номер меняется, только внутри компании — LATER-18
- **Шаблоны карточек и копирование карточки** — не упоминается
- **Критерии приёмки** — идея без решения (уточнить у PM: чек-лист или поле) — LATER-97

## 12. Администрирование
- **Владелец** — есть — один на весь Selen, им никто не управляет. Создаёт компании, назначает их администраторов, видит админку всех компаний; без выдачи доступа содержимое не видит. Передача владения — с паролем или аварийно командой — 3c, ADR-0017, LATER-54
- **Администратор компании** — есть — заменил «системного администратора»; ведёт в своей компании пользователей, приглашения, группы, справочники, «Структуру», «Пространства», журнал и корзину — П2b-1, ADR-0024

### «Права 2.0» по подэтапам (docs/stages/rights-2.md; ADR-0024 — черновик)
Порядок по решениям PM 23.10 и 26.10: П2a → П2b-1 → П2b-2 → «Редизайн» → П2c → П2d. П2e идёт параллельно с П2c или П2d, П2f — запросы на доступ. Полный аудит и отчёт этапа — в последнем подэтапе.
- **П2a. Каталог прав и стандартные роли** — сделан 23.10. Enum Permission: права на сущности (папки, пространства, доски, карточки, поля, время, автоматизации) и права компании. Таблицы roles, role_permissions, access_grants; участники и группы пространств перенесены в выдачи; AccessResolver; политики проверяют права каталога. Для пользователей ничего не изменилось.
- **П2b-1. Компании: данные и изоляция** — сделан 23.10. Таблицы companies и company_members («дом», администратор); company_id у корневых таблиц и у журнала; все данные — в «Компании 1»; `users.role` = owner или member. API админки — `admin/companies/{company}/…`; связи между компаниями запрещены в БД; шаблон справочников новой компании. Интерфейс прежний.
- **П2b-2. Админка нескольких компаний** — сделан 26.10 (PR #31). Экран «Компании»; выбор компании в админке (`/admin/c/<id>/…`); заголовки компаний в дереве; ссылка на недоступное ведёт на главную; вкладки в «Пользователях»; человек с двумя «домами»; одинаковый ответ и лимит приглашений; демо «Компания 2» и «Компания 3».
- **П2c. Гости, приглашения, права компании** — следующий. Гостевое членство (срок по желанию) и «Добавить гостя»; приглашение с выбором компании и правом «приглашать»; одно письмо для всех; приглашение существующего сотрудника (второй «дом»); деактивация в компании; права компании галочками лично и группам; аналитика трудозатрат — по праву. Плюс хвосты П2b-2: подтверждение «Снять» администратора, «последний администратор» по всем компаниям, события деактивации во всех «домах».
- **П2d. Доступ через папки и несколько ролей** — по плану. Выдачи на папки с наследованием; несколько ролей на сущность; «Доступ…» у папки и пространства; «Участники» с источниками; вкладка группы «Сущности»; «Переместить в…» с предупреждением «получат / потеряют доступ»; у пространства всегда есть кто управляет доступом. Стандартный «Администратор» получит права на папки, корзину, архив, удаление и перемещение пространства (это меняет ADR-0015); README Kaiten, раздел «05».
- **П2e. Пользовательские роли** — по плану. «Администрирование → Роли»: стандартные роли — только просмотр; пользовательские — создать, дерево галочек, область карточек, флаг новых прав, копировать, удалить неиспользуемую, порядок.
- **П2f. Запросы на доступ** — по плану — вкладка «Запросы на доступ» в «Пользователях» — LATER-114.
- **Что осталось вне «Прав 2.0»** — отложены LATER-10, права «Корень меню», архив и удаление компаний; для LATER-17 и LATER-18 записаны только правила на будущее; LATER-105 — сразу после этапа; LATER-11 влита в план.
