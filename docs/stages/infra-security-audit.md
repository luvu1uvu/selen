# Инфраструктура: агент-аудитор безопасности и проверки в CI — журнал работ

Карточка: **LATER-60** («Бэклог», «Взято в работу»). Ветка `infra/security-audit` от main `f4bec17`, рабочая копия
`~/dev/selen/.claude/worktrees/security-audit` (основная копия была занята веткой `layout-1` с чужими
незакоммиченными правками). Журнал обновляется после каждого крупного блока.

## Задача (промт PM, кратко)

1. Агент `.claude/agents/security-auditor.md`: только чтение кода и безопасные команды (composer audit, npm audit,
   make test при необходимости), ничего не меняет. Чек-лист по нашей системе; отчёт — находка, где, как
   воспроизвести, уровень (критично / важно / мелочь), предложение исправления. «Критично» и «важно» — карточками
   на стенд (`make pm-bug`, метка «безопасность»).
2. CLAUDE.md: когда звать аудитора — полный аудит в конце этапа и перед пилотом; точечно — если затронуты вход и
   сессии, права, файлы, инфраструктура. Не чаще.
3. CI: composer audit, npm audit (падать на high/critical), сканер секретов, Dependabot (composer, npm, GitHub Actions,
   Docker). Красное на main — не чинить в этом PR, а составить список.
4. Первый прогон аудитора на main целиком: отчёт `docs/security/audit-2026-10.md`, найденное — карточками.
   В этом PR ничего не исправлять. PR не мёржить до «принято».

## Решения PM (2026-10-19, при утверждении плана)

- ADR — **0020** (0019 занимает пакет «Раскладка доски и пространства»).
- Метка «безопасность» на стенде уже есть. `pm-bug` с полем `labels` только ставит существующие метки; нет метки —
  предупреждение, бот метки не заводит (его права не расширяем).
- Dependabot: обновления безопасности — сразу; minor/patch — одним сгруппированным PR раз в неделю; major — не
  предлагать; `open-pull-requests-limit: 3`.
- Hook — да. Агент запускается только из `~/dev/selen` или его рабочих копий; в недоверенной папке он сначала говорит
  об этом и не выполняет команд Bash.
- Карточки находок — после мёржа и `make pm-update` (до этого — в отчёте в PR). Критичное — сообщать сразу.

## Что было красным на main до этого PR

- `composer audit` в режиме по умолчанию падает (код 1) из-за двух заброшенных пакетов — `dragon-code/pretty-array`
  (замены нет) и `dragon-code/support` (замена — `illuminate/support`); их тянет laravel-lang. В CI не роняем
  (`--abandoned=report`), в отчёте аудита — «мелочь».
- Уязвимостей high/critical (composer, npm `frontend` и `e2e`) нет; gitleaks по всей истории — чисто.
- Dependabot alerts и Dependabot security updates в настройках репозитория **выключены** — без них «обновления
  безопасности сразу» не работают; включает владелец репозитория (runbook, раздел 14).
