## Исправление (LATER-69)

Формат копии Remote Control сверен по выводу `git worktree list --porcelain` с живой копией сервера (16–19.10):

```
worktree <основная копия>/.claude/worktrees/bridge-cse_<id сессии>
branch refs/heads/worktree-bridge-cse_<id сессии>
locked claude agent bridge-cse_<id сессии> (pid <pid сервера> start <время запуска сервера>)
```

Время в причине — в формате `LC_ALL=C ps -o lstart=` (например, `Fri Oct 16 14:09:03 2026`); скрипт сравнивает его со временем запуска процесса в UTC и в
местном времени.
