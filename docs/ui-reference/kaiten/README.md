# UI-референсы: Kaiten

Цель — сделать Selen максимально похожим на Kaiten по раскладке и поведению, чтобы сотрудники
переехали с минимальным трением. Копируем расположение элементов, сценарии и привычные паттерны.
**Не копируем** фирменный облик Kaiten: логотип, иконки, иллюстрации, фирменные цвета один в один.

Каждая сессия Claude Code, которая делает или меняет экран из этого списка, сверяется с этим файлом.
Колонка «Этап» — где пункт реализуется (номера — по [дорожной карте](../../roadmap.md); UI-1 и «пакет раскладки» —
работы до этапа 4).

**Скриншотов здесь нет — только описание словами** (ADR-0022): на снимках Kaiten — реальные доски компании,
ФИО и внутренние ссылки, а репозиторий публичный. Исходные снимки — в архивном приватном репозитории
`selen-archive` и у PM. Новый референс — словами (что видно, где расположено, как себя ведёт) или скриншотом
нашего dev с демо-данными.

## 01 — Дерево (сайдбар)

**Раскладка.** Левый край окна во всю высоту занимают две полосы:
- узкая (около 50 px) вертикальная полоса значков разделов: сверху вниз — уведомления, «моё», избранное (звезда),
  дерево, ещё пара разделов; внизу полосы, отдельно от остальных, — значок профиля. Активный раздел — значок
  в цветной подложке со скруглением;
- справа от неё — панель раздела шириной около 300 px. Шапка: заголовок «Дерево» слева, кнопка сворачивания панели
  справа. Под шапкой — поле поиска «Найти…» с лупой во всю ширину, справа от поля — кнопка «+».

**Строка дерева** (сверху вниз — плоский список с отступами по вложенности): значок типа узла (папка, пространство,
доска, документ; у пространства и папки — свой эмодзи вместо стандартного значка), стрелка «›» у раскрываемых
(у раскрытого — «˅»), у части узлов — значок «человечки», затем название. Длинное название обрезается многоточием.
Строка доски — без стрелки, со значком доски. Выбранная строка подсвечена фоном со скруглением.

**Поведение.** Пространство раскрывается в список своих досок; внутри пространства может быть вложенная папка
с документами. Раскрытые узлы запоминаются.

| Что видно | Как делаем в Selen | Этап |
|---|---|---|
| Узкая вертикальная полоса иконок слева: уведомления, «моё», избранное, дерево и др. Дерево — один из разделов | Полоса разделов. Сразу — «Дерево» и «Администрирование»; остальные разделы встают на свои места по мере появления | 3b |
| Шапка панели: заголовок «Дерево», кнопка сворачивания панели, поле «Найти…», кнопка «+» | Так же. «+» видит тот, кто ведёт структуру компании (администратор компании, Владелец) | 3b, П2b-2 |
| В одном дереве лежат папки, пространства и (позже) документы | Узлы дерева с типом: folder / space / document | 3b (document — этап 8 «Документы») |
| Пространство раскрывается в список своих досок; внутри пространства может быть вложенная папка с документами | Пространство → доски. Документы внутри пространства — на этапе 8 «Документы» | 3b |
| У пространств и папок свои иконки-эмодзи (например, 📦 или 💡) | Эмодзи-иконка у пространства и папки, задаёт системный админ; без иконки — стандартная | 3b |
| Иконка с человечками перед названием | Означает «доступно всем сотрудникам» (пространство открыто встроенной группе «Все сотрудники») | 3b |
| Подсветка выбранного элемента, стрелки раскрытия, запоминание раскрытых папок | Так же | 3b |
| (в Kaiten компания одна) | Несколько компаний (ADR-0024): над деревом каждой компании — заголовок с её названием, «+» — в заголовке компании, структуру которой ведёшь; компания одна — дерево как раньше, без заголовка | П2b-2 |

## 02 — Открытая карточка

**Раскладка** (окно около 800 px шириной, сверху вниз):
1. Крупное название карточки в одну-две строки.
2. Строка мелким шрифтом: «#номер» (ссылка) и «Заказчик <имя сотрудника>» (ссылка).
3. Серая строка со значками: «Создана N месяцев назад · Перемещена N месяца назад».
4. Горизонтальная линия во всю ширину. На её левом конце — большая круглая цветная кнопка «+»; на правом — ряд
   круглых белых кнопок с тенью: ▶ (таймер), кнопка-пилюля «→ <название следующей колонки>», ⚡ (автоматизации),
   «!» (блокировка), «поделиться», «⋯».
5. Секция «Основные параметры» со стрелкой сворачивания. Внутри — две колонки: название поля серым слева,
   значение справа. Сначала встроенные поля: «Расположение» (ссылка «доска / колонка (дорожка)» и лупа — выбор
   другого места), «Тип» (чип: кружок с буквой и название типа), «Участники» (ссылка «Добавить участников»).
   Дальше — пользовательские поля пространства, по строке на поле.
6. Секция «Описание» со стрелкой сворачивания и серым текстом-подсказкой в пустом описании.
7. Внизу — две вкладки цветным текстом со значками: «Комментарии» и «Спросить ИИ».

**Когда:** окно карточки как в Kaiten — UI-1 (до этапа 4): само окно, шапка, секции, комментарии; что не войдёт
в UI-1 (кнопки ряда действий и другие детали окна) — этап 7. Точный состав UI-1 — в его плане.

| Что видно | Как делаем в Selen | Этап |
|---|---|---|
| Карточка открывается большим окном поверх доски, а не узкой боковой панелью | Большое окно (модальное) со своим URL `/cards/KEY-N`; на узком экране — на весь экран; закрытие — шагом назад по истории, несохранённый текст — с вопросом | сделано (UI-1a) |
| Шапка: крупное название; строка «#номер · Заказчик ФИО»; «Создана N назад · Перемещена N назад» | Так же (относительное время, точное — в подсказке); номер — наш ключ `DEV-12`, щелчок копирует ссылку; заказчик меняется щелчком по имени | сделано (UI-1a) |
| Ряд действий: слева круглая «+» (добавить блок/поле), справа кнопки: ▶ таймер, «→ <следующая колонка>» (перенос в следующую колонку одним кликом), ⚡ кнопки автоматизации, «!» блокировка, «поделиться», «⋯» | «+» — как в Kaiten, две колонки: слева «Основное» (срок, метки, чек-лист, ссылка, загрузить файл), «Связи», «Остальное» (блокировка), справа «Поля» — заглушка до этапа 5 (LATER-97); «⋯» (перенос, архив, ссылка, корзина) — сделано в UI-1a; «→ Следующая колонка», «!», «поделиться» — в этапе 7; ⚡ — этап 10 «Автоматизации»; ▶ таймер — этап 6c, вместе с ручным учётом времени (решение PM 2026-10-22, LATER-1; раздел 08) | UI-1a / 6c / 7 / 10 |
| Сворачиваемая секция «Основные параметры»: Расположение (доска / колонка + поиск), Тип, Участники | Так же; дальше — ответственный, срок, «Срочно», метки, план в часах | сделано (UI-1a) |
| Дальше в той же секции — **пользовательские поля**: флажки (к каким платформам относится задача), сотрудник (чип с инициалами и ФИО), числа (оценки Reach, Impact, Confidence, Effort), ссылка (на внешний документ), выбор из списка (цветной чип со значением), вычисляемые (число дочерних карточек; RICE = Reach × Impact × Confidence / Effort) | Модуль пользовательских полей, все типы: текст, число, дата, флажок, ссылка, сотрудник, выбор из списка, множественный выбор, формула | 5 |
| Сворачиваемая секция «Описание» с подсказкой-плейсхолдером | Так же; ниже — чек-листы, связи, блокировки, файлы, ссылки, «Сведения» (пустые скрыты, появляются через «+») | сделано (UI-1a) |
| Внизу вкладки «Комментарии» и «Спросить ИИ» | Комментарии — так же, вторая вкладка — «История»; ИИ — не делаем (решение PM 2026-10-20) | сделано (UI-1a) / — |

## 03 — Экран пространства с досками

**Раскладка.**
- Сверху во всю ширину — панель пространства. Слева — группа переключателей видов: «Доски» (значок с подписью,
  активный) и значки других видов (таймлайн, таблица, список, календарь, файлы); дальше серые кнопки «Отчёты»
  и «Архив» и цветная «+ Добавить». Справа — «Фильтры» и пара значков (настройки вида, свернуть панель).
- Ниже — все доски пространства. В примере их две, рядом: слева узкая доска в одну колонку, справа широкая
  в семь колонок, которая уходит за правый край экрана.
- Шапка доски: слева ручка перетаскивания ⠿ и название доски, справа «˄» — свернуть доску.
- Под шапкой — строка заголовков колонок: название слева, счётчик справа. Без WIP-лимита — серый бейдж с числом,
  с лимитом — зелёный бейдж «сколько/лимит» (например, «5/7»). Колонки одной ширины (около 250 px), разделены
  тонкими вертикальными линиями.
- Под заголовками колонок — строка дорожки во всю ширину доски: название слева, справа счётчик карточек дорожки
  и «˄» — свернуть дорожку.
- Карточки — белые прямоугольники с лёгким скруглением во всю ширину колонки, друг под другом с небольшим зазором.

**Фасад карточки** (сверху вниз): название (переносится на несколько строк); чипы значений пользовательских полей —
цветная пилюля значения поля-списка, число в кружке (вычисляемое поле), серые пилюли с ФИО (поле «сотрудник»);
метки — цветные пилюли; значки скрепки и облачка с числом вложений и комментариев; строки чек-листов — название
серым мелким шрифтом, справа зелёная галочка и «3/3». Снизу слева — короткая цветная полоса типа карточки.
У отдельных карточек — цветная полоса сверху и значок ◆ справа от названия.

**Доски на холсте** (два снимка PM к LATER-50, 19.10; в пространстве три доски: одна в одну колонку, две — в пять):
- Холст — светло-серый фон под досками, заметно темнее самих досок. Между досками (зазор около 8 px), справа от них
  и под ними виден холст; на первом снимке PM стрелками показал именно эти места.
- Доска — блок с почти белым фоном, тонкой серой границей и скруглёнными углами. Ширина блока — сумма колонок
  (около 200 px на колонку): доска в одну колонку — узкий блок около 210 px, в пять колонок — около 1010 px.
  На всю ширину экрана блок не растягивается.
- Высота блока — по содержимому: доска без карточек низкая (шапка, заголовки колонок и пустое поле около 90 px),
  доска с карточками — по самой высокой колонке. Вертикальные линии между колонками — на всю высоту блока.
- Снимок 1: в первом ряду слева узкая доска, справа от неё широкая; во втором ряду широкая доска с карточками стоит
  под широкой первого ряда (левый край — как у неё), под узкой — пустой холст. Снимок 2: те же три доски, каждая
  в своём ряду, друг под другом, по левому краю; справа от каждой — холст своей ширины.
- Шапка и заголовки колонок — как описано выше; над холстом — панель пространства, над ней — строка поиска окна.

## 04 — Кнопки автоматизации

## 05 — Фильтры и поиск

Источник разделов 05–09 — пробный аккаунт Kaiten с тестовыми данными (аудит 27.10,
[каталог](../../research/kaiten-audit.md), разделы 5–9); снимки — в `selen-archive`, папка `kaiten-audit/`.

**Раскладка.** Кнопка «Фильтры» — справа на панели пространства. Условия появляются строкой над досками, каждое —
плашкой «поле: значение» с крестиком. Критерии добавляются по одному из длинного списка: текст и номер, люди
(заказчик, участник, ответственный), признаки (срочность, блокировка, тип, метка, размер), даты, место на доске,
пользовательские поля. У критерия — «равно / не равно» и значение, у людей ещё «не назначен». Группы условий
связываются «и» или «или»; для сложных условий есть большое окно.

Поиск — поле в шапке окна по центру; Ctrl/Cmd+K открывает то же окно. В окне вкладки по видам объектов (карточки,
документы, папки и др.), у карточек — уточнения: пространство, архивные, метки, тип, «только в названии».

**Поведение.** Фильтр один на все виды пространства и переходит между ними; счётчики колонок и дорожек считают только
видимые карточки. Фильтр хранится в адресе страницы и сам возвращается при следующем входе в пространство; его можно
сохранить личным или общим. Щелчок по метке на фасаде сразу фильтрует по ней. Поиск Kaiten по умолчанию ищет только
в названиях и только по началу слова, без окончаний; «ё» и «е» различает; номер находит только целиком.

| Что видно | Как делаем в Selen | Этап |
|---|---|---|
| «Фильтры» справа на панели пространства; условия плашками над досками; критерии добавляются по одному | Так же. Сначала — люди и «не назначен», метки, тип, срок и «просрочено», колонка, блокировка; пользовательские поля — после этапа 5 | 6a |
| «и / или» между группами условий, большое окно для сложных | Так же | 6a |
| Фильтр в адресе страницы, возвращается при следующем входе; сохранённые личные и общие фильтры | Так же | 6a |
| Щелчок по метке на фасаде фильтрует по ней | Так же | 6a |
| Поиск в шапке и Ctrl/Cmd+K, вкладки по видам объектов, уточнения выдачи | Так же; в отличие от Kaiten ищем и по содержимому (описание, комментарии — LATER-29), с окончаниями, «ё = е»; номер — и `DEV-42`, и `42`; в выдаче — фрагмент с найденным | 6a |
| «Личное» → мои карточки: я ответственный, карточка не готова | «Мои карточки» по всем пространствам | 6a |

## 06 — Меню доски и колонки

**Раскладка.** У доски по наведению на шапку появляются «+», ссылка, ⋮ и «свернуть». ⋮ открывает не короткий список,
а панель справа со всеми настройками доски, по группам: обычные действия (переименовать, в избранное, ссылка,
описание, удалить); копирование и перенос (клонировать — только структуру или с карточками, перенести в другое
пространство, выгрузить); настройки карточек (тип по умолчанию, предлагаемые поля, сумма по полю, застоявшиеся
карточки, WIP доски); правила доски флажками (назначать ответственным того, кто двигает карточку в работу или в готово;
двигать родителя по дочерним; прятать выполненные чек-листы).

У колонки ⋮ — в заголовке рядом с «+». В меню: переименовать, переставить, удалить, тип колонки (очередь / в работе /
готово); перенести все карточки или отсортировать их; WIP-лимит по числу карточек или по сумме размеров (ноль —
«этап пропускаем»); подписка на колонку; вид — карточки или короткий список; застоявшиеся — предупреждать через N дней
или скрывать; требовать отмеченные чек-листы.

**Поведение.** WIP-лимит сам ничего не запрещает: при превышении счётчик краснеет («5/2»); запрет — только отдельным
ограничением. Окна настроек закрываются по Esc без вопроса — несохранённое теряется (у нас так не делаем).

| Что видно | Как делаем в Selen | Этап |
|---|---|---|
| Меню доски и колонки — панелью справа с группами настроек, а не коротким списком | Так же: настройки этапов 5–10 добавляются в панель группами; закрытие с несохранёнными правками — с вопросом | 7 |
| WIP колонки по числу или по размеру, ноль — этап пропускаем; лимит дорожки | Так же; превышение — предупреждающий цвет бейджа, запрет — ограничением этапа 10 | 6b / 10 |
| Застоявшиеся карточки: предупредить через N дней или скрыть | Предупреждение на фасаде через N дней | 6b |
| Автоархивация карточек «Готово» | Так же, настройка доски | 6b |
| Клонировать доску (структура или с карточками), перенести в другое пространство | Так же | 7 |
| Тип карточки по умолчанию, предлагаемые поля, сумма по полю под колонкой и дорожкой | Так же | 5 |
| Подписка на колонку | Так же | 4 |
| Требовать отмеченные чек-листы и заполненное обязательное поле при переходе | Опции колонки в ограничениях (решение PM 2026-10-28) | 10 |

## 07 — Уведомления

**Раскладка.** Колокольчик — первый значок в полосе разделов слева, со счётчиком непрочитанных. Открывает панель
раздела: список уведомлений (кто, что сделал, с какой карточкой), «все / непрочитанные», «прочитать всё», ссылка на
настройки. Настройки — в профиле: таблица «событие × канал» (в приложении, почта, мессенджеры); подписки — вкладками
по пространствам и колонкам; подписка на карточку — колокольчик на краю окна карточки. Напоминание о сроке задаётся
в окне срока карточки (в назначенное время, за день или за два утром).

**Поведение.** О своих действиях Kaiten не уведомляет. Уведомление о комментарии приходит с задержкой около минуты —
правка успевает попасть. Почта по умолчанию включена почти для всех событий — ящик быстро засыпает.

| Что видно | Как делаем в Selen | Этап |
|---|---|---|
| Колокольчик в полосе разделов со счётчиком; панель «все / непрочитанные», «прочитать всё» | Так же; щелчок по уведомлению открывает карточку | 4 |
| Настройки — таблица «событие × канал» | Так же: в приложении и почта; Telegram — отдельным каналом (решение PM 2026-10-28) | 4 / 4b |
| Подписка на карточку (колокольчик в окне) и на колонку | Так же | 4 |
| Напоминание о сроке в окне срока | Так же; плюс утренняя сводка сроков | 4 |
| Не уведомлять о своих действиях; комментарий — с задержкой ~1 мин | Так же. Что включено по умолчанию — решить при планировании этапа 4 (в Kaiten почта приходит почти обо всём) | 4 |

## 08 — Учёт времени

**Раскладка.** ▶ — в ряду действий открытой карточки. Идущий таймер виден и в верхней панели приложения (время и
«остановить»). Запуск — окно с началом, комментарием и ролью учёта; остановка — окно с готовой записью. В карточке —
блок записей (дата, часы, роль, комментарий) с суммой часов. Раздел «Личное» → мои записи за период (по умолчанию
неделя): сетка «карточки × дни» и список записей, выгрузка.

**Поведение.** В ячейку недельной сетки время не вписать — только через карточку. Комментарий, введённый при запуске
таймера, при остановке теряется. Чужие записи правит только автор. Записи задним числом не ограничены.

| Что видно | Как делаем в Selen | Этап |
|---|---|---|
| ▶ в ряду действий карточки; идущий таймер — в верхней панели | Так же; таймер останавливается, когда карточка уходит в «Готово» | 6c |
| Запись: дата, часы, роль учёта, комментарий | Дата, часы, комментарий; комментарий запуска таймера сохраняется | 6c |
| Блок записей в карточке с суммой | Так же | 6c |
| «Моё время» неделей: карточки × дни и список | Так же | 6c |
| Чужие записи правит только автор | Правит тот, у кого право «править чужие записи» (решения PM 2026-10-22 и 2026-10-28); закрытия прошлого месяца нет | 6c |
| Суммарное время и время в блокировках — столбцы таблицы и архива | Так же | 6c |

## 09 — Отчёты

**Раскладка.** «Отчёты» — кнопка на панели пространства. Открывает список отчётов (в Kaiten их 12). Открытый отчёт:
сверху строка «Отчёты / название» и кнопки «скачать» и «описание графика»; по центру график с пояснениями;
справа — панель фильтра (период, доски, колонки начала и конца пути, типы, метки) и кнопка «Показать».

**Поведение.** Параметры отчёта хранятся в адресе страницы. Отчёты строятся по доскам одного пространства; дашборды
из нескольких пространств — отдельный раздел старшего тарифа.
