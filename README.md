# Selen

Внутренний канбан-инструмент компании: доски, карточки, метрики потока (lead time, cycle time).
Готовы **этап 0** (пользователи, приглашения, вход, журнал событий, бэкапы) и **этап 1** (пространства и доступ,
доски с колонками, подколонками и дорожками, карточки с перетаскиванием, история перемещений, lead/cycle time).

## Быстрый старт

Нужны только **Docker** (Docker Desktop, OrbStack или Colima) и **make**.

```bash
git clone git@github.com:luvu1uvu/selen.git && cd selen
make up       # первый запуск: соберёт образы, поставит зависимости, создаст .env
make fresh    # создаст таблицы и демо-данные: пространства, доски, ~380 карточек с историей за 60 дней
```

Откройте http://localhost:8080.

| Демо-пользователь (только локально), пароль у всех `password-123` | Что увидит |
|---|---|
| owner@selen.test — Владелец | всё, что видит системный администратор, плюс назначение администраторов и передача владения; в дереве — и пустые папки; в DEV — администратор |
| admin@selen.test — системный администратор | админка (кроме действий с администраторами и Владельцем); в DEV — администратор, OPS и MKT — только в админке |
| anna@selen.test | администратор пространства DEV (доска «Продукт» на 300 карточек) |
| boris@selen.test | editor в DEV и OPS |
| vera@selen.test | commenter в DEV (только чтение), editor в MKT |
| member@selen.test | editor в DEV, к OPS и MKT доступа нет |

Письма (приглашения, сброс пароля) не уходят наружу — они видны в Mailpit: http://localhost:8025.

Создать своего администратора: `make admin` (первый созданный на пустой базе становится Владельцем).

## Основные команды

```bash
make help            # все команды
make test            # тесты backend и frontend
make e2e             # тесты в браузере (Playwright) на отдельной базе
make lint            # линтеры
make metrics SPACE=DEV DAYS=60   # сводка lead/cycle time по доскам пространства
make backup          # бэкап базы
```
